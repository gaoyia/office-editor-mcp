# 三家出图金样容差

状态：✅
日期：2026-11-14

对应三家路线的跨格式 **C23**。只读 PNG 已放开。本计划只量 Office 16.0 连续两次导出的抖动，没有写绘制代码。

## 目标

同一对象导出两次。记下 PNG 的宽高、dpi，以及不一致的像素数和单通道最大差。这个差是导出本身的抖动，不是绘制器和 Office 之间的容差。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | Excel `Chart.Export` 两次 | ✅ 481×294，dpi 读数 95.9866，差 0 |
| 1 | PowerPoint `Slide.Export` 两次 | ✅ 1280×720，dpi 读数 95.9866，差 0 |
| 2 | 探测 Word 有没有页面 PNG | ✅ 没有。固定版式导出和 `SaveAs2` 的格式 17 都是 PDF |
| 3 | 把实测写进后几份出图计划 | ✅ |

## 实测

探测脚本留在 `target/pixel-jitter.ps1`，不进仓库用例。以后对图用 `manual-check/pixel-diff.ps1`：左图转成灰度，超过 `-MaxDelta` 的像素涂红。Office 16.0，路径 `C:\Program Files\Microsoft Office\root\Office16`。

- 柱形图在表上占 360×220 磅。`Chart.Export` 得到 481×294 的 PNG，两次字节数都是 3775，141414 个像素全部相同
- `Slide.Export` 不传宽高，得到 1280×720 的 PNG，两次字节数都是 2173，921600 个像素全部相同
- Word 的文档方法里有 `ExportAsFixedFormat` 到 `ExportAsFixedFormat3`，没有页面 PNG。导出的文件头是 `%PDF`

dpi 读数 95.9866 是 96 dpi 在这套图像接口里的写法。连续导出的抖动下限是 0。绘制器以后和金样比，不能比这个下限更严，也不能把这次的 0 写成绘制器已经对齐。

## 不做

- 不新增领域 JSON 动作
- 不把像素写回包
- 对照脚本只标红区。以后的红区在绘制引擎里修，不靠加大 `-MaxDelta` 过关，也不套进现有手测
