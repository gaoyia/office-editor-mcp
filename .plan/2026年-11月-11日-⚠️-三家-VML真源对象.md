## 第 0 步要另存的对象

- Excel：旧式窗体控件（按钮、复选框、下拉）。批注框的位置、大小、是否隐藏。页眉若被收成 `legacyDrawingHF`，记下图片还在不在 VML 里
- Word：现有 DrawingML 水印另存之后，水印是否变成页眉里的 VML。变成了才补查看、修改、删除
- PowerPoint：用户能插入的对象是否还会落进 `p:legacyDrawing`。不会则本格式 🚫

探测脚本放在 `target/`，不提交。2026-11-13 另存结果如下。

- Excel 窗体：按钮、复选框、下拉都在 `xl/drawings/vmlDrawing1.vml` 的 `x:ClientData`（`Button` / `Checkbox` / `Drop`）。同一份另存还有 `drawing1.xml` 的 AlternateContent，以及工作表 `<controls>`。只把按钮文字改成「按钮改」再另存，文字回到「按钮 1」，标题无 Repair。窗体不是单份 VML 真源。🚫，不写 inspect / apply
- Excel 旧式批注框：`comments1.xml` 存文字，框在同一份 VML，`ObjectType="Note"`，`visibility:hidden`，样式里有宽高。只把 `visibility:hidden` 改成 `visible` 再另存，仍是 `visible`，标题无 Repair。`comments` 的 `shapeId="0"` 与 `v:shape` 的 `_x0000_s1028` 不是同一个数。按本轮目标，编号对不上就不写契约。批注框本轮不实现。文字、作者、线程仍走已有批注
- Excel 页眉图：库写入的 `drawingHF` 另存后还在，同时多了 `legacyDrawingHF` 和 `v:imagedata`。页眉图仍走已有 drawing。不新增 VML 页眉 op。🚫
- Word 水印：另存前只有 DrawingML。另存后 Choice 仍是 `wps:wsp`，Fallback 才出现 `w:pict` / `v:shape`。真源没有改成 VML。🚫
- PowerPoint：插入矩形另存后没有 `p:legacyDrawing`，也没有 `v:shape`。本格式 🚫
