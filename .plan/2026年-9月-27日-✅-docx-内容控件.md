## 已锁定

- 只认本期种类：`plainText`（`w:text`）、`richText`（`w:richText` 或未写类型，ECMA-376 §17.5.2 缺省为富文本）、`dropDown`（`w:dropDownList`）、`comboBox`（`w:comboBox`）、`date`（`w:date`）、`repeatingSection`（`w15:repeatingSection` / `repeatingSectionItem`）。嵌套控件各算一条。`parent` 指向最近一层被收入的祖先控件，没有则为 `null`。
- 不收：`docPartObj` / 目录库、`bibliography`、`citation`、`picture`、`group`、`equation`、`checkbox`。目录库仍只走 `toc:`。
- id：正文 `sdt:{n}`，页眉页脚 `{容器}/sdt:{n}`。`{n}` 按该故事里被收入的 `w:sdt` 文档顺序从 1 计。插删后会变。`w:sdtPr/w:id` 进 `xmlId`，缺则为 `null`。`tag` / `alias` 取 `w:tag` / `w:alias` 的 `w:val`，缺则为 `null`。
- `level`：祖先里有 `w:p` 则为 `inline`，否则为 `block`。控件内段落仍走段落 id。
- 根上始终 `contentControlCount`（只计主文档），放在 `mathCount` 之后。页眉页脚容器也始终带 `contentControlCount`（紧跟 `mathCount`）。`scope.contentControls: true` 才列 `contentControls`。
- 每条字段顺序：`id`、`index`、`kind`、`level`、`host`、`tag`、`alias`、`xmlId`、`bound`、`parent`、`text`；下拉/组合框再跟 `items`；日期再跟 `fullDate`。`text` 为 `sdtContent` 子孙所有 `w:t` 拼接。`bound` 为是否有 `w:dataBinding`。
- 遇 `w:txbxContent` 停住；`mc:AlternateContent` 只进 Choice。框内 / 注内 / 批注内本期不编。
- `insertContentControl`：`id` 为正文或页眉页脚段落，或 `docx:document`。必填非空 `text`。可选 `kind`：`plainText`（缺省）、`richText`、`dropDown`、`comboBox`、`date`。可选 `tag`、`alias`、`items`（字符串数组，下拉/组合框）、`fullDate`（日期）。一律写成段内行内 `w:sdt`。`docx:document` 插到正文末尾、`sectPr` 之前的新段。写入唯一 `w:id`。
- `setContentControl` 用一条 run（行内）或第一段可见文本（块级）整份替换当前值。不改 `kind`。带 `w:dataBinding` 或 `kind` 为 `repeatingSection` 报 `NotImplemented`。块级里有 `w:tbl` 报 `NotImplemented`。
- `deleteContentControl`：`keep` 为 `content`（缺省，拆外壳留内容）或 `none`（连内容一起删）。带分节符且不能整段删 → `NotImplemented`。
- `setParaText` 碰到段内本期收入的行内控件 → `NotImplemented`。块级控件里的内层段落仍可 `setParaText`。
- create 本期不写内容控件。xlsx / pptx 拒绝这三个 op 与 `scope.contentControls`。
- 绑定到自定义 XML 的控件：inspect 仍列出（`bound: true`），改值报 `NotImplemented`。重复节只列、可删，不改值。
