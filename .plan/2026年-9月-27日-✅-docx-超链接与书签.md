# docx 超链接与书签

状态：✅  
日期：2026-09-27

从 `roadmap/docx.md` 拆出待做序号 0。`setParaText` 允许改含超链接的段，但可能让链不再包住新字。书签不进树。

## 目标

inspect 列出 `w:hyperlink` 与配对书签。apply 能改地址、插、删，不把整段可见文本当改链的唯一接口。书签能插到段落范围上。

## 已锁定

- 真源仍是 XML 与部件 `.rels`。不要打开 Word 再 Save 来完成改链。
- 超链接 id 按该故事里 `w:hyperlink` 的文档顺序：正文 `link:{n}`，页眉页脚 `{容器}/link:{n}`。关系 `r:id` 只进 `rId`，不当树上的唯一键。
- 书签 id 按该故事里被收入的 `w:bookmarkStart` 的文档顺序：正文 `bookmark:{n}`，页眉页脚 `{容器}/bookmark:{n}`。`w:id` 进 `xmlId`，`w:name` 进 `name`。
- 本期只收 `w:hyperlink` 元素（ECMA-376 §17.16.22）。HYPERLINK 域、图上 `a:hlinkClick`、框内 / 注内 / 批注内的链与书签不进树。
- 书签只收起止都在同一故事里、且 `w:name` 不以 `_` 开头的配对（隐藏书签含 `_GoBack` 不进树）。配对按 `w:id`。
- `setParaText`：段内存在本期收入的 `w:hyperlink` 时报 `NotImplemented`。书签不挡改字。
- 外部链写 hyperlink 关系，`TargetMode` 为 `External`。删链或改成内部锚时清掉无人引用的关系。
- `url` 与 `anchor` 不能同时出现。
- apply 只动被点名的那一个节点。create 本期不写超链接与书签。
- xlsx / pptx 的 `scope.hyperlinks` / `scope.bookmarks` 与对应 op 报 `InvalidField`。

## 不做

- 打开浏览器
- 邮件合并数据源
- HYPERLINK 域（跟域切片）
- 图 / 形状上的点击超链接

无。

另存带链文档能列出地址；改 URL 后 Word 能点开新地址；删书签后无修复。Word 16.0 手测 Hb1–Hb7 已过。
