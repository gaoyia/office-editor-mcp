## 已锁定

- 复用已有 op 名，只扩合法 `id` 宿主。不要为备注另写一套 XML。
- 备注页（`slide:{n}/notes`）扩：视频、音频、OLE、Zoom、连接线、超链接、域。
  图、图表、SmartArt、表、公式、3D、形状、动画已经在备注上，不重做。
- 幻灯片母版 / 版式（`master:{n}`、`master:{n}/layout:{k}`）扩：图、图表、SmartArt、表、视频、音频、OLE、Zoom、连接线、公式、3D、超链接、域。
  占位符与装饰形已经在母版上，不重做。
- id 前缀跟宿主走，例如 `slide:1/notes/video:3`、`master:1/pic:4`、`master:1/layout:1/table:5`、`slide:1/notes/link:1`、`master:1/fld:{guid}`。
- 根上 `pictureCount` / `videoCount` / `oleObjectCount` 等仍只计幻灯片 XML，不含备注、不含母版。与备注图同一惯例。
- 备注对象始终给出与幻灯片同名的计数（`videoCount` 等）。名单仍只跟对应 `scope` 键。
- 母版 / 版式对象不新增永远出现的 Count，以免打乱已验收的字段顺序。
  名单只在 `scope.masters` 与该对象自己的 scope（`pictures` / `media` 等）同开时出现，插在 `shapes` 之后、`layouts` 之前（版式没有 `layouts` 则放在 `shapes` 之后）。
- 批注内图表 / SmartArt / 表 / 媒体 / OLE / Zoom / 公式 / 3D / 连接线 / 域 / 超链接仍拒绝。批注内图维持原契约。
- `notesMaster` / `handout` 本切片不扩这些对象。对这两处发 `insertPicture` / `insertVideo` / `insertOle` 等仍报 `InvalidId`。
- 链接 OLE（`p:link`）与 ActiveX `p:control` 跟幻灯片同一套：现有模块没收的，新宿主也不收。
- 旧式 `commentAuthors` 继续忽略。
- `insertAnim` 已能绑母版占位符 / 装饰形 / 备注形状；新对象进树后按同一套 `tgtEl` 绑。
- create 本期不写这些新宿主（38）。
- 不实现放映引擎。不激活 OLE 服务器。不编辑 VML。
