## 已锁定（实现时不要改）

- 根上始终带 `slideSize`：`cx` / `cy` 取 `p:sldSz` 的 EMU 整数；`type` 取 `@type` 原文，没有则为 `null`。没有 `sldSz` 则 `slideSize` 为 `null`。不改 `notesSz`。
- 不按新 `sldSz` 缩放或重排已有形状、图、表。只改 `presentation.xml` 的 `p:sldSz`。
- `setSlideSize` 的 id 为 `pptx:presentation`。必须给 `cx` 与 `cy`（EMU 整数，`914400`–`51206400`，ECMA-376 `ST_SlideSizeCoordinate`）。`type` 可选，白名单为 `ST_SlideSizeType`：`screen4x3`、`letter`、`A4`、`35mm`、`overhead`、`banner`、`custom`、`ledger`、`A3`、`B4ISO`、`B5ISO`、`B4JIS`、`B5JIS`、`hagakiCard`、`screen16x9`、`screen16x10`。省略 `type` 则不改该属性；没有 `sldSz` 则新建（插在 `sldIdLst` 之后、`notesSz` 之前）。
- 主题挂在 `scope.masters` 的每份母版上，字段 `theme`。没有 theme 关系则为 `null`。有则为对象，字段顺序：`name`、`colors`、`fonts`。`name` 取 `a:theme/@name`，没有则为 `null`。不算主题排版引擎。
- `colors` 字段顺序：`name`、`dk1`、`lt1`、`dk2`、`lt2`、`accent1`、`accent2`、`accent3`、`accent4`、`accent5`、`accent6`、`hlink`、`folHlink`。`name` 取 `a:clrScheme/@name`，没有则为 `null`。每个槽位：有 `srgbClr/@val` 取其原文；否则有 `sysClr/@lastClr` 取该原文；再没有则为 `null`。
- `fonts` 字段顺序：`name`、`majorLatin`、`minorLatin`、`majorEa`、`minorEa`、`majorCs`、`minorCs`。`name` 取 `a:fontScheme/@name`。其余取对应 `latin` / `ea` / `cs` 的 `typeface` 原文，没有该元素则为 `null`。
- `setThemeColors` / `setThemeFonts` 的 id 为 `master:{n}`。写该母版 `.rels` 指向的 theme 部件。不重写 `a:fmtScheme`。不把未点名槽位的 `schemeClr` 展开成 `srgbClr`。
- `setThemeColors` 可写上述十二个槽位，至少给一个。值为六位 RGB 十六进制。写入时把该槽位子元素换成 `a:srgbClr`（`dk1` / `lt1` 若原先是 `sysClr` 也改成 `srgbClr`）。
- `setThemeFonts` 可写 `majorLatin` / `minorLatin` / `majorEa` / `minorEa` / `majorCs` / `minorCs`，至少给一个。`majorLatin` / `minorLatin` 空串报 `InvalidField`。`ea` / `cs` 允许空串。没有对应元素则补上。
- 不写 theme `p:style`。`setShapeFill` 仍写六位 RGB，不写 theme 色。
- `create` 的 `presentation.slideSize` / `presentation.theme` 仍走待做 19。create 仍写 16:9、不写 `sldSz/@type`。
