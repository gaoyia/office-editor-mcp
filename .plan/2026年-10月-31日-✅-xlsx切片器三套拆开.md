# xlsx 切片器三套拆开

状态：✅ 已完成。
日期：2026-10-31

不在三种格式的待做表里，不占待做序号。这是 `.plan/2026年-10月-30日-✅-大文件按领域拆开.md` 文末「后续」表里的 `xlsx/slicer.rs`。领域 JSON 不变，写出的 XML 不变。

## 为什么要做

`crates/ooxp/src/xlsx/slicer.rs` 有 3594 行，里面是三套对象：

- 表格切片器：`insert_table`、`set_table_selected`
- 透视切片器：`insert_pivot`、`set_pivot_selected`，以及透视缓存定义上的 `x14:pivotCacheDefinition`
- 时间线：`insert_timeline`、`set_timeline_filter`

那份计划定的拆分标准是「一个文件里有两套互不调用的对象」，这里正好是三套，只共用 drawing 框、视图属性和缓存部件命名。

## 目标

- 拆成一个目录：共用部分（drawing `graphicFrame`、视图属性、缓存与部件命名、inspect 的公共字段）一份，三套对象各一份。
- inspect 与 apply 的入口函数名和签名不变，调用方不用改。

## 不做

- 不改切片器、时间线的语义与写出的 XML。
- 不支持 OLAP 切片器（契约写明本期不进树）。

### 2. 去向

`slicer/mod.rs` 留公开类型和入口：`insert`、`delete`、`set_size`、`set_anchor`、`set_view`、`set_filter`、`count`、`collect`。入口按来源把勾选分给表格或透视。

- `common.rs`：drawing `graphicFrame`、视图属性、缓存与部件命名、inspect 的公共字段
- `table.rs`：`insert_table`、`set_table_selected`，以及表格缓存和 `autoFilter`
- `pivot.rs`：`insert_pivot`、`set_pivot_selected`，以及透视缓存定义上的 `x14:pivotCacheDefinition`
- `timeline.rs`：`insert_timeline`、`set_timeline_filter`，以及日期换算
