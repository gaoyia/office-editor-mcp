## 契约（已锁）

Office 16.0：

- COM `Comment` / `Comments` 没有 `AddPicture` / `InsertPicture`。
- 在 `</p188:txBody>` 之后写裸 `<a:blip r:embed="…"/>`，comments `.rels` 指向 `/ppt/media/…`：打开无 Repair，另存仍留下 `a:blip`，不改写成 `p:pic`。
- 用幻灯片 commentRel uri 把图包进 `extLst`：文件损坏。不要用。
- 没有画布 `xfrm`。`setPictureSize` / `setPicturePos` 报 `InvalidId`。

inspect：沿用已过 9 的 id `{批注 id}/pic:{k}` / `{回复 id}/pic:{k}`，只认该宿主下（顶层不含 `replyLst`）带 `r:embed` 的 `a:blip`。不并进幻灯片 `pictureCount`。

apply：

- `insertPicture` 的 `id` 可以是 `slide:{n}`、`slide:{n}/notes`，或批注 / 回复 id。对图 id、形状 id、批注内图 id 或 `pptx:presentation` 仍报 `InvalidId`。往批注 / 回复插时不要 `x`/`y`/`cx`/`cy`。找不到该批注报 `IdNotFound`。对 `kind` 为 `ink` 报 `NotImplemented`。
- 写入位置：该 `p188:cm` 或 `p188:reply` 上，`txBody` 之后、`extLst` 之前一个 `a:blip r:embed="…"`。没有 `extLst` 则放在该宿主末尾。不写 `p:pic`。
- `replacePicture` / `deletePicture` / `exportMedia` 认批注内图 id。删图只摘 `a:blip`，批注文字留下。
- create 不写批注内图。

手测编号 **Pcip**。脚本 `manual-check/office/cases/pptx-comment-pics.ps1`。PowerPoint 16.0 Pcip1–Pcip5 已过。
