## 已锁定

- 根上始终有 `theme`，不要另给 scope。来源是 workbook `.rels` 里 Type 以 `/theme` 结尾的部件。没有则为 `null`。
- 有部件时字段顺序与 docx 66 对齐：`name`、`colors`、`fonts`、`fmt`、`extraSchemes`。取值规则照抄 `crates/ooxp/src/theme.rs`，并加上 docx 66 的脚本字体与补充色板。
- `fonts` 在 `minorCs` 之后加 `majorScripts`、`minorScripts`。数组按 `a:font` 文档顺序。每项字段顺序：`script`、`typeface`。没有则为 `[]`。
- `extraSchemes` 取 `a:extraClrSchemeLst/a:extraClrScheme`。没有列表则为 `[]`。每项字段顺序：`name`、`colors`。`colors` 规则与主 `clrScheme` 相同。
- 根上始终有 `themeOverride`，放在 `theme` 之后。没有 Type 以 `/themeOverride` 结尾的关系则为 `null`。
- `setThemeColors` / `setThemeFonts` / `setThemeFmt` / `setThemeOverride` 的 id 必须是 `xlsx:workbook`。写入规则与 docx 相同，并收 docx 66 那组可选 `name` / `themeName` / 脚本列表。没有 theme 时前三条报 `IdNotFound`，不新建。`setThemeOverride` 缺则新建 `/xl/theme/themeOverride1.xml`。
- 新 op `setThemeExtraSchemes`。id 必须是 `xlsx:workbook`。值为数组，整份替换。`[]` 或 `null` 去掉 `extraClrSchemeLst`。
- create：`workbook.theme` 可选。省略则仍不写 theme 部件。
- 不改 `styles.xml` 里格子的 `theme` 指数。docx / pptx 的 id 规则不变。
- 手测编号 **Xth**。脚本 `manual-check/office/cases/xlsx-theme.ps1`。不要和 Th、Ts、Xtf 撞。
