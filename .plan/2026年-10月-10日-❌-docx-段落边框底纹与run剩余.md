## 已锁定

- 只读该 `w:p` 自己的 `w:pPr`、该 `w:r` 自己的 `w:rPr`。缺元素为 `null`，不猜规范缺省。
- 段上在 `spacing` / `eastAsia` 之后增加 `borders`、`shd`、`tabs`。都没有则为 `null`。
- `borders` 字段顺序：`top` / `left` / `bottom` / `right`。每边与页面边框同一套 `val` / `sz` / `space` / `color`。`null` 删掉该边。
- `shd` 对象：`fill` 为六位 RGB。没有 `shd` 为 `null`。不解析 theme。
- `tabs` 为数组，按 `w:tab` 文档顺序。每项 `val`（`left` / `center` / `right` / `decimal` / `bar`）与 `pos`（twip）。空数组与缺元素都当 `null`。
- `setParaFormat` 增加可选 `borders` / `shd` / `tabs`（对象或 `null` 删掉）。与原有字段至少给一个。id 仍是任意故事段落 id。
- `scope.runs` 在 `eastAsianLayout` 之后增加 `highlight`、`strike`、`dstrike`、`vertAlign`。
  - `highlight` 取 `w:highlight/@w:val`，没有为 `null`
  - `strike` / `dstrike` 取对应 OnOff，没有元素为 `null`
  - `vertAlign` 取 `w:vertAlign/@w:val`（`superscript` / `subscript` / `baseline`），没有为 `null`
- `setRunFormat` 增加同样四个可选字段；`null` 删掉对应元素。id 仍是 run id。
- 不要 `keepNext`、`widowControl`、`pageBreakBefore`、`vanish`、`spacing`（字符间距）、`kern`。那些不算本切片。
- create 本期不写这些字段，见待做 56。
- xlsx / pptx 上发这些新字段报 `UnknownField` 或 `InvalidField`（与现有 `setParaFormat` / `setRunFormat` 分工一致）。
- 手测编号 **Bd** / **Rh**。脚本 `manual-check/office/cases/docx-para-run-remain.ps1`。不要和 Pb、Pf、Ea、Th 撞。
