## 已锁定

- 直接格式写在段或 run 上，不要为了改加粗去改样式定义（那是样式计划）。
- `setParaText` 的「整段变单一 run 但加粗还在」继续成立；新 op 才做精细 run 切分。
- 单位 twip / 半磅，与现有距离字段一致。
- 段上只读该 `w:p` 自己的 `w:pPr`，不把 `styles.xml` 摊进来。
- run 作为树上节点：id 为 `{段落 id}/run:{n}`，`{n}` 从 1 起，按该段内被收入的 `w:r` 文档顺序（遇 `w:txbxContent` 停住；`mc:AlternateContent` 只进 Choice；`w:del` 里的 run 不编）。增删 run 之后 `{n}` 会变。
- `scope.runs` 为 true 时，已切出的段落（及已展开的页眉页脚 / 框内 / 注内 / 批注内段）带 `runs`。省略则只有 `runCount`。xlsx / pptx 的 `scope.runs` 报 `InvalidField`。
- apply `setParaFormat` 的 id 是段落 id（正文、页眉页脚、框内、注内、批注内均可）。`setRunFormat` 的 id 是 run id。
