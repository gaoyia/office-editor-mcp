- 错误 JSON 不加 `allowed` / `hint` / `doc`。
- help 仍只展开一层。不提供 `depth=all`。试用目录不附 `docs/` 和示例。正式压缩包仍是可执行文件加 `LICENSE`。
- `initialize` 里的许可义务、困境和捐赠图留在输出里。
- 不按 `format` 裁剪 op 的 limits。同一条说明仍可以写别的格式会怎样。

## 要改什么

### 1. 单元格样式

`xlsx` create 格子的 `font`、`fill`、`border`、`align` 引用 `#/$defs/setCellStyleOp/properties/font` 这一类路径。help 缩短时只留下定义名 `setCellStyleOp`。打开 `xlsxSheetCreate` 就会看到整条 op，并带上必填的 `op` 和 `id`。运行时接受的是样式对象，没有这两项。

以 `setCellStyleOp` 里现有的四份字段为正文，抽成 `cellFont`、`cellFill`、`cellBorder`、`cellAlign`，与已有的 `cellColor` 并列。`setCellStyleOp` 和 create 格子都改成引用这四份。`cell.json` 里另一处相同结构一并改成引用，不留两份。

缩短后的 `$ref` 是 `cellFont` 这类名字。`name=cellFont` 看不到 `op` 和 `id`。`name=xlsxCellCreate` 仍能看到 `color` 和 `fg`。字段名仍是 `fg`。

不改 `help.rs` 的一层展开。`ref_def_name` 仍只取定义名。测试里现在写死 `$ref` 等于 `setCellStyleOp` 的断言改成新名字。

### 2. 填充对象

`shapePaintObject` 把 `color`、`stops`、`ang`、`file` 放在同一层。`type` 为 `grad` 时再带 `color`，`pptx/request/shape.rs` 的 `parse_paint_object` 会报不认识的字段。pptx 分册 `setShapeFill` 已经按类型写了允许的字段。schema 还没分开。

`shapePaint` 外层保持现在的三种形状：`null`、六位颜色字符串、对象。对象改成按 `type` 的 `oneOf`，与解析器的允许名单一致：

- `solid`：必须有 `color`，可选 `alpha`
- `grad`：必须有 `stops`，可选 `ang` 和 `alpha`，不收 `color`
- `blip`：必须有 `file`，不收 `alpha`

不改解析器，不改写出的 XML。`help name=shapePaint` 要能看出这三支，而不是把 `color` 写成各种 `type` 都能带。

### 3. 三处缺省

分册已经写了，schema 的字段上没有说明，help 因此看不出来。只加 `description` 和 `descriptionEn`，不改校验：

- `docxChartCreate.kind`：省略时为 `anchor`，绕排为 `square`。与 docx 分册 `paragraphs[].charts` 同一句。
- `docxTableCreate.style`：值是 `style:` 加上 `styleId`，不是样式的显示名。与分册 `tables[].style` 同一句。
- `docxTableCreate.after`：从 1 起，表插在该段之后。`0` 表示插在第一段之前。省略则插在全部段落之后。与分册 `tables[].after` 同一句。

### 4. create 的 path

`inspectRequest`、`applyRequest` 的 `required` 已经包含 `path`。`createRequest` 的 `required` 只有 `action`，`path` 写在 `comment` 里。省略 `path` 时运行时已经报缺少 `path`。

把 `path` 放进 `createRequest` 的 `required`。三种正文的 `oneOf` 保持不动。`comment` 可以留下。

### 5. 命令行帮助

`docs/cli.md` 已经写了标准流、退出码、`locale` 高于 `--lang` 再高于 `OOXP_LANG`、`ooxp mcp`，以及一行一条和 `Content-Length` 两种帧。`--help` 只有 `--input`、`--lang`、`--pretty`。没有 `--version`。

在 `crates/ooxp-cli` 的 clap 说明里补上这些已有约定，并打开 `--version`，版本来自 `CARGO_PKG_VERSION`。`mcp` 仍在进入 clap 之前拦截，不改成子命令。`ooxp --version` 能打出版本号。`docs/cli.md` 的调用一节加上 `--version`。帧格式那一节已经够用，不重写。
