# xlsx 工作表图表

状态：✅ 库测试与 Excel 16.0 手测 Xc1–Xc7 已过  
日期：2026-09-27

从 `.plan/2026年-9月-27日-❌-xlsx-图与图表路线.md` 拆出序号 1。工作表上的图表不是 `xdr:pic`，也不是 Word 那种 embedding 工作簿。本期编 SpreadsheetDrawing 的 `xdr:graphicFrame` 和 `/xl/charts/chartN.xml`，数据写回本工作簿单元格。不画图、不求值公式。

规范线索：工作表或图表工作表经 drawing 指向 `xdr:graphicFrame`（ECMA-376 §20.5.2.16）。`a:graphicData/@uri` 为 chart URI 时，关系指向 `/xl/charts/chartN.xml`（§21.2）。系列公式在 `c:f`，指向本包单元格；`c:numCache` / `c:strCache` 是缓存。图表工作表（`chartsheet`）上的那张框走同一套图表 id，不另编图 id。

契约真源：`docs/json-contract.md`、`docs/json-schema/request.schema.json`、`docs/errors.md`、`docs/architecture.md`、`docs/opc.md`、`docs/checklist-xlsx.md`。

## 目标

工作表和图表工作表上的 DrawingML 图表能列，能改标题、系列、类型、轴标题、图例与标签，能插、能删，能改 `oneCell` / `absolute` 的尺寸与锚点。Excel 打开时自己重画。数据以本工作簿单元格为准，同时回写 cache。

本期不按全量验收。当前能交的只是表里标着要做、且当期已 ✅ 的编号。

## 已锁定（写入契约后不要改）

- 图表 id：`sheet:{name}/chart:{cNvPrId}`。`{cNvPrId}` 取该 `xdr:graphicFrame` 里 `xdr:nvGraphicFramePr/xdr:cNvPr/@id` 的原文，匹配规则与工作表图相同。没有该属性时用 `sheet:{name}/chart:index:{k}`，`stable` 为 `false`。`{k}` 只在该表全部 drawing 部件内从 1 计，只计入被收入的图表。`{name}` 规则与现有工作表 id 相同。
- 系列 id：`{图表 id}/series:{idx}`。`{idx}` 从 0 起，按 chart 部件里 `c:ser` 的文档顺序，不跟 `c:idx/@val`。
- 只认锚点的直接子元素 `xdr:graphicFrame`，且 `a:graphicData/@uri` 为 `http://schemas.openxmlformats.org/drawingml/2006/chart`（可带尾斜杠）。chartex URI 列入，`type` 为 `chartex`。组合 `xdr:grpSp` 里的框、`xdr:pic`、形状、SmartArt、OLE、VML 不进 `charts`。`mc:AlternateContent` 只进第一个 `Choice`。
- 工作簿根始终有 `chartCount`，等于各 `worksheet` 与 `chartsheet` 的 `chartCount` 之和。每张 `worksheet`、每张 `chartsheet` 始终有 `chartCount`。`dialogsheet` 没有这个字段，也没有 `pictures`。
- 名单只在 `scope.charts: true` 时出现，挂在对应表上，不挂在工作簿根上。不依赖 `sheet` / `range` / `pictures`。不把 chart 部件或媒体字节塞进树。
- `categories` / `values` / `sizes` 优先取 `c:f` 指向的单元格缓存值（与 inspect 单元格同一套 `<v>`）；读不到再退回 chart 的 cache / lit。单元格值与 chart cache 不一致时该系列 `cacheStale: true`。另报 `nameRef` / `catRef` / `valRef`，气泡再报 `sizeRef`，取 `c:f` 原文；没有公式则为 `null`。
- `setChartSeries` 仍收数组。有可解析的连续 A1 `c:f` 时：把数组写入这些格子，点数变了就按原起点扩或收公式区域，并回写 cache。命名区域、三维引用、不连续区域报 `NotImplemented`。没有 `c:f`（只有 lit）时只改 lit / cache，不新造单元格区域。不在库里求值公式。
- `addChartSeries`：能从已有系列的 `c:f` 推出右侧相邻空列则写入；推不出报 `NotImplemented`。`deleteChartSeries` 只删 `c:ser`，不删单元格。删光系列报 `InvalidField`。
- `insertChart` 的 `id` 必须是 `sheet:{name}`，且该表 `kind` 为 `worksheet`。必须给 `from` 与 `dataFrom`。`dataFrom` 是写到该表上的数据表左上角（第 1 行系列名，第 1 列分类，数值向右）。按 `setCell` 语义覆盖已有格子。`c:f` 指向这些格子。不写 embedding。`anchor` / 尺寸字段与 `insertPicture` 相同。`kind` / `wrap` 在 xlsx 上报 `InvalidField`。
- 对 `chartsheet` / `dialogsheet` 发 `insertChart` 报 `InvalidField`。不新建图表工作表。
- `deleteChart` 删掉包含该 `xdr:graphicFrame` 的整个锚点；drawing 删空后的清理与删图相同。不删数据单元格。chart 部件无人引用则删。对图表工作表上那张（或仅剩一张）图表发 `deleteChart` 报 `NotImplemented`（会留下空的 chartsheet）。
- `setChartWrap` 仍是 Word 绕排，xlsx 上报 `InvalidField`。改锚点走新 op `setChartAnchor`，字段与 `setPictureAnchor` 相同，`id` 必须是图表 id。docx / pptx 上发 `setChartAnchor` 报 `InvalidField`。
- `setChartSize` 只改 `oneCell` / `absolute` 的 `xdr:ext`（以及存在的 `a:xfrm/a:ext`）。对 `twoCell` 报 `NotImplemented`。
- 类型、组合图、透视、次轴、趋势线、误差线、chartex 的限制与现有 docx 图表 op 相同。xlsx 上受限图除 `deleteChart`、`setChartSize`、`setChartAnchor` 外报 `NotImplemented`。
- 改单元格（含插图写下的数据表、改系列写入的格子）走与 `setCell` 同一套重算标记：`fullCalcOnLoad`，必要时删 `calcChain`。
- `create` 带图表见 `.plan/2026年-9月-27日-✅-xlsx-create带图表.md`。`exportChartData` 在 xlsx 上仍报 `InvalidField`（数据就在本工作簿里）。pptx 的 `scope.charts` 与图表 op 仍报 `InvalidField`。
- 页眉页脚里的图表、组合里的图表本期不进树。

## 不做

- 新建或删除图表工作表（另开，见 `.plan/2026年-9月-27日-❌-xlsx-图表工作表.md`）
- 改透视源、刷新透视缓存

- create 带图表（另开，见 `.plan/2026年-9月-27日-✅-xlsx-create带图表.md`）

## 验收

手测编号 Xc1–Xc7，写入 `docs/checklist-xlsx.md`。脚本建议 `manual-check/office/cases/xlsx-charts.ps1`。源文件必须是 Excel 亲手另存，至少一张工作表柱形图，系列公式指向本表单元格。不要用库 `create` 产物当带图样例。

Excel 16.0 插入的图通常是 `twoCellAnchor`。真 `oneCell` 由 `insertChart` 或 `setChartAnchor` 写入后再让 Excel 打开。

- Xc1：无 `charts` 时有 `chartCount`、没有名单；`charts: true` 时 id 为 `sheet:…/chart:…`，`type` / 系列值与工作表一致。
- Xc2：`setChartSeries` 后 Excel 无修复，单元格与图上的值都是新值。
- Xc3：`insertChart` 往 `worksheet` 插图，Excel 能看见且无修复；`dataFrom` 一带有数据表。
- Xc4：`deleteChart` 后该图消失，数据单元格还在，无修复。
- Xc5：`setChartType` 改为折线后按折线显示（允许样式重置），无修复。
- Xc6：对 `oneCell` `setChartSize` 或 `setChartAnchor` 后位置或尺寸对上，无修复。
- Xc7：`exportChartData` 打到 xlsx 上得到 `InvalidField`。不强制开 Excel。
