## 目标

inspect 给出工作表级排序状态。apply 能写入或删除 `<sortState>`。Excel 打开能看见排序字段。库不把格子按值重排。

## 已锁定（写入契约后不要改）

- 排序挂在工作表节点上的 `sortState`，不另编 id。不进 `view`，也不进 `autoFilter`。
- 每张 `worksheet` 始终有 `sortState`。没有 `<sortState>` 则为 `null`。`chartsheet` / `dialogsheet` / `macrosheet` 没有此项。
- 工作表字段：`autoFilter` 之后始终跟 `sortState`，再跟 `outline`。
- `sortState` 对象字段顺序：`ref`、`caseSensitive`、`columnSort`、`columns`。`ref` 取 `@ref`，能解析则规范化成 `A1` 或 `A1:B2`。`caseSensitive` / `columnSort` 取同名属性，缺省 `false`。`columns` 按 `<sortCondition>` 文档顺序。每项：`ref`、`descending`。`descending` 缺省 `false`。不报 `customList` / `dxfId` / `iconId` / `iconSet` / `sortBy` / `sortMethod`。
- `setSortState` 的 `id` 必须是 `sheet:{name}`，且该表 `kind` 为 `worksheet`。必须给 `ref`。`ref` 为 `null` 时删掉 `<sortState>`，不要出现 `columns`。`ref` 为范围时必须给非空 `columns`。每项必须给 `ref`，且该范围必须落在 `sortState/@ref` 内。`descending` 可选，缺省 `false`。`caseSensitive` / `columnSort` 可选，缺省 `false`；为真才写属性。整段替换已有 `<sortState>`，不保留未点名的 `sortCondition`。
- 不重排 `sheetData`，不隐藏行，不求值。不改表格部件里的排序。不写 `x14` 扩展排序。出现 `customList` / `sortBy` / `sortMethod` / `dxfId` 报 `InvalidField`。
- 对 `chartsheet` 报 `InvalidField`。对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。docx / pptx 上发此 op 报 `InvalidField`。不标重算。create 本期不写排序。
- 手测编号 **Xsr**，脚本 `manual-check/office/cases/xlsx-sort.ps1`。

## 不做

- 按值重排单元格
- 自定义序列、按颜色 / 图标排序
- 表部件上的排序
- 拼音 / 笔画 `sortMethod`

## 验收

手测编号 Xsr1–Xsr5。Excel 16.0：`xlsx-sort.ps1`，5 PASS / 0 FAIL。COM `Sort.SortFields.Count=1`、`Order=2`（降序）、键 `$A$1:$A$3`；A1 仍为 3。

- Xsr1：create 产物 `sortState` 为 `null`。
- Xsr2：`setSortState` 后 inspect `ref` 与 `columns[0].descending` 对上；Excel 无修复。
- Xsr3：COM `Sort.SortFields` 能看见对应列。
- Xsr4：`ref: null` 后 `sortState` 为 `null`，无修复。
- Xsr5：缺 `ref` 或列范围越界得 `InvalidField`，未写文件。
