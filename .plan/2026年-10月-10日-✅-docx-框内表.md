## 已锁定

- 只做文本框故事。注内 / 批注内的表仍不编。框内再套框保持 🚫。
- 框内表 id 带框前缀，例如 `{框 id}/table:{n}`。`{n}` 是该框 `w:txbxContent` 里 `w:tbl` 的文档顺序，从 1 起。
- 单元格段落仍一次倒出，规则与正文表相同。
- `insertTable` 的 id 允许框内段落 id（插到该 `w:p` 之后）或框 id（插到该框内容末尾）。已有框内表 id、框内单元格 id 同样允许（嵌套表）。
- 嵌套表插在该格 `tcPr` 之后、已有段落之前。格末仍保留至少一个 `w:p`。接到格尾会让 Word 16.0 报无法读取。不算自动列宽。
- `deleteTable` / 行列表结构 / `setTableStyle` / `setTableFloat` / `setTableCellMar` / `setCellFormat` 允许框内表 id 与单元格 id。
- 根上 `tableCount` 仍只计正文；框节点另报 `tableCount`。`scope.tables` 为 true 时框上带 `tables`。
- 框内表带修订痕迹时结构 op 仍报 `NotImplemented`。
- xlsx / pptx 不要带 Word 框内表字段。
- 手测编号 **Bx**。脚本 `manual-check/office/cases/docx-box-table.ps1`。不要和 Bb、Tf、T 撞。

Word 16.0 手测 Bx1–Bx5 通过。无 Repair。COM 框内 `Tables.Count=1`。
