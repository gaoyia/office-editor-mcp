对应 `roadmap/pptx.md` 待做序号 **47**。前置：`.plan/2026年-9月-29日-✅-pptx-主题与幻灯片尺寸.md`。不要和 46 的 `fmtScheme`、48 的备注 / 讲义 theme 部件合成一份。不算主题排版引擎。

slideMaster、notesMaster、handoutMaster 都有 `p:clrMap`。幻灯片、版式、备注页有 `p:clrMapOvr`。页上还可挂 `themeOverride` 部件。inspect 都不报这些。docx 的 `setThemeOverride` 只认 `docx:document`。xlsx 上页级覆盖不套。

## 目标

各宿主 `clrMap`、页 / 版式 / 备注页的 `clrMapOvr`、以及页上的 `themeOverride` 部件能 inspect、能 apply。不把映射结果算成最终 RGB。

## 已锁定

- inspect：`masters[]` 在 `theme` 之后加 `clrMap`。对象十二键与 `p:clrMap` 属性同名：`bg1`、`tx1`、`bg2`、`tx2`、`accent1`–`accent6`、`hlink`、`folHlink`。值为 theme 槽名原文。缺元素则为 `null`。
- `scope.notesMaster` / `scope.handout` 为 true 时，对应对象同样加 `clrMap`。
- 每页、每份版式、每份备注页加 `clrMapOvr`：`master`（有 `a:masterClrMapping`）或对象（与 `clrMap` 相同）。缺则为 `null`。
- 每页与每份备注页加 `themeOverride`。来源是该宿主 `.rels` 里 Type 以 `/themeOverride` 结尾的部件。没有则为 `null`。有则字段与 docx `themeOverride` 相同。
- 新 op `setClrMap`。id 必须是 `master:{n}`、`notesMaster` 或 `handout`。十二槽可选，至少给一个。值为已有 theme 槽名。不认识的令牌报 `InvalidField`。
- 新 op `setClrMapOvr`。id 必须是 `slide:{n}`、`slide:{n}/notes` 或 `master:{n}/layout:{k}`。值为 `"master"`（写成 `a:masterClrMapping`）或十二槽对象。
- `setThemeOverride` 的 id 增加 `slide:{n}` 与 `slide:{n}/notes`。缺部件则新建 `/ppt/theme/themeOverrideN.xml` 并挂该宿主关系。`enabled: false` 删掉这条关系与无人引用的部件。
- docx / xlsx 上发 `setClrMap` / `setClrMapOvr` 报 `InvalidField`。
- 手测编号 **Tcm**。脚本 `manual-check/office/cases/pptx-theme-clrmap.ps1`。不要和 Ts、Tfm、Pcm、Tc 撞。
