## 已锁定（写入契约后不要改）

- 真源是工作表 `<hyperlinks>/<hyperlink>`（ECMA-376 §18.3.1.47 / §18.3.1.48），不是单元格上的属性，也不是 `HYPERLINK()` 公式。
- 名单挂在该 `worksheet` 上，不挂在单元格节点上。每张 `worksheet` 始终有 `hyperlinkCount`。工作簿根上 `hyperlinkCount` 为各表之和。`scope.hyperlinks: true` 时该表带 `hyperlinks`，不依赖单元格切片。
- id：`sheet:{name}/link:{n}`。`{n}` 从 1 起，按该表 `<hyperlink>` 的文档顺序。增删之后序号会变。
- `insertHyperlink` 的 id 必须是 `sheet:{name}`，必填 `ref`（A1 或闭区间）。`url` 与 `location` 至少给一个，可以同时给（外部目标加靶内位置）。`text` / `anchor` 在 xlsx 上报 `InvalidField`。显示字走 `setCell`。可选 `tooltip`、`display`。
- `setHyperlink` / `deleteHyperlink` 的 id 必须是超链接 id。xlsx 的 `setHyperlink` 认 `url` / `location` / `tooltip` / `display` / `ref`，不认 `text` / `anchor`。
- 外部链：工作表 `.rels` 上 Type 以 `/hyperlink` 结尾、`TargetMode` 为 `External`。内部链只写 `location`，不写关系。删链或改成无 `r:id` 时清孤儿关系。
- `ref` 与已有链的单元格相交报 `InvalidField`。
- 对 `chartsheet` 发超链接 op 报 `InvalidField`。对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。
- `create` 本期不写超链接。`sheets[]` 出现 `hyperlinks` 报 `UnknownField`。
- 不编辑 VML；不打开浏览器；不发送邮件。
