# 幻灯片多行文本布局近似

状态：✅ 已完成（布局近似，不保证文字逐像素一致）

日期：2026-11-16

验收来源：用户本轮明确更改（对话 t66u）：「接近的方案解决后把这个收为已完成并作为结论」。范围只及 `pptx-preview-fill-image` 的 `multiline`（多行文本）子项，以及同一套形状/表单元格文字排版。不把 alpha-grad、shape-grad 或整份幻灯片出图标完成，不改变渐变或官方像素对照的 MaxDelta=0。

对应 `.plan/2026年-11月-14日-⚠️-pptx-幻灯片出图.md`，以及补齐清单第 3 段里这一档官方用例。C25 第 0 段「字形灰度暂缓」仍然有效；其它带字页、占位符并不是差 0。

## 做法

幻灯片独立路径 `Face::draw_slide`：基线 = 内边距顶边 + Windows `tmAscent`，再用 GDI `GetGlyphOutline` 灰阶落点。未写 `lnSpc` 时行距仍是 1.2 倍字号。图表共用的 typographic `Face::draw` / `draw_gdiplus` 不改。

## 验收（已量化）

- 单元测试：`slide_text_first_ink_follows_windows_cell`、`slide_multiline_layout_follows_windows_cell_and_120_pitch`。`cargo test -p ooxp --lib --test pptx_slide_image` 与 `cargo clippy -p ooxp --all-targets -- -D warnings` 通过。
- 对照本机 PowerPoint 16.0 `Slide.Export` 金图（alpha-ml-probe，12/18/24/36/48/72 磅 Calibri 单行与两行；官方 `pptx-preview-fill-multiline`，36 磅两行）：

| 项 | 结果 |
| --- | --- |
| 行距 1.2 倍字号 | 19/29/38/58/77/115，与金图一致 |
| 首墨 12/18/24 磅 | 相对内边距顶边 5/7/9，与金图一致；左右偏移也一致 |
| 首墨 36/48/72 磅 | 比金图低 1 像素（15/20/30 对 14/19/29）。官方 multiline 用例同样是首墨 +1。48 磅另有水平偏移 +1 |
| 单行与两行的第一行 | 同一套首墨，不是多行第一行的单独错误 |
| 字形灰阶 | 不保证逐像素一致。官方 multiline 新导出相对金图 `differ=1866`、`maxDelta=255`（旧 typographic 路径是 `differ=1801`、`maxDelta=255`）。官方 `pptx-preview-fill-multiline-px` 在 MaxDelta=0 下仍会失败，这是已记录的残余，不靠放宽容差算通过 |

最终结论：布局近似，不保证文字逐像素一致。
