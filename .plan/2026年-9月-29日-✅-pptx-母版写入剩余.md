## 已锁定（实现时不要改）

- 新 op，不把 `insertShape` / `deleteShape` 扩到母版。幻灯片上的 `insertShape` 仍不抄版式占位符。
- `insertLayout` 的 id 为 `master:{n}`。写出一份空白版式（`type="blank"` `preserve="1"` `clrMapOvr`），关系与 `sldLayoutId` 按另存补。可选 `name`。
- `deleteLayout` 的 id 为 `master:{n}/layout:{k}`。有任何页的 `layoutId` 指向它则报 `InvalidField`。至少留一份版式。
- `insertPlaceholder` 的 id 为 `master:{n}` 或 `master:{n}/layout:{k}`。写出带 `p:ph` 与 `p:txBody` 的 `p:sp`。`type` 白名单待文档写死。`title` / `ctrTitle` 不写 `idx`；其它类型取该宿主已有最大整数 `@idx` 加 1，没有则写 `10`。不写 `stCxn`、不写 theme `p:style`、不写 `a16:creationId`。`type` 白名单：`title`、`body`、`ctrTitle`、`subTitle`、`dt`、`ftr`、`sldNum`。
- `deletePlaceholder` 的 id 为已有占位符 id。只删该 `p:sp`。不改各页 XML。
- `insertMaster` 的 id 为 `pptx:presentation`。可选 `from`（`master:{n}`），省略则抄 `master:1`。抄该母版及其全部版式与 theme 部件，新开 master / layout / theme 部件。不生成新的占位符几何。
- `deleteMaster` 的 id 为 `master:{n}`。最后一份母版或仍有页用其版式则报 `InvalidField`。
- 装饰形（没有 `p:ph`）仍不进树。备注母版本期不写。
- `create` 的 `presentation.masters` 仍走待做 19。
