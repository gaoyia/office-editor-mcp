# 条件格式差分虚线与斜点划线

状态：❌
日期：2026-11-16
分类：功能缺失

对应 C25 第 11 段，序号 **84**。公式差分的细线、中等、粗线、点线、发丝、双线和点划线已差 0。`dashed` 的竖向相位、`slantDashDot` 的末端还没和 Excel 对齐，因此整表不做，见 `.plan/2026年-11月-16日-✅-xlsx-公式差分点线双线.md`。

## 目标

差分边框为 `dashed` 或 `slantDashDot` 时，与 Excel 16.0 差 0。对不上继续失败，不加大容差。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 对照竖向虚线相位和斜点划线末端 | ❌ |
| 1 | 只画能差 0 的那一种，另一种可留待下一刀 | ❌ |
| 2 | 手测差 0 | ❌ |

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS

- 不重做已差 0 的点线、发丝、双线和点划线差分
