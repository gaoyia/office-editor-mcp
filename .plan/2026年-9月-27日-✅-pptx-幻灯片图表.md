## 目标

幻灯片上的嵌入图表能列、改标题、改系列、增删系列、改类型、改轴标题与图例，能插、能删，能改画布尺寸与坐标。`exportChartData` 写出 embedding。PowerPoint 打开时自己重画。

圆环、雷达、气泡、组合图跟 docx 扩展图表同一套限制，不要再拆一期。透视图表只改标题、图例、标签、删除与尺寸位置，不改数。

## 已锁定（写入契约后不要改）

- 图表 id：`slide:{n}/chart:{cNvPrId}`。`{cNvPrId}` 取 `p:nvGraphicFramePr/p:cNvPr/@id`。没有则 `slide:{n}/chart:index:{k}`，`stable` 为 `false`。系列：`{图表 id}/series:{idx}`，规则与 docx 相同。
- 只认 `p:graphicFrame` 且 URI 为 chart（可带尾斜杠）。chartex 列入，`type` 为 `chartex`。`p:pic`、表格、SmartArt 不进 `charts`。组合里符合条件的框要展开。
- 根上 `chartCount` 等于各页之和。每页始终有 `chartCount`。名单只在 `scope.charts: true` 时出现，挂在对应页上。不依赖 `scope.slide`。
- 现行契约里 pptx 的 `scope.charts` 与图表 op / `exportChartData` 报 `InvalidField`。本期改成认它们。
- 改数据必须同时改 cache 与 embedding（有则改）；以 embedding 为准，不一致则 `cacheStale: true`。不在库里求值。
- `insertChart` 的 `id` 必须是 `slide:{n}`。必须给 `type`、`series`。`from` / `to` / `dataFrom` / `anchor` 是 xlsx 字段，pptx 上报 `InvalidField`。`kind` / `wrap` 是 Word 字段，pptx 上报 `InvalidField`。可选 `x` / `y` / `cx` / `cy`。新建 chart、`.rels`、最小 embedding，不写本演示文稿里的工作表。
- `setChartSize` 写 `a:ext`。`setChartPos` 写 `a:off`。`setChartWrap` / `setChartAnchor` 仍报 `InvalidField`。
- 类型、组合图、透视、次轴、趋势线、误差线、chartex 的限制与现有 docx 图表 op 相同（含圆环 / 雷达 / 气泡 / 组合图已放开的那些）。
- `create` 带图表另开。xlsx 的 `exportChartData` 仍拒绝。
