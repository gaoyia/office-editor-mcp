样例：`tmp/c15-probe/open/` 另存稿，基线在 `before/`。截图在同一 `open/`。

立方体页「模型旋转 / 摄影机」对应 `am3d:camera` 与 `am3d:trans/am3d:rot`。五边形页「光源」对应 `am3d:spPr` 里的 `a:scene3d/a:lightRig`，**不是** `am3d:ambientLight` / `am3d:ptLight`。后两者插入后一直是 C7 缺省，三家另存都没改。

光源角度 300° 只在 Word 里动手改过，另存为 `lightRig.rev=18000000`（`rig=freezing`，`dir=t`）。Excel / PowerPoint 这次没改，所以包里没有 `a:scene3d`，inspect 为 `null`。这不是「只有 Word 有光源」。三家 `am3d:spPr` 同一套 DrawingML，`setModel3dCamera` 的 `lightRig` 三家都认。新建时的 `rig` / `dir` 缺省也用 Word 这次写出的 `freezing` / `t`。

旋转三家都写到 `am3d:rot/@ax @ay @az`（六万分之一度）。空 `<am3d:rot/>` 表示未转。摄影机位置 / 观察目标点写 `am3d:camera` 的 `pos` / `lookAt`，单位是 XML 整数（界面 1.0 = 36000000）。视野写 `perspective/@fov`（六万分之一度；缺省 `2700000` = 45°，Word 截图 31.5° = `1892375`）。`up` 另存未改，仍是 `dy=36000000`。

`preTrans` / `scale` / `postTrans` 另存未改。摄影机位移不是这两段。不要把经纬度换算成 `pos`。

PowerPoint「大小 / 位置」、Excel「大小 / 随单元格」是画布几何，见 C12，不进 C15。填充、线条、阴影、发光、柔化边缘、文本框、五边形页「三维旋转」不进 C15。Word 另存把 `objViewport` 换成空的 `winViewport`，当实现细节，不进树。

## 已锁定

- inspect 在现有 `model3ds[]` 键顺序里、`hyperlink` 之前插入：`camera`、`rot`、`lightRig`。
- `camera` 始终是对象。字段顺序：`pos`、`up`、`lookAt`、`fov`。
- `pos` / `lookAt` 字段顺序 `x`、`y`、`z`，取对应属性，能解析成整数则写整数，否则 `null`。
- `up` 字段顺序 `dx`、`dy`、`dz`，规则相同。
- `fov` 取 `am3d:perspective/@fov`，能解析成非负整数则写整数，否则 `null`。
- `rot` 始终是对象。字段顺序：`ax`、`ay`、`az`。取 `am3d:rot` 对应属性；缺属性或没有 `am3d:rot` 则为 `null`。
- `lightRig` 取 `am3d:spPr/a:scene3d/a:lightRig`。没有则为 `null`。有则字段顺序：`rig`、`dir`、`lat`、`lon`、`rev`。
- `rig` 取 `@rig` 原文，缺则为 `null`。`dir` 取 `@dir` 原文，缺则为 `null`。
- `lat` / `lon` / `rev` 取子元 `a:rot` 对应属性，能解析成整数则写整数，否则 `null`。没有 `a:rot` 则三项都是 `null`。
- 不把 `am3d:ambientLight` / `ptLight` 放进树。插入仍抄 C7 缺省。
- 不把 `preTrans` / `scale` / `postTrans` / `meterPerModelUnit` 放进树。
- 新 op `setModel3dCamera`。id 必须是 3D 模型 id。可给 `camera` / `rot` / `lightRig`，至少给一个。未点名留下。
- `camera` 为对象。可给 `pos` / `up` / `lookAt` / `fov`。子对象只写点名的轴；未点名留下。`fov` 为非负整数。
- `rot` 为对象。可给 `ax` / `ay` / `az`，值为整数。未点名留下。没有 `am3d:rot` 时先补空元素再写属性。
- `lightRig` 为对象或 `null`。`null` 去掉 `a:scene3d`（因而去掉 lightRig）。对象可给 `rig` / `dir` / `lat` / `lon` / `rev`。写任一项时若还没有 `a:scene3d`，补 `a:camera prst="orthographicFront"` 再写 `a:lightRig`。新建 lightRig 时：未给的 `rig` 为 `freezing`，未给的 `dir` 为 `t`，未给的 `a:rot` 轴为 `0`。已有 lightRig 则只改点名项。docx / xlsx / pptx 同一套规则。
- create / insert 不增加这些 JSON 字段。缺省 XML 仍抄 C7。inspect 得到缺省 `camera`（`pos.z=66519324`，`fov=2700000`）、`rot` 三轴 `null`、`lightRig` `null`。
- 手测编号 **D3c** / **X3c** / **P3k**。pptx 格属性已占用 P3c。不要和 D3d / D3g、X3d / X3g、P3d / P3g 撞。
