# docx 内容控件数据绑定与重复节

状态：❌ 未开始。
日期：2026-10-31

对应 `roadmap/docx.md` 待做序号 **72**。前置：内容控件（22）已过。先探测：Word 16.0 不支持的部分标 🚫。

## 现状

`docs/json-contract-docx.md` 内容控件一节：

- 带 `w:dataBinding` 的控件仍列出，`bound` 为 `true`，但 `setContentControl` 报 `NotImplemented`；也「不写自定义 XML 部件」。
- `kind` 为 `repeatingSection` 或 `group` 的控件，`setContentControl` 报 `NotImplemented`。
- 块级 `sdtContent` 里有 `w:tbl` 时报 `NotImplemented`。

模板类文档大量使用数据绑定和重复节，这几类控件现在只能读不能改。

## 目标

按第 1 步探测的结果，分三块，能做的做，Word 不支持的标 🚫：

- 数据绑定：改绑定控件的值时，同时写回它绑定的自定义 XML 节点，两边一致；可以新建绑定（新建或复用 `customXml` 部件）。
- 重复节：增删重复项（`repeatingSectionItem`），改项里的子控件。
- 组合：改组合控件里的子控件。块级控件里含表格时也能改。

## 不做

- 不实现开发者模式 UI，不做 XML 映射窗格。

### 6. 测试与手测

- 改绑定控件的值：控件显示文本与 `customXml` 节点同时变；inspect 读回一致。
- 增删重复项各一条测试；改组合子控件一条。
- 样本用 Word 16.0 另存的模板，不能只用本库 create 的产物。
- 手测：Word 16.0 打开产物，绑定值、重复项显示正确，不报修复。
