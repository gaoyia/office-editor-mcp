# 工作表换行与缩进

状态：❌
日期：2026-11-16
分类：功能缺失

对应 C25 第 8 段，序号 **84**。`wrapText` 或非 0 的 `indent` 当前整表失败。公开样本 `NewStyleConditionalFormattings.xlsx`、`WidthsAndHeights.xlsx` 有换行。

## 目标

点名的换行单元格，以及点名的缩进单元格，与 Excel 16.0 的 `CopyPicture` 对比。非文字像素差 0。字形灰度暂缓，位置和黑框要对齐。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 契约写明换行和缩进条件 | ❌ |
| 1 | 只画这两档（若必须拆开，先交差 0 的那一档） | ❌ |
| 2 | 手测差 0 | ❌ |

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。
