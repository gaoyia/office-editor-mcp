# 幻灯片图片放大

状态：✅
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。等像素、无非整像素裁剪的拷贝已经差 0，不重做。手测已记：2×2 的 PNG 拉成 4×4 时，四角是原色，其余 12 个像素是混合，最近邻对不上。本切片在 Windows 上用已有共享路径里的公开 GDI+ API（`InterpolationMode.HighQualityBicubic`、`WrapMode.TileFlipXY`、`PixelOffsetMode.Half`）做未裁剪的放大，不把 Office COM 当库 renderer。

## 目标

不透明嵌入 PNG 放大到目标像素（源可以是多种尺寸，倍率可以是整数或非整数，也可以只放宽一边），与 PowerPoint 16.0 差 0。对不上继续整页失败。透明图按用户 t93u 验收：优先求像素一致；有限尝试后可接受色彩/alpha 混合残差，但位置、目标尺寸和边界不得偏差。几何用独立锚点检查，不用颜色容差掩盖位移。官方原始 pixel-diff 照实记录，不放宽全局 MaxDelta=0，也不把透明页写成差 0。

已交付范围：嵌入 PNG，没有 `srcRect`（等像素整像素裁剪仍走原来的拷贝路径），目标宽和高都不小于源像素。`p:pic` 与形状 `blipFill` 同一条放大路径。Windows 上走上述 GDI+ 插值。带透明通道的像素先插值再按已有 `over()` 叠到页面上。

仍不画：任一目标边小于源（缩小未对照官方），以及带 `srcRect` 且裁完尺寸与目标不同（缩放裁剪另案，见 `.plan/2026年-11月-16日-❌-pptx-缩放裁剪.md`）。平铺、`fillRect` 偏移、图片页底也不在本切片。非 Windows 没有这条 GDI+ 对照路径：不透明放大沿用历史最近邻，不声称与 Office 差 0；带透明像素的放大整页失败，避免静默用最近邻冒充成功。xlsx 工作表出图未接这条放大路径，目标尺寸不等于源时仍整页失败，未对照。

不要把「图片支持」标成全部完成。透明页没有像素差 0，只交付了几何准确的子范围，残差按 t93u 接受并记录，不再无穷枚举 1 级残差。字形灰度仍按 C25 第 0 段暂缓，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。形状渐变收口和圆角直边收口仍是未差 0，不重做。

验收时：不透明非文字像素必须 `differ=0`、`maxDelta=0`。透明页把几何和像素完全一致拆开，官方残差照实写进记录。不把灰阶差靠放宽容差算通过。
