# xlsx 列宽行高与合并

状态：✅ 已通过 Excel 16.0 手测  
日期：2026-09-27

从 `roadmap/xlsx.md` 拆出待做序号 2。`cols` 与行 `ht` 改单元格时会原样留下。不能读或写列宽、行高、合并。

## 目标

inspect 范围内给出列宽、行高、合并区域。apply 能设列宽、行高、合并与取消合并。不按文字去算「最适列宽」。

## 已锁定

- inspect 有单元格切片时始终带 `cols` / `rows` / `merges`（可空）。稀疏：只报带 `width` 或 `bestFit` 的 `<col>`、带 `ht` 的行、与范围相交的合并。
- 独立 op：`setColWidth`、`setRowHeight`、`mergeRange`、`unmergeRange`。不用 Word 表的 `mergeCells`。
- JSON `width` 是 Excel 列宽字符数（COM `ColumnWidth`）。写入按 §18.3.1.13 公式转成 `col/@width`，MDW 固定 7 像素，不读实际字体。inspect 按同一公式还原到 2 位小数。
- 只改被点名的列：盖住更多列的 `<col>` 先拆开。
- `setRowHeight` 写 `ht` 与 `customHeight`，不算自动换行高度。
- 合并只留左上角值，其余格按 `setCell` 清空值和公式。相交的已有合并先删再写入。
- 不按列宽反推 `twoCell` 图尺寸。只跑这些 op 不标重算。
- create 本期不写列宽、行高、合并。

## 不做

- 排版、自动换行高度计算（可写 `customHeight` 数值）
- 列/行隐藏与大纲（视图另开）

## 前置

无。

## 验收

列宽 20、行高 30、合并 A1:B2 后 Excel 对得上；取消合并无修复。Excel 16.0 手测 Xl1–Xl5 已过。
