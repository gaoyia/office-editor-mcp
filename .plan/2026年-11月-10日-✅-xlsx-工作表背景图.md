## 已锁定

- 只做 `worksheet`。`chartsheet`、`dialogsheet`、`macrosheet` 不读、不写。对这三种表发下面两个 op 报 `InvalidField`。
- id 固定为 `sheet:{name}/background`。一张表一个，不另编序号。
- `background` 紧跟该表 `pictureCount` 之后。没有 `<picture>` 则为 `null`。有则为对象，字段顺序：`id`、`contentType`。不把字节放进树。
- 不计入 `pictureCount`。不出现在 `pictures`。不进 `<drawing>`。
- `setSheetBackground` 的 `id` 必须是工作表 id `sheet:{name}`，必填 `file`。已有背景则换媒体，没有则新建 `<picture>` 和 image 关系。
- `deleteSheetBackground` 的 `id` 必须是背景图 id。删掉 `<picture>` 和这条关系。媒体没有别的引用时一并删。
- 对单元格 id、工作表图 id、页眉图 id 发这两个 op 报 `InvalidId`。docx / pptx 上报 `InvalidField`。
- create：`sheets[].background` 可选，值是本地文件路径。只许 `worksheet`。省略则不写 `<picture>`。
- `exportMedia` 认这个 id，写出 `/xl/media/…` 的原字节。
- 手测编号 **Xbg**。脚本 `manual-check/office/cases/xlsx-background.ps1`。不要和 Xb、Xb2 撞。
