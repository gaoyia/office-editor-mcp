# docx 字符缩放

状态：✅
日期：2026-10-11

对应 `roadmap/docx.md` 待做序号 **65**。前置：`.plan/2026年-10月-10日-✅-docx-段落边框底纹与run剩余.md`。不要和 62 的字距合成一份。

62 写明不做 `w:w`。那是 run 上的字符缩放百分比（§17.3.2.41 的邻条 `w:w`），不是间距。inspect `runs` 名单没有它。`setRunFormat` 也不认。能开，所以另开。

## 目标

run 上的字符缩放能 inspect、能 `setRunFormat`。不把样式里的缩放摊进来。不算排版引擎。

## 已锁定

- `scope.runs` 在 `kern` 之后加 `scale`。不要叫 `w`（和宽度字段撞）。
- `scale` 取 `w:rPr/w:w/@w:val`（百分比整数）。没有元素为 `null`。
- `setRunFormat` 增加可选 `scale`；`null` 去掉该元素。合法范围与规范一致，越界报 `InvalidField`。
- 格内、框内、注内、批注内同样认。xlsx / pptx 上该字段报未知字段。
- 手测编号 **Rsc**。脚本 `manual-check/office/cases/docx-run-scale.ps1`。不要和 Rcs、Rh、Ea 撞。

## 不做

- 字符间距与 kern（见 62）
- 与 Word 像素级一致
