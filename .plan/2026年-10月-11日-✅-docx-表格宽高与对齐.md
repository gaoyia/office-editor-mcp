# docx 表格宽高与对齐

状态：✅
日期：2026-10-11

对应 `roadmap/docx.md` 待做序号 **57**。前置：表格结构与外观（12 / 49）已过。

inspect 能报 `pos`（浮动 `tblpPr`），apply 有 `setTableFloat`。表首选宽度、列宽、行高、行内对齐原先不进树，也没有 set op。图 / 框 / 形状 / 图表 / SmartArt 已有尺寸 op。不算排版引擎，不算自动列宽。

## 目标

inspect 与 apply 能读写 Word 表的首选宽度、网格列宽、行高，以及行内表的 `jc` / `tblInd`。create 复用同一套 apply。不要另写一套 XML。

## 已锁定

- `setTableWidth`：写 `tblW`、可选 `tblGrid` / 各格 `tcW`。`type` 为 `dxa` 时写 `tblLayout=fixed`；`auto` / `pct` 写 `autofit`。给了 `cols` 时长度必须等于 `colCount`。只给 `w` 且 `type` 为 `dxa` 时按现有列宽比例缩放到总和为 `w`。始终把各格 `tcW` 写成所占网格列之和。不算最适列宽。
- `setTableAlign`：行内表 `jc` 与 `tblInd`。不要和 `setTableFloat` 混。不要复用 pptx 的 `setTablePos` / `setTableSize`。
- `setTableRowHeight`：行 id，写 `trHeight`。`h` 为 `null` 时去掉。不算按内容自动行高。
- xlsx 的 `setColWidth` / `setRowHeight` 单位和寻址不同，不要共用。
- 不做：单元格垂直对齐、表级边框独立 op、OLE 事后改尺寸。

## 不做

- 排版引擎、自动列宽、按页边反推
- 框内再套框
- 独立改某格 `tcW` 而不改网格
