## 已锁定（探测后写入契约，不要改）

- 题注与交叉引用仍是域：继续出现在 `fields`。另给 `caption:{n}` / `xref:{n}` 精简单名，不把它们从 `fields` 里摘掉（与 TOC 同时进 `fields` 与 `tocs` 相同）。
- 根上始终有 `captionCount` / `crossRefCount`，放在 `tocCount` 之后。只计主文档。页眉页脚容器不出现这两项计数。
- `scope.captions` / `scope.crossRefs` 才列名单。嵌套在其它域结果里的 SEQ / REF / PAGEREF / NOTEREF 不进这两份名单（避免把 TOC 里的 PAGEREF 当成交叉引用）。
- 题注：顶层 `SEQ`。交叉引用：顶层 `REF` / `PAGEREF` / `NOTEREF`。`kind` 为 `ref` / `page` / `note`。
- `_Ref*` 书签仍不进 `bookmarks`（现有隐藏书签规则）。题注节点上的 `bookmark` 给出包住该 SEQ 的书签名（优先 `_Ref*`）。
- `insertCaption`：在 body 直接子段落之后（或 `docx:document` 末尾）新写一段。指令 ` SEQ {label} \* ARABIC `，复杂域、`w:dirty`、不写结果。标签字 `{label} `、可选 `title` 写在 `bookmarkEnd` 之后。自动书签 `_Ref` 加九位数字。不写 `pStyle`。label 默认 `Figure`，须符合 ECMA-376 SEQ identifier（拉丁字母开头，最多 40 个拉丁字母 / 数字 / 下划线）。
- `insertCrossRef`：把 REF / PAGEREF 追加到已有段落（正文或页眉页脚），与 `insertField` 相同。`bookmark` 为书签名（可 `_` 开头），必须在主文档里已有。`kind` 为 `ref`（缺省，` REF {name} \h `）或 `page`（` PAGEREF {name} \h `）。本期不写 NOTEREF。
- `deleteCaption`：宿主是 body 直接子段落则整段去掉（题注就是这一段）；否则只拆 SEQ 与包住它的 `_Ref*` 书签。带分节符且不能整段删时报 `NotImplemented`。
- `deleteCrossRef`：拆掉该 REF / PAGEREF / NOTEREF 域（含缓存），不删整段。
- 不在库里求值。打开 Word 后由 Word 刷新是预期。
- create 本期不写题注与交叉引用。
- 框内 / 注内 / 批注内本期不编。xlsx / pptx 上这些 op 与 scope 键报 `InvalidField`。
- 手测编号 **Cp**（不要用 Cf，create 补齐已占用），脚本 `manual-check/office/cases/docx-caption-xref.ps1`。
