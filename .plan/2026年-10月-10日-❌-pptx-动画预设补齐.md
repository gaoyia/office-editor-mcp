# pptx 动画预设补齐

状态：❌
日期：2026-10-10

对应 `roadmap/pptx.md` 待做序号 **28**。前置：`.plan/2026年-10月-9日-✅-pptx-动画setAnim与进片.md`。

`docs/json-contract-pptx.md` 现状：`insertAnim` / create `anims[].type` 只认 `fade`；`setAnim` 不改 `type`；不写 `txEl`；inspect 能读 `presetClass` 与 `animMotion` 等，但不写重复、声音、路径点。`setTiming` 仍报 `UnsupportedOp`。

## 目标

按模板写入常用进入 / 强调 / 退出 / 路径预设。inspect 与 `setAnim` 能读写 `repeat` 与效果声音。PowerPoint 16.0 打开无修复。

## 已锁定

- 仍是预设模板，不接受整棵时间轴 JSON。`setTiming` 仍报 `UnsupportedOp`。
- `setAnim` 可改已有一条的 `type` / `repeat` / 声音；省略不改。
- 按段 `txEl`、点对象触发、`moveAnim` 本期写进同一份契约，能拆手测组，不要另开对象模型。
- 不实现放映引擎。
