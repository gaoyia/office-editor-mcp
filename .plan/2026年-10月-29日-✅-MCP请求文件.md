# MCP 请求文件

状态：✅ 已落地。
日期：2026-10-29

不在 `roadmap/` 的格式待做里。这是 `ooxp mcp` 的参数形状，不占待做序号。领域 JSON 不增加字段。

## 目标

六个工具的参数有两种形状：直接写领域 JSON，或只写 `requestPath` 指向本机上一份领域 JSON 文件。命令行读完文件后交给库的仍是领域 JSON。

## 不做

- 不把 `requestPath` 写进领域契约或 `docs/json-schema/`。
- 不把文件内容和其它参数拼在一起。
- 不在库里解析 JSON-RPC，也不在库里读这个请求文件。

## 清单

| 序号 | 项 | 状态 |
| --- | --- | --- |
| 1 | `docs/cli.md`、`docs/architecture.md`、`docs/json-contract.md`、`README.md` 写明两种形状 | ✅ |
| 2 | `inputSchema` 用 `oneOf` 列出两种形状 | ✅ |
| 3 | 读文件、拒绝混写、`action` 仍须匹配工具名 | ✅ |
| 4 | 单测覆盖读文件、混写、文件不存在、`action` 不匹配 | ✅ |

## 验收

- 只写 `requestPath` 时，文件内容按该工具执行。
- `requestPath` 与其它字段同时出现时，工具结果带 `isError`。
- 库收到的对象里没有 `requestPath`。
