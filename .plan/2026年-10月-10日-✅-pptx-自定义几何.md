## 已锁定

Office 16.0 `Shapes.BuildFreeform` 再 `ConvertToShape()`：宿主是带 `p:txBody` 的 `p:sp`，没有 `prstGeom`。
COM `Type=5`、`AutoShapeType=138`。必须写完整 `a:custGeom` 骨架：空 `avLst` / `gdLst` / `ahLst` / `cxnLst`，
`rect` 的 `l` / `t` / `r` / `b` 都是 `0`，再写 `pathLst`。`path/@w` / `@h` 比最大点大约 1。
不写 theme `p:style`，不写 `a16:creationId`，与 14 一致。

形状 `geom` 仅当存在 `a:custGeom` 时出现，插在 `prst` 之后。不要给矩形补 `geom: null`。
`setShapeGeom` 整份替换 `custGeom`。本期可写 `moveTo` / `lnTo` / `close`。
inspect 可读 `cubicBezTo` / `arcTo` 等原文 `type`。`setShapeGeom` 写这些命令报 `InvalidField`。

`insertShape` 可选 `geom`，与 `prst` 互斥。给了 `geom` 则写自由形状（不写 `txBox`，仍带 `txBody`）。

`BeginConnect` / `EndConnect` 另存稳定：`a:stCxn` / `a:endCxn` 的 `id` 是目标 `cNvPr/@id`，
`idx` 为 COM 站点减 1。`insertConnector` 可选 `start` / `end`。新增 `setConnector`。
`site` 为正整数，写入 `idx = site - 1`。目标必须是同宿主形状或连接线。
inspect 只在有元素时带 `start` / `end`。不算自动绕障碍。

create 本期不写 `geom` / 连接绑定（38）。不重算组合框。三维、艺术字字填充走 C10。
备注页连接线走 31。母版上新建非占位符走 29。手测编号 **Pcg**。Office 16.0 手测 Pcg1–Pcg5 已过。
