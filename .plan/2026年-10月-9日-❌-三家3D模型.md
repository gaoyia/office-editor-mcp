# 三家 3D 模型

状态：❌ 探测已过，规则已锁，文档与代码未动
日期：2026-10-09

对应 `roadmap/docx.md`、`roadmap/xlsx.md`、`roadmap/pptx.md` 跨格式 **C7**。前置：正文图 / 工作表图 / 幻灯片图。不要和 EMF 嗅探、墨迹、OMML 捆在一起。不算 3D 渲染引擎。不把 GLB 塞进 inspect 树。不要走 `insertPicture`。

request schema 的 `file` 仍是路径字符串。inspect 的 `contentType` 是出参。

## 目标

三种格式能按文件头写入 glTF Binary（`.glb`），inspect 给稳定 id，`exportMedia` 写出 GLB 原字节。Office 16.0 打开无修复。不进 `pictures`。Fallback 海报不进 `pictures`。

## 探测结论（Office 16.0）

`Shapes.Add3DModel`（Word 走 `InlineShapes.Add3DModel`）插入本地 `.glb` 后另存：

- 部件：`/…/media/model3d1.glb` 加 PNG 海报 `image1.png`
- `Default Extension="glb"` → `model/gltf.binary`；`png` → `image/png`
- 关系：`Type=http://schemas.microsoft.com/office/2017/06/relationships/model3d` 指向 GLB；另有一条 image 指向海报
- `a:graphicData/@uri` = `http://schemas.microsoft.com/office/drawing/2017/model3d`
- 命名空间 `am3d`：`http://schemas.microsoft.com/office/drawing/2017/model3d`
- `am3d:model3d/@r:embed` 指向 GLB；`am3d:raster/am3d:blip` 指向海报
- `mc:AlternateContent`：`Choice Requires="am3d"`，Fallback 是海报 `pic`
- Excel / PowerPoint：`xdr:graphicFrame` / `p:graphicFrame`。COM `Type=30`
- Word：`wp:inline` 包 `am3d:model3d`，不是 `pic:pic`。行内 COM `Type=19`
- 相机、灯光、`am3d:trans` 由 Office 写出。库写入抄一套默认值，不把这些字段放进 inspect

## 已锁规则

- 只认 **GLB**：文件头小端 `glTF`（`0x46546C67`），version=2。不认 `.gltf` JSON、USDZ。不是 GLB 报 `InvalidImageFile`（对外 `InvalidField`）
- **不是图**。不进 `pictures`，不计入 `pictureCount`。对图 id 发 3D op、对 3D id 发图 op 报 `InvalidId`
- inspect 只走 `Choice Requires="am3d"`。Fallback 海报与 `am3d:raster` 用的 PNG **不进** `pictures`
- id：
  - docx：`{段落 id}/model3d:{wp:docPr/@id}`；没有 `docPr/@id` 时用 `model3d:index:{k}`，`stable` 为 `false`
  - xlsx：`sheet:{name}/model3d:{cNvPr}`；没有则 `model3d:index:{k}`
  - pptx：`slide:{n}/model3d:{cNvPr}`；备注为 `slide:{n}/notes/model3d:…`
- inspect：
  - 根上 / 每张表 / 每页始终 `model3dCount`（docx 只计正文，xlsx 只计工作表 drawing，pptx 只计幻灯片；不含页眉、备注）
  - 计数字段插在 `oleObjectCount` 之后（docx 插在 `oleObjectCount` 之后；xlsx 工作簿与 `worksheet` 同位置；pptx 根与每页同位置）
  - `scope.model3ds: true` 才出名单。xlsx / pptx / docx 的 `scope` 都要收这个键；未开本切片前该键报未知字段
  - 字段顺序：
    - docx：`id`、`name`、`kind`、`cx`、`cy`、`wrap`、`contentType`、`stable`。`kind` / `wrap` 与图相同。本期写入只做 `inline`
    - xlsx：`id`、`cNvPrId`、`name`、`anchor`，然后按锚点种类跟位置字段（与工作表图相同），再跟 `contentType`、`stable`
    - pptx：`id`、`cNvPrId`、`name`、`x`、`y`、`cx`、`cy`、`contentType`、`stable`
  - `contentType` 恒为 `model/gltf.binary`。不把 GLB、相机、灯光摊进树
- apply（三家都认，从各自「docx 专用 op」名单里拿出来）：
  - `insertModel3d`：`id` 为段落 / `sheet:{name}` / `slide:{n}`（或备注容器 `slide:{n}/notes`）。`file` 必填。`cx`/`cy` 成对可选，缺则 1 英寸见方。xlsx 可给 `from`（缺省 A1、`oneCell`）。pptx 可给 `x`/`y`（缺省 0）。docx 本期不写浮动
  - `replaceModel3d`：`id` 为 3D id。换 GLB 字节，保留 graphicFrame / `wp:inline` 与关系 id；海报仍用 1×1 PNG 占位。不改位置尺寸
  - `deleteModel3d`：删该 AlternateContent；GLB 与海报无人引用则删
  - 本期不新开 `setModel3dSize` / `setModel3dPos`
- 写入：GLB 原字节 + 1×1 PNG 占位作 `am3d:raster` 与 Fallback。相机 / 灯光 / `am3d:trans` 抄探测默认值。不栅格化模型。手测若 Repair 再改海报
- `exportMedia`：认 3D id，写出 GLB 原字节，`contentType` 为 `model/gltf.binary`
- create：`paragraphs[].model3ds[]`、`sheets[].model3ds[]`、`slides[].model3ds[]`，每项 `file`，可选尺寸 / 锚点。不要写进 `pictures[]`
- 页眉、备注：inspect 页眉 / 备注容器可列已有 3D；xlsx 页眉槽、pptx 批注内本期不插
- 组合里符合条件的 `graphicFrame` / `wp:inline` 要展开，组合本身不进树
