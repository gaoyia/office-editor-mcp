## 已锁定（探测后写入契约，不要改）

- INDEX 与 XE 仍是域：继续出现在 `fields`。另给 `index:{n}` / `xe:{n}` 精简单名，不把它们从 `fields` 里摘掉。
- 根上始终有 `indexCount` / `indexEntryCount`，放在 `crossRefCount` 之后、`mathCount` 之前。只计主文档。页眉页脚容器不出现这两项计数。
- `scope.indexes` / `scope.indexEntries` 才列名单。嵌套在其它域结果里的 INDEX / XE 不进这两份名单。
- `insertIndex`：在 body 直接子段落之后（或 `docx:document` 末尾）新写一段。复杂域、`w:dirty`、带 `separate`、不写结果。默认指令 ` INDEX \h "A" \c "1"`。不写 Index 样式，不包 `w:sdt`，不改 `sectPr` 分栏。
- `insertIndexEntry`：把 XE 追加到已有段落（正文或页眉页脚），与 `insertField` 相同。写入 begin / 指令 / end，**不写** `separate`（与 Word MarkEntry 一致）。`entry` 必填，写成 ` XE "{entry}" `。允许冒号表示次级项。含英文双引号或空串 / 空白报 `InvalidField`。
- `deleteIndex`：删掉该 INDEX 域从 begin 到 end 的全部 run（含结果区），再删掉因此变空、且没有 `sectPr` 的正文段落。本期不按构建基块 `sdt` 整块删（COM 未包 sdt）。
- `deleteIndexEntry`：拆掉该 XE 域，不删整段。
- 不在库里求值。打开 Word 后由 Word 刷新是预期。
- create 本期不写索引。
- 框内 / 注内 / 批注内本期不编。xlsx / pptx 上这些 op 与 scope 键报 `InvalidField`。
- 手测编号 **Ix**，脚本 `manual-check/office/cases/docx-index.ps1`。
