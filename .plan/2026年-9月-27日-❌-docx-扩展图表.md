## 已锁定（写入契约后不要改）

- 不另开图表 id。正文仍是 `{段落 id}/chart:{docPrId}`，系列仍是 `{图表 id}/series:{idx}`。
- `type` 在现有枚举上增加 `doughnut`、`radar`、`bubble`。`doughnutChart` → `doughnut`，`radarChart` → `radar`，`bubbleChart` → `bubble`。股价、曲面、复合饼图仍是 `other`，`chartex` 仍是 `chartex`。
- 气泡系列字段顺序：`id`、`index`、`name`、`categories`、`values`、`sizes`，必要时再跟 `cacheStale`。`categories` / `values` 对应 `c:xVal` / `c:yVal`，`sizes` 对应 `c:bubbleSize`。非气泡系列不出现 `sizes`。
- 圆环按饼图规则：`insertChart` / 转到 `doughnut` 时必须恰好一条系列，否则 `InvalidField` 或 `NotImplemented`（与现有饼图一致）。雷达按折线规则：分类加数值。
- 组合图不再仅仅因为 `type=combo` 就整张锁死。次轴、趋势线、误差线仍走原来的 `flags` 限制。
- 透视图表改数、改类型、插入透视图不在本期。`create` 仍不写图表。xlsx / pptx 仍拒绝图表 op。
- 框内、注内、批注内的图表本期仍不进树。

## 转换

| 从 → 到 | 规则 |
| --- | --- |
| `pie` ↔ `doughnut` | 只换包裹；系列条数必须为 1 |
| `line` / `area` / `bar` / `col` ↔ `radar` | 留下 `c:ser` 的分类与数值 |
| `scatter` → `bubble` | `xVal` / `yVal` 留下；`bubbleSize` 用与 `yVal` 等长的 `1` |
| `bubble` → `scatter` | 丢掉 `bubbleSize` |
| `combo` → 单一类型 | 所有系列改到同一包裹；对不上（例如多系列转饼）则 `NotImplemented` |
| 单一类型 → `combo` | 不走 `setChartType`，请用 `insertChart` 的 `combo` |

不要写出 Word 要修复的包。

## 不做

- 图表渲染、坐标轴刻度算法
- 股价图、曲面图、复合饼图、chartex
- 次坐标轴、趋势线、误差线（仍是 `NotImplemented`）
- 改透视源、刷新透视缓存、在 Word 里新建透视表
- xlsx / pptx 工作表或幻灯片上的图表
