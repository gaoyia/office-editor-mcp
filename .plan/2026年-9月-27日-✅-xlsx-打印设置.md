## 已锁定

- 页眉页脚字符串仍走 `setHeaderFooterText`。
- 打印设置挂在工作表节点上的 `print` 对象，不另编 id。`setPrintSetup` 的 `id` 必须是 `sheet:{name}`。`worksheet` 与 `chartsheet` 都认；对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。
- 每张 `worksheet` / `chartsheet` 始终有 `print`。没有对应 XML 时按 ECMA 缺省填：边距 `left`/`right` 0.7、`top`/`bottom` 0.75、`header`/`footer` 0.3（英寸）；`paperSize` 1（Letter）；`orientation` 为 `portrait`（XML `default` 或缺省都报 `portrait`，与 Excel UI 一致）；`scale` 100；`fitToPage` false；`fitToWidth` / `fitToHeight` 1；`gridLines` / `headings` / `hCenter` / `vCenter` false；`printArea` null；`rowBreaks` / `colBreaks` 空数组。
- `print` 字段顺序：`left`、`right`、`top`、`bottom`、`header`、`footer`、`paperSize`、`orientation`、`scale`、`fitToPage`、`fitToWidth`、`fitToHeight`、`gridLines`、`headings`、`hCenter`、`vCenter`、`printArea`、`rowBreaks`、`colBreaks`。
- 边距 JSON 单位是英寸，与 XML `pageMargins`（§18.3.1.62）相同。不要用磅。Excel COM `PageSetup.*Margin` 是磅，手测用 `InchesToPoints` 对照。
- `orientation` 只写 `portrait` / `landscape`。`paperSize` 是 ECMA 整数（9 为 A4）。`scale` 为 10–400 的整数。
- 给了 `fitToWidth` / `fitToHeight` 时写 `sheetPr/pageSetUpPr/@fitToPage="1"`。给了 `scale` 且未同时给 fit 时把 `fitToPage` 写成假（Excel 的缩放与适页互斥）。
- 打印区域只通过 `print.printArea` 与 `setPrintSetup.printArea` 读写，写成该表的 `_xlnm.Print_Area` 定义名，不另开 op。`printArea` 为规范化 A1（可带表名前缀）；`null` 删掉该表这条定义名。定义名名单里仍能看见 `_xlnm.Print_Area`。
- 手工分页符：`rowBreaks` / `colBreaks` 为从 1 计的整数数组，只读写 `man="1"` 的 `<brk>`。不算自动分页，不估页数。
- `setPrintSetup` 除 op/id 外至少一字段。不改 `headerFooter` 原文。不标重算。create 本期不写打印设置。
- 手测编号 **Xps**，脚本 `manual-check/office/cases/xlsx-print.ps1`。
