## 第 0 步探测（2026-10-10，Word 16.0）

`Styles.Add`：字符 Type=2，表格 Type=3，段落 Type=1。Range.Style 能套上字符样式，写出 `w:rStyle`。

自定义样式带 `w:customStyle="1"`。内置 `Normal` 不能删。中文 Word 里 Default Paragraph Font 的 `styleId` 是 `a0`，Normal Table 是 `a1`，不要写死英文 id。

表套自定义表格样式后 `w:tblStyle/@w:val` 对得上。`tblLook` 同时写 `val` 与六个开关；`ApplyStyleRowBands=true` 对应 `noHBand="0"`。

浮动：`Rows.WrapAroundText=true` 后写出 `tblpPr`（`horzAnchor=margin`、`vertAnchor=text`、`tblpX`/`tblpY` 为 twip）以及 `tblOverlap val=never`。默认 `leftFromText` / `rightFromText` 为 180。

表默认边距 `tblCellMar`：6 磅 → 120 twip，8 磅 → 160 twip，`type=dxa`。单元格 `tcMar` 只写出被改的边。底纹 `w:shd val=clear color=auto fill=FF0000`。斜线 `tcBorders/tl2br` 与 `tr2bl`。

## 已锁定

- 不实现排版引擎。不求值表内 `=SUM(ABOVE)`。不写 `tblStylePr` 条件格式块。
- 框内 / 注内 / 批注内的表仍不编、不插。对这些容器发本期表外观 op 报 `InvalidId`。
- `insertStyle` 的 id 必须是 `docx:document`。`styleId` 是 XML 令牌，不是 `style:` 前缀。允许 `[A-Za-z_][A-Za-z0-9_-]*`。已存在报 `InvalidField`。`type` 为 `paragraph` / `character` / `table`。`numbering` 报 `InvalidField`。`name` 省略则与 `styleId` 相同。`basedOn` 可选，值为 `style:{id}`；省略则绑到同类型 `w:default` 样式（没有则不写 basedOn）。写入 `w:customStyle="1"`。
- `deleteStyle` 只删 `w:customStyle` 为开的样式。默认样式或没有 customStyle 的报 `InvalidField`。不扫描文档引用。
- `setStyle` 接受段落、字符、表格样式。编号样式仍报 `InvalidField`。`before` / `after` 只允许段落与表格样式；字符样式带这两项报 `InvalidField`。rPr 字段（`font` / `eastAsiaFont` / `sz` / `bold` / `color`）三种都可写。
- `setRunStyle`：id 是正文或页眉页脚 run id，`style` 为 `style:{id}` 或 `null`。目标必须是字符样式。写入 `w:rStyle`（`EG_RPrBase` 最前）。
- `setTableStyle`：id 是表 id。`style` 与 `look` 至少给一个。`style` 为表格样式 id 或 `null`（去掉 `tblStyle`）。`look` 为对象或 `null`（去掉 `tblLook`）。对象字段：`firstRow`、`lastRow`、`firstColumn`、`lastColumn`、`bandedRows`、`bandedColumns`。写出六个属性与 `val`（bit：0x20 首行、0x40 末行、0x80 首列、0x100 末列、0x200 noHBand、0x400 noVBand）。`bandedRows=true` 写 `noHBand=0`。
- `setTableFloat`：不要复用 pptx 的 `setTablePos`（单位是 EMU）。id 是表 id。`pos` 为对象或 `null`。`null` 去掉 `tblpPr` 与 `tblOverlap`。对象写入 `tblpPr`，并写 `tblOverlap val=never`。锚点只认 `margin` / `page` / `text`。`x` / `y` 单位 twip。省略的 `leftFromText` / `rightFromText` 缺省 180。
- `setTableCellMar`：id 是表 id。`top` / `left` / `bottom` / `right` 为 twip 或 `null`，至少给一个。写入 `tblCellMar`，`type=dxa`。
- `setCellFormat`：id 是单元格 id。`fill`（六位 RGB 或 `null` 去掉 `shd`）、四边 `tcMar`、`tl2br` / `tr2bl`（边对象或 `null`）至少给一个。斜线 `val` 与页面边框同一套。写出 `shd val=clear color=auto`。
- inspect：`scope.tables` 名单在 `nested` 之后、`rows` 之前跟 `style`、`look`、`pos`、`cellMar`。单元格在 `vMerge` 之后、`paragraphs` 之前跟 `fill`、`cellMar`、`tl2br`、`tr2bl`。run 在 `index` 之后、`text` 之前跟 `style`（`w:rStyle/@w:val`，没有为 `null`）。
- 页眉页脚表走同一套 op。嵌套表可以改外观。
- xlsx / pptx 上发本期新 op 报 `InvalidField`。pptx 的 `setTablePos` 语义不变。
