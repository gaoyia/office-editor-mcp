## 已锁定（写入契约后不要改）

- 图 id：`slide:{n}/pic:{cNvPrId}`。`{n}` 规则与现有页 id 相同。没有 `cNvPr/@id` 时用 `slide:{n}/pic:index:{k}`，`stable` 为 `false`。`{k}` 只在该页全部被收入的 `p:pic` 内从 1 计。
- 只认 `p:pic` 且带 `a:blip`。`p:sp`、连接线、`p:graphicFrame`（图表 / 表 / SmartArt）不进 `pictures`。组合本身不进树，里面的 `p:pic` 要展开。
- `mc:AlternateContent` 只进第一个 `Choice`。
- 演示文稿根始终有 `pictureCount`，等于各页之和。每页始终有 `pictureCount`。名单只在 `scope.pictures: true` 时出现，挂在对应页上。不依赖 `scope.slide`。不读媒体字节。
- 现行契约里 pptx 的 `scope.pictures` 报 `InvalidField`。本期改成认这个键。
- `insertPicture` 的 `id` 必须是 `slide:{n}`。对图 id、形状 id 或 `pptx:presentation` 发此 op 报 `InvalidId`。必须给 `file`。`x` / `y` / `cx` / `cy` 可选，EMU；缺尺寸按像素 96 dpi；只给一个尺寸报 `InvalidField`。缺坐标则放到该页空白处，不要叠在 `(0,0)`。
- `kind` / `wrap` / `from` / `to` / `anchor` 是 Word 或 Excel 的字段，pptx 上报 `InvalidField`。
- `setPictureWrap` / `setPictureAnchor` 在 pptx 上仍报 `InvalidField`。改位置走 `setPicturePos`。
- `setPictureSize` 写 `a:xfrm/a:ext`。`setPicturePos` 写 `a:off`；`x` / `y` 至少给一个。
- `cNvPr/@id` 取该页已有全部 `cNvPr`（`sp` / `pic` / `graphicFrame` / 组合）的最大整数加 1，至少为 2（`1` 留给 `spTree`）。
- `setShapeText` 继续只改 `p:sp`，不得误伤 `p:pic`。
- `create` 带图另开。xlsx / docx 的图片契约不动。

## 验收

手测编号 Pp1–Pp7，写入 `docs/checklist-pptx.md`。脚本建议 `manual-check/office/cases/pptx-pictures.ps1`。源文件必须是 PowerPoint 亲手另存，至少一张 `p:pic`。另备一张本地 PNG。不要用库 `create` 产物当带图样例。

- Pp1：无 `pictures` 时有 `pictureCount`、没有名单；`pictures: true` 时 id 为 `slide:…/pic:…`。
- Pp2：`replacePicture` 后无修复；位置尺寸不变。
- Pp3：`insertPicture` 往一页插图，能看见且无修复。
- Pp4：`deletePicture` 后该图消失，无修复。
- Pp5：`setPictureSize` 后 COM 或目视尺寸对上（允许 EMU 误差）。
- Pp6：`setPicturePos` 后图跟着走，无修复。
- Pp7：`exportMedia` 与 `/ppt/media/…` 字节一致。不强制开 PowerPoint。
