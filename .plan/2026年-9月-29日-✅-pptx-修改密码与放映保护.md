## 契约（已锁）

PowerPoint 16.0 探测：`p:showPr` 在 `/ppt/presProps.xml` 的 `p:presentationPr`（§19.2.1.30），插在 `prnPr` 之后、`clrMru` 之前。create 只有 `<p:clrMru/>`。COM 对 create 缺省：`ShowType=1`（`present`）、`LoopUntilStopped` 假、`ShowWithNarration` 真、`ShowWithAnimation` 真、`AdvanceMode=2`（`useTimings` 真）。另存还会写 `penClr` / `sldAll` / 激光笔扩展；apply 不自己写这些，有则原样留。改成 `browse` 时写入 `p14:browseMode showStatus="0"`（uri `{F99C55AA-B7CB-42B0-86F8-08522FDF87E8}`），否则 PowerPoint 16.0 的 COM `ShowType` 为 `4`。

`p:modifyVerifier` 在 `presentation.xml`（§19.2.1.19），`defaultTextStyle` 之后、`extLst` 之前。COM 设 `ShowType` 不会写出它。空 `<p:modifyVerifier/>` 与带哈希样例都不要用 COM 打开。

inspect 根上始终带，不要 scope 键：

1. `showPr`：字段顺序 `type`、`loop`、`showNarration`、`showAnimation`、`useTimings`。没有 presProps 或没有 `p:showPr` 时按 COM/create 缺省（`present` / `false` / **`true`** / `true` / `true`）。有元素时属性按 schema 缺省：`loop` / `showNarration` 缺为 `false`，`showAnimation` / `useTimings` 缺为 `true`。不进树：`sldAll` / `sldRg` / `custShow`、`penClr`、`extLst`、`kiosk/@restart`、`browse/@showScrollbar`。
2. `modifyProtection`：只有 `hasPassword`。非空哈希属性则为 `true`。树上不出现哈希。不要用 docx 那个 `protection` 对象名。

根字段顺序：`customShowCount` 之后、`props` 之前插入 `showPr`、`modifyProtection`。

apply `setShowPr`：`id` 必须是 `pptx:presentation`。五个字段至少给一个。没有元素时先按树上缺省再建。序列化：`loop` / `showNarration` 为真写 `"1"`，为假省略；`showAnimation` / `useTimings` 为假写 `"0"`，为真省略。新建写 `<p:sldAll/>`。改成 `browse` 时写入 `p14:browseMode`。回到 PowerPoint 缺省且没有 `sldRg` / `custShow` / `penClr`、也没有除 browseMode 以外的 `extLst` 时删掉整个 `p:showPr`。xlsx / docx 报 `InvalidField`。没有 presProps 报 `OpcPartMissing`。

apply `setProtection`：pptx 认 `pptx:presentation`。只认 `enforced`。`enforced: true` 与 `password` 报 `NotImplemented`（不写哈希）。已有哈希时改任何字段（含 `enforced: false`）报 `NotImplemented`，不删哈希。没有元素且 `enforced: false` 则空操作。本期只删不建。

create：`presentation` 上出现 `showPr` / `modifyProtection` 报未知字段。不写 `p:showPr`，也不写 verifier。
