状态：✅ 库测试与 Excel 16.0 手测 Xp1–Xp7 已过  
日期：2026-09-27

从 `.plan/2026年-9月-27日-❌-xlsx-图与图表路线.md` 拆出序号 0。工作表上的图不是单元格，也不是 Word 那种 `w:drawing`。本期只编 SpreadsheetDrawing 的 `xdr:pic`，不画图、不算列宽行高。

规范线索：工作表经关系指向 `/xl/drawings/drawingN.xml`（`xdr:wsDr`，ECMA-376 §20.5）。锚点是 `xdr:twoCellAnchor` / `xdr:oneCellAnchor` / `xdr:absoluteAnchor`。图是锚点下的 `xdr:pic`，`xdr:cNvPr/@id` 作稳定 id。媒体经 drawing 部件 `.rels` 指向 `/xl/media/…`（§20.2）。`xdr:col` / `xdr:row` 从 0 计，树上仍写成 A1。

契约真源：`docs/json-contract.md`、`docs/json-schema/request.schema.json`、`docs/errors.md`、`docs/architecture.md`、`docs/opc.md`、`docs/checklist-xlsx.md`。

## 目标

工作表上的 DrawingML 图能列、换、插、删，能改尺寸，能改锚点。Excel 打开时自己画。`exportMedia` 认工作表图 id。

本期不按全量验收。当前能交的只是表里标着要做、且当期已 ✅ 的编号。

## 已锁定（写入契约后不要改）

- 图 id：`sheet:{name}/pic:{cNvPrId}`。没有 `cNvPr/@id` 时用 `sheet:{name}/pic:index:{k}`，`stable` 为 `false`。`{k}` 只在该表全部 drawing 部件内从 1 计。`{name}` 规则与现有工作表 id 相同。
- 只认锚点的直接子元素 `xdr:pic` 且带 `a:blip`。组合 `xdr:grpSp` 里的图、图表 `xdr:graphicFrame`、形状 `xdr:sp`、连接线、VML `legacyDrawing`、页眉页脚图不进名单。
- `mc:AlternateContent` 只进第一个 `Choice`。
- 工作簿根始终有 `pictureCount`，等于各 `worksheet` 的 `pictureCount` 之和。每张 `worksheet` 始终有 `pictureCount`。`chartsheet` / `dialogsheet` 没有这两个字段。
- 名单只在 `scope.pictures: true` 时出现，挂在对应工作表上，不挂在工作簿根上。不依赖 `sheet` / `range`。不读媒体字节。
- `insertPicture` 的 `id` 必须是 `sheet:{name}`，且该表 `kind` 为 `worksheet`。必须给 `from`（A1）。`anchor` 只认 `oneCell`（缺省）与 `twoCell`（必须再给 `to`）。不插入 `absolute`。
- `setPictureWrap` 仍是 Word 绕排，xlsx 上报 `InvalidField`。改锚点走新 op `setPictureAnchor`。
- `setPictureSize` 只改 `oneCell` / `absolute` 的 `xdr:ext`（以及存在的 `a:xfrm/a:ext`）。对 `twoCell` 报 `NotImplemented`（显示尺寸由起止格决定，反推列宽行高是排版）。
- `oneCell` ↔ `twoCell` 可以互转。与 `absolute` 互转报 `NotImplemented`。已有 `absolute` 只许改 `posX` / `posY` 或尺寸。
- `twoCell` 不报 `cx` / `cy`。不算列宽行高。
- `create` 带图另开，见 `.plan/2026年-9月-27日-✅-xlsx-create带图.md`。pptx 的 `scope.pictures`、图片 op、`exportMedia` 仍报 `InvalidField`。
- 图表另开，见 `.plan/2026年-9月-27日-✅-xlsx-工作表图表.md`。

## 不做

- 图表、SmartArt、形状、控件、OLE、批注 VML
- 页眉页脚图、图表工作表上的图
- 组合里的图
- 按单元格自动绕排或对齐
- create 带图（另开，见上）

## 验收

手测编号 Xp1–Xp7，写入 `docs/checklist-xlsx.md`。脚本建议 `manual-check/office/cases/xlsx-pictures.ps1`。源文件必须是 Excel 亲手另存，至少各一张 `oneCell` 与 `twoCell`。另备一张本地 PNG。不要用库 `create` 产物当带图样例。

- Xp1：无 `pictures` 时有 `pictureCount`、没有名单；`pictures: true` 时 id 为 `sheet:…/pic:…`，`anchor` / `from` 与工作表一致。
- Xp2：`replacePicture` 后 Excel 无修复；锚点不变。
- Xp3：`insertPicture` 往 `worksheet` 插 `oneCell`，Excel 能看见且无修复。
- Xp4：`deletePicture` 后该图消失，无修复。
- Xp5：对 `oneCell` `setPictureSize` 后 COM 或目视尺寸对上（允许 EMU 换算误差）。
- Xp6：`setPictureAnchor` 把 `from` 改到另一格后，图跟着走，无修复。
- Xp7：`exportMedia` 写出的文件与 `/xl/media/…` 字节一致。不强制开 Excel。
