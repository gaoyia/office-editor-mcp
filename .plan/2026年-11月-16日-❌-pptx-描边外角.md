# 幻灯片描边外角

状态：❌
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。手测已记：线宽 9525 和 19050 的直边是整像素，四个外角各有一个覆盖不同的半透明像素，套不齐，因此先不画。已合入 main 的圆角直边单元测试（PR4）不是这一项；官方直边差 0 仍见 `.plan/2026年-11月-16日-⚠️-pptx-圆角矩形直边收口.md`，不得当作本项已完成。

## 目标

不透明矩形（或先点名的一种形状）在整像素线宽下，描边外角与 PowerPoint 16.0 差 0。对不上就继续不画或整页失败，不加大容差，不在对照图上补像素。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 重新对照官方外角覆盖，写进契约 | ❌ |
| 1 | 只画出能差 0 的那一档描边 | ❌ |
| 2 | 手测 1280×720，`differ=0`，`maxDelta=0` | ❌ |

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。
