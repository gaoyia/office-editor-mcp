## 第 0 步（Excel 16.0 另存）

探测脚本 `manual-check/office/cases/_probe-xlsx-29-extlink.ps1`（不要提交、不要进 `run.ps1`）。

- 公式 XML：`<f>[1]Sheet1!A1</f>`，缓存 `<v>42</v>`。COM 显示 `='[file.xlsx]Sheet1'!A1`。
- `/xl/workbook.xml`：`<externalReferences>` 在 `sheets` 之后、`calcPr` 之前。`<externalReference r:id="rId2"/>`。
- 工作簿 `.rels`：Type `…/externalLink`，Target `externalLinks/externalLink1.xml`。
- `/xl/externalLinks/externalLink1.xml`：`externalBook/@r:id="rId1"`，`sheetNames/sheetName`，`sheetDataSet/sheetData/@sheetId` 从 0 计。Excel 另存还带 `xxl21:alternateUrls`。本期不写 `xxl21` / `x14` / `mc:Ignorable`。
- 该部件 `.rels`：Type `…/externalLinkPath`，`TargetMode="External"`。Excel 另存同时写相对文件名与 `file:///…` 绝对路径。本期只写一条：调用方给的 `path`。
- `[Content_Types]`：Override `application/vnd.openxmlformats-officedocument.spreadsheetml.externalLink+xml`。

## 已锁定（写入契约后不要改）

- 外部引用挂在工作簿上。id 为 `extlink:{n}`，`{n}` 从 1 起，按 workbook `<externalReference>` 文档顺序。与公式里的 `[n]` 同一套。增删之后旧下标会变。
- 每本工作簿始终有 `externalLinkCount`。`scope.externalLinks` 为 true 时列出名单。没有则为空数组。不依赖单元格切片。
- 名单每项字段顺序：`id`、`index`、`kind`、`path`、`sheets`。`index` 与 id 里的 `{n}` 相同。`kind`：有 `<externalBook>` 为 `book`，其余（DDE / OLE）为 `other`。`path` 取 `externalBook` 的 `r:id` 对应关系 `Target` 原文，缺则为 `null`。`sheets` 按 `<sheetName>/@val` 文档顺序。不把 `sheetDataSet` 缓存格子放进树。不写 `xxl21`。
- `insertExternalLink` 的 `id` 必须是 `xlsx:workbook`。必须给非空 `path`。`sheets` 可选，缺省 `["Sheet1"]`；空数组或空表名报 `InvalidField`。不读目标文件。追加到名单末尾，新下标为原 `externalLinkCount+1`。
- 写出 `/xl/externalLinks/externalLinkN.xml`（N 取未占用的最小正整数）、该部件一条 `externalLinkPath` 关系（`TargetMode="External"`）、workbook 一条 `externalLink` 关系与 `<externalReference>`。`sheetDataSet` 为每个表名写空的 `<sheetData sheetId>`。不写缓存值。不写 `xxl21`。
- `path`：已是 `file:` / `http:` / `https:` 则原样当 Target；绝对盘符或 UNC 写成 `file:///` 加原文；其余当相对路径原样写入。
- `deleteExternalLink` 的 `id` 必须是 `extlink:{n}`。找不到报 `IdNotFound`。若任一工作表 `<f>` 或定义名文本含 `[k]`（k 为该条或更大的下标）报 `NotImplemented`，不写文件。否则摘该条 `<externalReference>`、对应部件及其 `.rels`、workbook 关系与 Override。删光则去掉 `<externalReferences>`。不重写公式。
- `setCell` 仍把公式当字符串。跨工作簿请先 insert，再写 `=[n]Sheet1!A1`。库不把文件路径改写成 `[n]`，也不把 `[n]` 展开成路径。
- 对 DDE / OLE 外部链只读进树（`kind=other`），insert 不写它们。delete 仍走上面那条占用检查。
- docx / pptx 上发这些 op 或 `scope.externalLinks` 报 `InvalidField`。create 本期不写外部引用。不标重算。
- 手测编号 **Xel**，脚本 `manual-check/office/cases/xlsx-external-link.ps1`。不要和 Xl、Xcn 撞。
