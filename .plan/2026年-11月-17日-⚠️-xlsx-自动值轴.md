## 根因与公开逻辑证据

旧axis_range不接收图表高度/字体，把所有图统一限制5..10区间，并强制包含0。旧read_clustered_column从未读valAx的min/max/majorUnit/minorUnit，显式配置也被自动算法覆盖。

本次27个有限预声明输入，实际cells=公式=numCache=COM Series；每个包独立SHA、同一chart原生导出及公开Axis属性。没有通过缩图片推标量。

| 数据/96高度 | Office min..max / major |
|---|---|
| 1/4/2，96 | 0..5 / 5 |
| 1/4/2，144、200 | 0..5 / 1 |
| 1/4/2，240、336、480 | 0..4.5 / 0.5 |
| -1/-4/-2，200 | -5..0 / 1 |
| -2/4/1，200 | -3..5 / 1 |
| 全0，200 | 0..1 / 0.2 |
| 全3，200 | 0..3.5 / 0.5 |
| 0.1/0.4/0.2，200 | 0..0.5 / 0.1 |
| 99/100/99.5，200 | 98.4..100.2 / 0.2（未实现，诚实NI） |

**4.5/.5不是所有情况下都错**，大图原有headroom测试由COM确认仍正确，不能硬改为5/1。新模型按固定96完整字体行框+一栅格间隙的可容纳标签数给nice-number候选容量，上限保留10，不按1/4/2值硬编码。生产Calibri10行框16.276px；单用现有GDI字身14px会过密，首次独立测试已发现并保留失败日志，未调若干数据阈值凑值。

## 支持边界

- 延续原1/2/5×10^n候选及95%留白；图表高度和完整字体行框参与容量。支持本次21自动配置+5显式配置的min/max/major/minor标量，共26×4=104个与COM相同。27分母的窄范围非零自动minimum一项诚实NI，不称畸形。
- 显式min/max/majorUnit/minorUnit优先，不由自动候选覆盖；支持非整除范围的major/minor数值映射，限制最多1000主/5000次标记防无界循环。常规默认5分割走原像素舍入；自定义minor按真实比例绘制。
- 多值轴、log/reversed、自定义crosses/crossesAt、非General数值格式等本片未实现，有效配置诚实NI，不新增formatter/轴类型。缺失保持原缺省。
- 这不是Office全域自动算法的复刻。不同title/布局/有效字体配置的容量仍需逐源证据；默认autoZero交点另以COM crossesAt核对：取0在min/max内的clamp，并驱动类别轴线/刻度/标签，不再固定负下限。26交点一致；尺度四项与交点第五项分开统计，不声称字体/AA整图对齐。raw COM crosses/IsAuto也保留。
- chart固定96、MDW、oneCell/zoom、legend、P1 sheet/spark、P3 alpha不改。既有大图headroom断言保留；不改旧gold、容差、DPI，不扩大PPT例外。
