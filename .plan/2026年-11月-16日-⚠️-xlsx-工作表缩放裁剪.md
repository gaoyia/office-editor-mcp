# 工作表要缩放的裁剪

状态：⚠️
日期：2026-11-16
分类：功能缺失

对应 C25 第 12 段，序号 **84**。不透明 PNG 在目标像素等于图片像素时已画，整像素且不缩放的裁剪已画。要缩放的裁剪此前让整表失败。64×20 的图用双格锚点铺满 A1 时，Excel 16.0 收成 63×19 再滤镜，不要和本切片混成一次冒险。

## 目标

点名一档工作表上「裁剪后再缩放」的 PNG，与 Excel 16.0 的 `CopyPicture` 差 0。对不上继续失败。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 锁定裁剪和目标尺寸 | ✅ |
| 1 | 只画这一档 | ✅ |
| 2 | 手测差 0 | ⚠️ |

## 本刀交付（2026-11-17，Asia/Shanghai）

- **定位**：工作表 `xdr:pic` 的 `a:srcRect` 整像素裁剪后再放大到目标框（**不是** export viewport 缩放）。复用 PPT 同源公开 GDI+ `scale_device_rgba_window`（源矩形画在原图上，相位用真实 dest）。仅不透明 PNG；裁完宽高均 ≤ 目标（允许一边相等）；半像素百分比 / 缩小 / 一边放一边缩 / 无裁纯放大 / 透明 → 仍 NotImplemented。不扩 t93 透明残差例外。不碰 PPT `dest_y=65` 已知 differ=34/maxDelta=2 锁。
- 库测：`xlsx_sheet_picture` 6/6 PASS（含 upscale 接线、downscale NI、1:1 裁剪回归）。
- 官方：`xlsx-sheet-crop-scale-image`（oneCell；中心 2×2→4×4、左裁 3×4→6×8、顶裁→8×6、1:1 裁剪回归）。本机 `GetDpiForSystem=106`，CopyPicture **sizeDiffer** left=73×133 right=65×121。**不**缩金样、**不**改 DPI、**不**容差 → 整图像素差 0 门未过 → ⚠️。滤波是否与 Excel 逐像素一致在 sizeDiffer 下无法宣称；机制按 GDI+ 接线，不以 PPT 差 0 假定 Excel。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不重做等像素拷贝和整像素不缩放裁剪
- 不把 64×20→63×19 双格锚点缩收混进本切片
