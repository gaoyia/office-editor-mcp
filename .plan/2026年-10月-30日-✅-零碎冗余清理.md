# 零碎冗余清理

状态：✅ 已完成。
日期：2026-10-30

不在三种格式的待做表里，不占待做序号。来源是 2026-10-30 的代码审计。领域 JSON 不变。

## 目标

清掉几类体量不大、但会越积越多的冗余：

- 重复的分发分支
- 重复的 XML 小工具
- 多余的 `#[allow(dead_code)]` 和真正的死代码
- 按开发批次起名的文件

## 不做

- 不改 op 语义、字段或错误码。
- 不拆 `error/kind.rs`。522 个错误种类都有地方构造，没有死项。

## 做了什么

- 每个动作允许哪些信封字段记在 `json::envelope_fields`。`dispatch` 只在 `screen` 查一次。inspect、create、apply、exportMedia、exportChartData 按 `for_format` 分到三种格式。
- `ooxp mcp` 的工具参数名从这张表生成。说明文字仍在 `mcp.rs`。领域 JSON 没有拆扁。
- `xml::attr_is_true` 与 `xml::attr_is_true_trimmed` 收掉 xlsx 里五份 `attr_true`。`attr_on`、`attr_bool`、`attr_on_off` 的裁空白、大小写和缺省值不一样，留在原处。`find_child` 前面已经删过。
- 批注的 GUID 和时间收进 `host_env`。当时两份 `unix_to_dt` 的月份都是 `i + 1`，合成一份。SmartArt、自定义视图和节的 GUID 格式不同，没有并进来。
- 有调用方的 `allow(dead_code)` 删掉标记。没有调用方的 `normalize_source`、`container_id`、`body_para_of` 删掉。只解析不读取的 `id` 和 `initials` 不再存进结构，解析时的校验还在。`crates/ooxp/src` 里已经没有 `allow(dead_code)`。
- `lib.rs` 的测试挪到 `facade_tests.rs`。这些测试共用 `part_text`，要打开私有的 `Package`，所以留在库内，没有为了挪测试把 `Package` 公开。
- `chart/remain.rs` 改名为 `series_decor.rs`。`xlsx/create_remain.rs` 改名为 `create_extra.rs`。`docx/create_round4.rs` 改名为 `create_doc.rs`，`create_round5.rs` 改名为 `create_para.rs`。每个文件本来就是一块领域，只是名字按批次起的，没有再拆。`theme_remain.rs` 已经在主题合并里改成 `theme_fields.rs`。架构文档原先没有列出这些文件名。
- `xlsx/apply.rs` 里按名字找工作表、并区分 `SheetNotFound` 与 `SetCellWorksheetOnly` 的三段，收成 `worksheet_part`。

审计收尾（2026-10-30）：

- GUID：`host_env::new_guid`（时间、进程号、计数）与 `random_guid`（随机字节）是唯二的生成函数。批注、自定义视图、节、域、媒体、Zoom、书目、构建基块、SmartArt `modelId` 都调它们，原来的 5 份副本已删。
- `host_env::unix_secs_nanos` 只被旧的 SmartArt GUID 用，已从 `install` 的参数和 `Env` 里删掉。项目没有历史用户，`install_clock` 少一个参数不需要兼容。
- `op_fields::require_id` 改成细分报错：类型不对报 `WrongType`，空串报 `NonEmptyString`，缺了才报 `MissingField`。`docx/watermark.rs` 的副本已删。错误码仍是 `InvalidField`。
- 保留：三份图表 op 解析只剩把共享结果填进各格式结构体；`custom_view.rs` 的 `attr_true` 额外接受 `on`，只此一处用。
