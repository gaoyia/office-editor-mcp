## 已锁定（写入契约后不要改）

- 先探测再写契约。Excel 16.0 `AddCommentThreaded` 另存得到：`/xl/threadedComments/threadedComment1.xml`（根 `ThreadedComments`，命名空间 `http://schemas.microsoft.com/office/spreadsheetml/2018/threadedcomments`，CT `application/vnd.ms-excel.threadedcomments+xml`，关系 Type `http://schemas.microsoft.com/office/2017/10/relationships/threadedComment`）；`/xl/persons/person.xml`（根 `personList`，CT `application/vnd.ms-excel.person+xml`，workbook 关系 Type `http://schemas.microsoft.com/office/2017/10/relationships/person`）；占位 `/xl/comments1.xml`（作者 `tc={顶层 GUID}`，`xr:uid` 同 GUID）；`/xl/drawings/vmlDrawing1.vml` 与工作表 `<legacyDrawing>`。
- id：`cell:{name}!{A1}/comment:{guid}`；回复 `{批注 id}/reply:{guid}`。`{guid}` 取 `threadedComment/@id` 原文，含花括号，精确匹配。`insertComment` 的 id 必须是单元格 id `cell:{name}!{A1}`。
- 每张 `worksheet` 始终有 `commentCount`（只计无 `parentId` 的顶层）。工作簿根上 `commentCount` 为各表之和。`scope.comments: true` 时该表带 `comments`。`chartsheet` / `dialogsheet` / `macrosheet` 没有 `commentCount` / `comments`。
- 回复是同部件里带 `parentId` 的 `threadedComment`，inspect 嵌在 `replies`，不另占 `commentCount`。
- 旧式 VML 批注（`comments.xml` 里作者不以 `tc=` 开头、或没有线程化部件）不进树。
- 不改已有 VML 框的几何。insert / delete 只追加或去掉对应 Note `v:shape`，并维护占位 `comments.xml`。
- `create` 本期不写批注。
- 对 `chartsheet` 发批注 op 报 `InvalidField`。对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。
- person 缺省 `providerId="None"`、`userId="Name"`。`initials` 接受但不写入 XML，树上恒为 `null`。
