## 已锁定

- 继续用现有 `setTransition`，不新开 op。仍整段替换 `<p:transition>`（含 AlternateContent）。不写 `<p:timing>`。不实现放映预览。
- 声音字段名 `sound`，与 `insertAnim` 同一套：写入是本地 WAV 路径，按文件头认；inspect 取 `sndAc/stSnd/snd/@name`，没有则为 `null`。不把字节塞进树。
- 有 `<p:transition>` 时 `sound` 始终出现。给了 `sound` 才写 `p:sndAc/p:stSnd/p:snd`，并可脏该宿主 `.rels`、`/ppt/media/…` 与 `[Content_Types].xml`。省略则不写 `sndAc`。不写 `loop`。不写 `endSnd`。
- `type` 为 `null` 时忽略 `dur` / `advClick` / `advTm` / `dir` / `invX` / `invY` / `sound` / `orient` / `spokes`，清整节，并丢掉该切换不再引用的音频关系。
- `orient` 只对 `split`：`horz` / `vert`，写在效果子元素上。省略则不写该属性。inspect 有该属性才出现该字段。
- `spokes` 只对 `wheel` / `wheelReverse`：整数 `1`–`8`。省略则不写。inspect 有该属性才出现该字段。ECMA-376 示例是 1 / 2 / 3 / 4 / 8；MS-PPTX `wheelReverse` 与 `p:wheel` 同型 `CT_WheelTransition`。
- `setTransition` 的 `id`：`slide:{n}`、`master:{n}`、`master:{n}/layout:{k}`。对 `slide:{n}/notes`、`notesMaster`、`handout` 报 `InvalidId`。ECMA-376 `CT_NotesSlide` / `CT_NotesMaster` / `CT_HandoutMaster` 没有 `transition`。
- 母版 / 版式在 `scope.masters` 下始终带 `transition`（没有则为 `null`），不另开 scope。字段插在 `theme` / `kind` 之后、`animCount` 之前。
- inspect 对象字段顺序：`type`、`dur`、`advClick`、`advTm`、`sound`，然后有则跟 `dir`、`orient`、`spokes`，再有则跟 `invX` / `invY`。
- create 的 `slides[].transition` 跟 `setTransition` 同一套新字段。本期不给 create 写母版切换。
- 根上切换计数不变。不写 `thruBlk`。
