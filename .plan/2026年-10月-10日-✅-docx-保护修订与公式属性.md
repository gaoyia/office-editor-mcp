### 例外编辑区

- 根上始终 `editRangeCount`，放在 `bookmarkCount` 之后。只计主文档 `w:permStart`（与 `permEnd` 成对）。页眉页脚容器另有自己的 `editRangeCount`。
- `scope.editRanges` 才有名单。每条字段顺序：`id`、`index`、`xmlId`、`edGrp`、`ed`、`host`、`text`。
- `id` 为 `perm:{n}` 或 `{页眉页脚容器}/perm:{n}`。`xmlId` 是 `w:id` 原文。`edGrp` / `ed` 取对应属性，缺为 `null`。`host` 是起点所在段落。`text` 为起止之间可见 `w:t`。
- 不成对的标记仍列出，`text` 为 `""`。框内 / 注内 / 批注内不编。
- `insertEditRange`：id 是正文或页眉页脚段落。把 `permStart` 插在 `pPr` 之后、内容之前，`permEnd` 插在段末。省略 `edGrp` 与 `ed` 时写 `edGrp=everyone`。两者都给报 `InvalidField`。`edGrp` 为 `everyone` / `administrators` / `contributors` / `editors` / `owners` / `current`。`xml id` 用下一个未占用非负整数。
- `deleteEditRange`：id 是 `perm:{n}`。删掉该对 Start/End，不删文字。
- 对框 / 注 / 批注 / 公式 / 表 id 发这两 op 报 `InvalidId`。xlsx / pptx 的 `scope` 里出现 `editRanges` 报 `InvalidField`。

### 节 formProt

- 节节点在 `pageBorders` 之后始终有 `formProt`。没有 `w:formProt` 为 `null`；OnOff 为开为 `true`，为关为 `false`。
- `setFormProt`：id 是 `section:{n}`。`formProt` 必填：`true` 写无 `val` 的 `formProt`；`false` 写 `val="0"`；`null` 删掉该元素。
- `setProtection` 打开窗体仍给各节写 `formProt`（无 val），关掉仍删掉各节 `formProt`。随后可用 `setFormProt` 把某节改成 `val=0`。

### writeProtection 哈希

- `setProtection` 增加可选 `writePassword`（非空）。算「至少一个可写字段」。空串报 `InvalidField`。
- 给了 `writePassword` 时写 `writeProtection`：`cryptProviderType=rsaAES`、`cryptAlgorithmClass=hash`、`cryptAlgorithmType=typeAny`、`cryptAlgorithmSid=14`、`cryptSpinCount=100000`、新 16 字节盐、`hash`/`salt` 标准 Base64。口令 UTF-16LE，`H0 = SHA-512(salt || password)`，再 `i = 0 .. 99999`。不写遗留预处理，不写 ISO `algorithmName` / `hashValue`。
- 已有 sid=14 且 hash/salt/spin 齐：改或删 `writeProtection` 必须给对得上的 `writePassword`；对不上报 `InvalidField`；不给却要改 `readOnlyRecommended` 或再写哈希报 `NotImplemented`。其它算法即使给了也报 `NotImplemented`。
- `writePassword` 且 `readOnlyRecommended: false`：校验后删掉 `writeProtection`。只给 `writePassword`：重写哈希。有哈希时 `recommended` 仍被忽略，树上 `readOnlyRecommended` 仍为 `false`。
- `password` 与 `writePassword` 可同时给，分别打到两个元素。只改限制编辑时不要动已有 `writeProtection` 哈希。
- create 出现 `writePassword` 报 `NotImplemented`。xlsx / pptx 出现该键报 `UnknownField` 或 `InvalidField`。

### 修订 move

- `kind` 增加 `moveFrom`、`moveTo`：不在属性容器里、直接子元素不是 `w:p` / `w:tbl` 的 `w:moveFrom` / `w:moveTo`。
- `text` 与 run 级 `ins` / `del` 相同（`moveFrom` 用可见 `w:t`）。`moveFromRangeStart` / `End` / `moveToRangeStart` / `End` 不另列。
- 接受 `moveFrom`：删掉该节点（含内容），并删掉包住它的同 `w:id` RangeStart/End。拒绝 `moveFrom`：拆壳留下内容，并删掉这对 Range。
- 接受 `moveTo`：拆壳留下内容，并删掉这对 Range。拒绝 `moveTo`：删掉该节点（含内容），并删掉这对 Range。
- 表结构 op、`setParaText` 碰到已收入的 move 仍报 `NotImplemented`。

### OMML

- 每条公式在 `kind` 之后、`host` 之前跟 `jc`。取父 `oMathParaPr/m:jc/@m:val`：`center` / `centerGroup` / `left` / `right`。没有该元素或行内为 `null`。不认识报 `XmlBroken`。
- `insertMath` / `setMath` 可选 `jc`。行内带 `jc` 报 `InvalidField`。`null` 删掉 `m:jc`（`oMathParaPr` 空则整段删掉）。显示公式写入 `oMathParaPr`。
- `expr` 增加 `phant`（`e`；可选布尔 `show` / `zeroWid` / `zeroAsc` / `zeroDesc` / `transp`，有则写 `phantPr`）与 `borderBox`（`e`；可选 `hideTop` / `hideBot` / `hideLeft` / `hideRight`）。`groupChr` / `box` 仍 inspect 为 `other`，apply 报 `InvalidField`。
- `type=text` 可选 `brk`：`true` 写 `m:rPr/m:brk`。inspect 有该元素为 `true`，否则不要该键。
- 仍忽略 `ctrlPr` / `m:rPr` 里除 `brk` 以外的属性。不写 `m:rPr` 字体。

### 参考文献样式

- 根上始终 `bibliographyStyle`，放在 `eastAsianSettings` 之后。没有 bibliography customXml 为 `null`。有则字段顺序：`selectedStyle`、`styleName`、`version`，取 `b:Sources` 对应属性原文，缺为 `null`。
- `setBibliographyStyle`：id 必须是 `docx:document`。`styleName` 必填：`APA` / `MLA` / `Chicago` / `IEEE` / `GB7714`。按上表写三个属性。没有 customXml 时按 `insertSource` 那套新建空 `b:Sources` 再改属性。
- 不认识的 `styleName` 报 `InvalidField`。不在库里跑 XSL。
