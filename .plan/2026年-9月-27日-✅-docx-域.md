## 目标

inspect 列出域指令与缓存结果。apply 能改指令字符串、能删域留下结果或留下指令。不在库里更新域结果（那是 Word 的域引擎）。

## 已锁定

- 真源仍是 XML。不在库里求值，也不打开 Word 再 Save 来刷新缓存。打开 Word 后由 Word 刷新是预期。
- 域 id 按该故事里被收入域起点的文档顺序：正文 `field:{n}`，页眉页脚 `{容器}/field:{n}`。`field:{n}` 在增删域之后会变，只够同一次 inspect 之后立刻 apply。
- 本期收入：配对完整的复杂域（`w:fldChar` 的 begin 与 end，ECMA-376 §17.16.18）以及 `w:fldSimple`（§17.16.19）。嵌套域各算一条，外层 `instr` 只含本层 `instrText` / `@instr`，不含嵌套域的指令。故事末尾尚未闭合的 begin 不进树（规范说此时不当域）。
- 框内 / 注内 / 批注内的域不进树；对这些容器发域 op 报 `InvalidId`。
- HYPERLINK 域进 `fields`，不进 `hyperlinks`（后者仍只收 `w:hyperlink` 元素）。
- TOC 域本期当普通域读写。生成目录块见目录计划。
- `setParaText`：目标段落在本期收入的域范围内（起点段、终点段、以及跨段域中间的段）时报 `NotImplemented`。
- apply：`insertField` 在段末写入复杂域（begin / instrText / separate / 可选结果 / end），begin 标 `w:dirty`。`setField` 只改指令，不改结果缓存。`deleteField` 的 `keep` 为 `result`（缺省，留下缓存结果）或 `instr`（留下指令当普通文本）。
- create 本期不写域。xlsx / pptx 的 `scope.fields` 与对应 op 报 `InvalidField`。pptx 的 `a:fld` 仍不收不改。
