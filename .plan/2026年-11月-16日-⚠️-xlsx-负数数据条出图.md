# 负数数据条与主题色数据条

状态：⚠️
日期：2026-11-16
分类：功能缺失→本刀有限交付

对应 C25 第 11 段，序号 **84**。x14 实心 + `axisPosition=middle` 的负数数据条本刀可画；仅主题色无 `rgb`、未知轴/cfvo/边框/渐变负条仍 NI。非负 ECMA 渐变条保持历史 10–90% 淡出。

## 机制（Excel 16.0 / x14 真源，2026-11-17 Asia/Shanghai）

- ECMA `dataBar` + 规则 `extLst` `{B025F937-…}` id → 表 `extLst` `{78C0D931-…}` `x14:conditionalFormattings` / `x14:dataBar`。
- **本刀可画**：`gradient=0` 实心；`axisPosition=middle`；`minLength=0`/`maxLength=100`；cfvo 仅 `min`/`max`；正色用 ECMA `color/@rgb`；负色：`negativeBarColorSameAsPositive=0`（或 Excel 省略该属性但仍写 `negativeFillColor`）用 `negativeFillColor/@rgb`，否则同正色；轴色 `axisColor/@rgb`（缺省黑）。
- 几何：格内中轴；正右负左；长度 ≈ `|v| / max(|values|) * half`；竖向 padding 上/下各 2px（与非负条一致）；零值只画轴。
- **明确 NI（不静默错画）**：`axisPosition` 非 middle / 缺省未知；非 min/max cfvo；`border=1`；非 LTR `direction`；主题色-only（无 rgb）；带负数的 x14 渐变条；PPT/`cellGradient` 参数不进 dataBar。
- 不把颜色抵消当 AA；不混 PPT gamma。CF `priority` / `stopIfTrue` / 显示 value 路径不改。
