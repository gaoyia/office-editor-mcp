## 已锁定

- 规则 id 为 `sheet:{name}/cf:{n}`，`n` 为该表全部 `<cfRule>` 文档顺序，从 1 计。不要套单元格 id。
- 每张 `worksheet` 始终有 `conditionalFormatCount`。有单元格切片时列出该表全部规则（`conditionalFormats`，可空），不按 inspect 范围过滤。
- 同一 `<conditionalFormatting>` 里多条规则共用 `sqref`；改一条的 `sqref` 改整块。
- apply 三个 op：`insertConditionalFormat`（工作表 id，始终新建一块一条）、`setConditionalFormat` / `deleteConditionalFormat`（规则 id）。
- 可写类型：`cellIs` / `expression` / `colorScale` / `dataBar` / `iconSet`。其它类型 inspect 列出，set 只许改 `sqref` / `priority` / `stopIfTrue` / `dxf`，或改成可写类型。
- 颜色写进 `dxf` / `styles.xml`，复用单元格样式的 font/fill/border JSON；能复用相同 `dxf` 就复用下标。`setCellStyle` 仍不改 `dxfs`。
- 公式不求值、不补 `=`。
- `extLst` 里的 `x14:conditionalFormattings` 不认识就原样留，本期不列不改。不写 x14 扩展数据条。
- 不标重算，不删 `calcChain`。create 本期不写条件格式。
- 手测编号 Xn，脚本 `manual-check/office/cases/xlsx-conditional-format.ps1`。Xn1–Xn5 于 2026-09-28 以 Excel 16.0 通过（5 PASS / 0 FAIL，收尾 Office 进程 0）。

## 不做

- 与 Excel 像素级一致的色阶
- 透视表上的条件格式可第二刀
- `top10` / `aboveAverage` / 文本类规则的 insert
- 求值

单元格样式。

## 验收

A1:A10 大于 0 填绿后 Excel 能看见规则；删规则无修复。
