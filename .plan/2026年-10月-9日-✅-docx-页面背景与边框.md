## 第 0 步结论（Word 16.0）

探测脚本 `_probe-docx-35-page-bg.ps1` 与 `_probe-docx-35-page-bg-2.ps1`（不要提交、不要进 `run.ps1`）。SaveAs2 曾挂住，走 TEMP 里 `Save()`。

- 页面颜色：COM `Background.Fill` 另存为 `<w:background w:color="FF0000"/>`，在 `w:body` 之前。COM RGB 按 BGR 打包，XML 是 RGB 六位十六进制。
- 同时写 `settings.xml` 空元素 `<w:displayBackgroundShape/>`。`Options.DisplayBackgrounds` 不存在；`ActiveWindow.View.DisplayBackgrounds` 可用。
- Word 另存还会补 footnotes / theme / webSettings / fontTable；apply 不要为背景或边框去建这些。
- `PageSetup.Borders` 无 `Enable`，四边 `Item` 为 Null。`Sections.Borders.Enable = true` 写出：
  `<w:pgBorders w:offsetFrom="page"><w:top/left/bottom/right w:val="single" w:sz="4" w:space="24" w:color="auto"/></w:pgBorders>`
  插在 `pgMar` 之后。Word 另存还写 `bordersDoNotSurroundHeader` / `bordersDoNotSurroundFooter`；最小 XML 不写这两项 Word 仍无 Repair。
- 自行写入最小 `w:background` + `displayBackgroundShape`、或最小 `pgBorders`、或两者叠在一起，Word 打开标题栏无 Repair。

## 已锁定

- 根上始终 `pageBackground`，放在 `fontEmbed` 之后。对象字段顺序：`color`、`display`。没有 `w:background` 时 `color` 为 `null`；`display` 对应 `w:displayBackgroundShape`。本期只认 `@w:color`（六位十六进制或 `auto`）；不写 themeColor，不写 `w:drawing` 渐变。
- 节上始终 `pageBorders`，放在 `footerLink` 之后。没有 `w:pgBorders` 为 `null`。有则字段顺序：`offsetFrom`、`display`、`zOrder`、`top`、`left`、`bottom`、`right`。缺属性为 `null`。每边：`val`、`sz`、`space`、`color`。
- `setPageBackground`：id 必须是 `docx:document`。`color` 必填，字符串或 `null`。非空须是六位十六进制。写入时同时写 `displayBackgroundShape`；`null` 删掉 `w:background` 与 `displayBackgroundShape`。
- `setPageBorders`：id 必须是 `section:{n}`。`enabled: false` 删掉 `pgBorders`。否则可写 `offsetFrom`（`page`/`text`）、`display`（`allPages`/`firstPage`/`notFirstPage`）、`zOrder`（`front`/`back`）、四边对象或 `null`。边对象 `val` 必填。本期 `val` 只认 `nil`/`none`/`single`/`dashed`/`dotted`/`double`/`thick`/`wave`/`dashSmallGap`/`dotDash`/`dotDotDash`。不写艺术型 `art`。
- 不要为这两条 op 新建 footnotes / theme / webSettings / fontTable。
