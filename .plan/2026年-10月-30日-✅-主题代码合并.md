## 目标

`xlsx/theme.rs` 有 1391 行，`docx/theme.rs` 有 1401 行。把路径前缀 `/xl/` 和 `/word/`、宿主名 `workbook` 和 `document` 统一换掉后，两份只差 14 行。这 14 行是 docx 把 `theme::inspect_override_full` 的函数体手抄了一遍，行为相同。

`pptx/request/theme_remain.rs` 里又有一组和上面两份相同的解析函数：

- `parse_fmt_*`
- `parse_scripts_at`、`parse_script_item`
- `parse_extra_scheme_*`、`parse_extra_colors`
- `parse_scheme_name`、`parse_hex_at`

做完后主题的解析和打补丁只在 `theme` 一处。xlsx、docx、pptx 各自只留宿主相关的部分：theme 部件从哪条关系找，id 叫什么，themeOverride 放在哪。

## 不做

- 不改主题相关 op 的字段、id 或错误码。
- 不动 pptx 的 `clrMap`、`clrMapOvr` 与幻灯片尺寸。这些是 pptx 自己的。
- 不把 `schemeClr` 展开成 RGB。

### 1. 文档

在 `docs/architecture.md` 模块清单里写明：

- `theme` 负责主题 op 的字段解析、inspect 与 XML 补丁。
- 格式模块只交给它：theme 部件名、themeOverride 部件名、宿主 id 的写法。

### 2. 宿主描述

- 定义一个小结构，放这几样东西：部件目录、宿主 id 前缀（`workbook` 或 `document`）、找 theme 部件的方法、themeOverride 的部件名。
- `xlsx/theme.rs` 与 `docx/theme.rs` 里的约 40 个函数搬进 `theme`，参数里带上这个结构。
- 两个格式文件各自只剩构造宿主描述的代码，外加对 `theme` 的转发入口。
- docx 读 themeOverride 改调 `theme::inspect_override_full`。

### 3. pptx

- `theme_remain.rs` 里与上面相同的解析函数删掉，改调 `theme`。
- 删完如果这个文件还有剩下的内容，按领域改名，不再用 `remain` 这个名字。

### 4. themeOverride 新建

- 合并 `xlsx/theme.rs` 第 1335 行、`docx/theme.rs` 第 1345 行、`pptx/theme_map.rs` 第 241 行这三份。
- pptx 用的是编号部件名，由调用方传入部件名来区分。

### 5. 验收

- `xlsx_theme`、`docx_theme`、`pptx_theme_*` 这些测试全过，不改期望值。
- `cargo fmt --all` 与 `cargo clippy --all-targets --all-features -- -D warnings` 通过。
- 手测：用 Excel 16.0 和 Word 16.0 各打开一份改过配色和字体的文件，「页面布局 / 设计」里的主题颜色与改动一致。

### 验收记录

- 宿主描述是 `ThemeHost`：theme 部件名、themeOverride 部件名、宿主 id、错误路径前缀、id 错误原因、相对路径算法。xlsx 与 docx 只构造它并转发。
- docx 的 themeOverride inspect 改调 `inspect_override_full`，不再手抄函数体。
- pptx 相同的解析函数改调 `theme::ops`。剩下和宿主绑在一起的三份解析放在 `theme_fields.rs`。
- 三份新建 themeOverride 收成 `install_override`。pptx 传入编号部件名，并总是补关系；xlsx 与 docx 用固定部件名，已有关系时不重复补。
- `xlsx_theme`、`docx_theme`、`pptx_theme_size`、`pptx_theme_clrmap`、`pptx_theme_notes_handout` 期望没改，全过。
- Excel 16.0：`xlsx-theme.ps1` 5 PASS。打开改过配色和字体的文件不报修复，accent1 为 `FF0000`，majorLatin 为 Arial。
- Word 16.0：`docx-theme.ps1` 5 PASS。主题色 accent1 的 RGB 为 255，主题字体为 Arial，不报修复。
