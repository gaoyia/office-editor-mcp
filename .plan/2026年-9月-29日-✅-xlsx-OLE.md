## 第 0 步结论（2026-09-29，Excel 16.0）

脚本：`manual-check/office/cases/_probe-xlsx-20-ole.ps1`（不进 `run.ps1`）。

COM：`$ws.Shapes.AddOLEObject([Type]::Missing, $file)`。Type=7。

xlsx 嵌入另存：

- 工作表 `<oleObjects>` 里**每条**一个 `mc:AlternateContent`：`mc:Choice Requires="x14"` 含 `oleObject` + `objectPr`；`mc:Fallback` 只有 `oleObject`
- `oleObject`：`progId="Worksheet"`（不是 `Excel.Sheet.12`）、`shapeId` 从 **1025** 起、`r:id` 在**工作表** `.rels`
- 关系 Type 为 `package`，目标 `/xl/embeddings/Microsoft_Excel_Worksheet.xlsx`（第二条 `…Worksheet1.xlsx`）
- `objectPr`：`defaultSize="0"`，`r:id` 指向预览图（工作表 `.rels` 的 image，另存为 EMF）；`anchor/@moveWithCells="1"`，子元素是无前缀 `from` / `to`（里面仍是 `xdr:col` 等；`CT_ObjectAnchor` 始终有 to）。库写入用 PNG 占位。
- 另有 `<drawing>`：`mc:AlternateContent` 是 `xdr:wsDr` 的子元素；`mc:Choice Requires="a14"` 里是整段 `xdr:twoCellAnchor editAs="oneCell"`（不是把 AlternateContent 塞进锚点）。隐藏 `xdr:sp`，`cNvPr/@id` 与 `shapeId` 相同，`name` 为「Object 1」，`hidden="1"`。Fallback 为空。`a14:compatExt/@spid` 为 `_x0000_s1025`
- 另有 `<legacyDrawing>` VML：只有 `_x0000_t75`（没有批注 `t202`）；`v:shape id="_x0000_s1025"`，`x:ClientData ObjectType="Pict"`，含 `x:CF` / `x:AutoPict`；`v:imagedata` 预览在 **VML** `.rels`
- 两条 OLE 可共用同一张预览图关系

txt 嵌入：`progId` 为系统语言下的包装程序名（本机中文「包装程序外壳对象」），关系 Type `oleObject` → `/xl/embeddings/oleObject1.bin`。库写入时用英文 `Package`，与 pptx 同一套分类。

## 契约（已锁）

- 只认工作表 `<oleObject>` 且带非 External、Type 后缀为 `oleObject` 或 `package` 的关系。有 `@link` 的链接对象、ActiveX `controls` 不进树。
- id：`sheet:{name}/ole:{shapeId}`，`{shapeId}` 取 `oleObject/@shapeId`。没有则 `sheet:{name}/ole:index:{k}`，`stable` 为 `false`。`{k}` 只在该表被收入的嵌入对象内从 1 计。
- 根与每张 `worksheet` 始终 `oleObjectCount`。`scope.oleObjects: true` 时展开该表 `oleObjects`。页眉、`chartsheet`、组合里的 OLE 本期不进树。
- 与 `shapeId` 相同的隐藏 `xdr:sp` 不进 `shapes` / `shapeCount`，也不当 `groupShapes` 成员。预览 EMF / PNG 不进 `pictures`。
- `exportMedia` 认 xlsx OLE id，写出 embeddings 部件，不是预览图。
- `insertOle` 的 id 必须是 `sheet:{name}`。只要 `file` 与 `from`。锚点字段对齐 `insertPicture`。缺 `cx` / `cy` 时用 `1828800` × `914400`。`objectPr.anchor` 始终写 `from`/`to`（oneCell 按列宽行高把尺寸换成 to，不保证与 Excel 像素级一致）。新 `shapeId` 取 `max(1024, 已有 oleObject/@shapeId, 已有 VML _x0000_s####)` 加 1。
- 写入：工作表 `oleObjects` 的 x14 AlternateContent（`objectPr/anchor` 的 `from`/`to` 无前缀）；工作表 `.rels` 的 package / oleObject 与预览 image；`xdr:wsDr` 下用 a14 AlternateContent 包整段 `twoCellAnchor`（`editAs="oneCell"`，`cNvPr/@hidden="1"`）；VML Pict 占位只写 t75（与批注 Note 同类伴随 markup，不是改表单控件 VML）。预览用库内 1×1 PNG。Office 文件 `progId` 用 `FileSpec::ole_obj_name()`（xlsx 为 `Worksheet`）。其它扩展名 `progId` 为 `Package`，打成 Ole10Native。
- `deleteOle` 的 id 必须是 OLE id。摘该条 AlternateContent / Fallback `oleObject`，摘 dummy `xdr:sp` 与对应 VML `v:shape`，清掉无人引用的关系与 embeddings / 预览。
- 不提供改尺寸、位置、图标、ProgID 的 op。create 本期不写 OLE（待做 25 也不含此项）。
