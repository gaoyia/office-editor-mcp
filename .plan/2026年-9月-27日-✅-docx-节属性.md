# docx 节属性

状态：✅ 文档、实现、库测试与 Word 16.0 手测已通过  
日期：2026-09-27

从 `roadmap/docx.md` 拆出待做序号 0。距边界只读写了 `w:pgMar` 的 `header` / `footer`。本期补上上下左右、装订线、纸张、方向、分栏、垂直对齐、行号、文档网格，以及整篇镜像边距与装订线在上。

## 目标

节节点补上页面边距、纸张尺寸与方向、分栏、垂直对齐、行号、文档网格。apply 只改点名的属性。没有 `w:pgMar` / `w:pgSz` 时插入，不编造未点名的默认值。

## 已锁定

- 距边界 op 继续只动 `header` / `footer`，不要把四边距塞进 `setHeaderFooterDistance`。
- 不猜 Word 默认一英寸。属性不存在就是 `null`。
- 不分页、不算「这一节有几页」。
- 节节点字段顺序：`id`、`index`、`headerDistance`、`footerDistance`、`top`、`bottom`、`left`、`right`、`gutter`、`pageWidth`、`pageHeight`、`orient`、`columns`、`vAlign`、`lineNumbering`、`docGrid`、`rtlGutter`、`headerLink`、`footerLink`。
- 文档根在 `sections` 之后增加 `mirrorMargins`、`gutterAtTop`（`settings.xml` 里对应 OnOff；缺部件或缺元素为 `null`）。
- `rtlGutter` 在节上（`w:sectPr`）；`mirrorMargins` / `gutterAtTop` 在整篇 settings。
- apply 九个 op：`setPageMargin`、`setPageSize`、`setColumns`、`setVerticalAlign`、`setLineNumbering`、`setDocGrid`、`setRtlGutter`（`id` 为 `section:{n}`）；`setMirrorMargins`、`setGutterAtTop`（`id` 为 `docx:document`）。
- `top` / `bottom` 允许负数（`ST_SignedTwipsMeasure`）。`left` / `right` / `gutter` 与距边界一样非负。
- 改 `orient` 不自动对调 `pageWidth` / `pageHeight`。
- `setColumns` / `setLineNumbering` / `setDocGrid` 的 `enabled: false` 删除对应元素；不要写 `enabled: true`。
- create 仍写现在的最小 `pgSz` / `pgMar`，不在本期补分栏或网格。

## 不做

- 排版引擎
- 插删节（见插删节计划）
- `w:pgNumType`、`w:type`（分节符类型）、`w:paperSrc`、`w:pgBorders`
