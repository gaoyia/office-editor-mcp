# xlsx 公式：查找与引用

状态：✅
日期：2026-11-11

对应 `roadmap/xlsx.md` 待做序号 **59**。前置：序号 50 的求值器。`HYPERLINK` 已有，不重写。

## 目标

实现 §18.17.7 查找与引用类里还没有的函数，并把结果写入 `<v>`。

- 查找：`CHOOSE`、`HLOOKUP`、`LOOKUP`、`MATCH`、`VLOOKUP`、`INDEX`
- 位置：`ADDRESS`、`COLUMN`、`COLUMNS`、`ROW`、`ROWS`、`OFFSET`、`AREAS`
- 间接：`INDIRECT`、`TRANSPOSE`
- 其它：`GETPIVOTDATA`、`RTD`

## 不做

- 不重写 `HYPERLINK`。
- 不实现 `XLOOKUP`、`XMATCH`、`FILTER`、`UNIQUE`、`SORT`。第五版类目表没有这些名字。
- `TRANSPOSE` 只铺进已经写好的数组公式 `ref`。普通格子写入 `#VALUE!`。
- 不连接 RTD 服务器。没有服务器时写入 `#N/A`，不带 `ca="1"`。
- 不把认不出的函数写成 `#NAME?`。`ECMA.VLOOKUP` 不求值。

## 写法

- `VLOOKUP` 与 `HLOOKUP` 精确匹配不区分大小写，并认 `*` 和 `?`。近似匹配取不超过查找值的最后一项。找不到是 `#N/A`。
- 找到之后，序号小于 1 是 `#VALUE!`，超出是 `#REF!`。还没找到时，序号不对也是 `#N/A`。
- `MATCH` 的 0 是精确，正数是升序近似，负数是降序。`MATCH(4,{9,5,1},-1)` 是 2。
- `INDEX` 返回引用。序号 0 表示整行或整列。`OFFSET` 与 `INDIRECT` 也返回引用，公式带 `ca="1"`。
- `ADDRESS` 的绝对号 1 到 4 分别写成 `$C$2`、`C$2`、`$C2`、`C2`。R1C1 对应 `R2C3`、`R2C[3]`、`R[2]C3`、`R[2]C[3]`。
- `GETPIVOTDATA` 按已经写进格子的数回答，见已过 76。对不上是 `#REF!`。没画出来的形状不写缓存。
