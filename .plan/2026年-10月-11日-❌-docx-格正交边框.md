inspect 格上只有 `tl2br` / `tr2bl`。`setCellFormat` 的 `top` / `left` / `bottom` / `right` 是 `tcMar`，不是 `tcBorders` 四边。60 曾把本项写成「不做、不另开」。四边能开，所以另开。

## 目标

## 已锁定

- inspect 格字段在 `cellMar` 之后、斜线之前加 `borders`。没有正交边且没有格内内外框则为 `null`。
- `borders` 字段顺序：`top` / `left` / `bottom` / `right` / `insideH` / `insideV`。每边与页面边框同一套 `val` / `sz` / `space` / `color`。缺该边则为 `null`。
- `left` 先取 `w:left`，没有则取 `w:start`。`right` 先取 `w:right`，没有则取 `w:end`。写入 `left` / `right`，并去掉对应的 `start` / `end`。`insideH` / `insideV` 与 `CT_TcBorders` 同名，不要留给以后。
- 新 op `setCellBorders`。id 必须是单元格 id。值为对象或 `null`（去掉正交边与格内内外框，斜线留下）。对象里未点名的边留下。某边 JSON `null` 去掉该边。
- 不要复用 `setCellFormat` 的 `top` 等字段名。不要和 60 的表级 `setTableBorders` 混。斜线仍走 `setCellFormat`。
- create：`cellFormats[]` 可带 `borders`，不要 `id`。
- 框内表同样认。xlsx / pptx 上发此 op 报 `InvalidField`。
- 手测编号 **Tcb**。脚本 `manual-check/office/cases/docx-cell-borders.ps1`。不要和 Tc、Tb、Tf、Tbdr 撞。
