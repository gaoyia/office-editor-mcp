## 探测结论（Word 16.0）

COM `WdContentControlType`：0 富文本、1 纯文本、2 图片、3 组合框、4 下拉、5 构建基块、6 日期、7 组合、8 复选、9 重复节。10–16 一律「命令失败」。没有公式控件的 COM Type。`Selection.InsertEquation` 不存在。

**复选（Type=8）**：折叠空选区 `ContentControls.Add(8)` 成功。另存：

```xml
<w:sdtPr>
  <w:id w:val="…"/>
  <w14:checkbox>
    <w14:checked w14:val="1"/>
    <w14:checkedState w14:val="2612" w14:font="MS Gothic"/>
    <w14:uncheckedState w14:val="2610" w14:font="MS Gothic"/>
  </w14:checkbox>
</w:sdtPr>
<w:sdtContent>
  <w:r>
    <w:rPr>
      <w:rFonts w:ascii="MS Gothic" w:eastAsia="MS Gothic" w:hAnsi="MS Gothic" w:hint="eastAsia"/>
    </w:rPr>
    <w:t>☒</w:t>
  </w:r>
</w:sdtContent>
```

勾选符 U+2612，未勾 U+2610。命名空间 `http://schemas.microsoft.com/office/word/2010/wordml`（与 `w14:paraId` 相同）。MS-DOCX `CT_SdtCheckbox`：内容必须是单个字符。

**图片（Type=2）**：不能套在普通文字上。Word 对话框原文：「无法插入图片控件。在包含非图像内容、浮动图像或多个内嵌图像的所选内容周围。」折叠空选区插入占位成功：`w:picture` + `w:showingPlcHdr` + 一张 `wp:inline`（约 1905000 EMU，媒体 `word/media/image1.png`）。套已有一张行内图成功：`w:picture`、无 `showingPlcHdr`；若该段只有图，Word 会写成块级 `sdt`（`sdtContent` 里一个 `w:p`）。本期插入仍只写段内行内 `w:sdt`，内容是调用方 `file` 生成的 DrawingML，不写占位图、不写 `showingPlcHdr`。

**组合（Type=7）**：`ContentControls.Add(7, Range)` 对单段、两段、去掉段落标记一律「所选内容无效」。先 `Range.Select()` 再 `Add(7)`（不传 Range）成功。Word 写成块级 `w:group`，并带 `w:lock w:val="contentLocked"` 与 `w:placeholder`。手写块级 `w:group` 包一个 `w:p`、手写行内 `w:group` 包一个 `w:r`，Word 打开均为 Type=7，无 Repair，不必写 lock / placeholder。本期 `insertContentControl` 仍在段末追加行内外壳。

**公式**：COM 不把 `w:equation` 算进 `ContentControls`（Count=0）。手写 `<w:equation/>` 包 `w:r`/`w:t` 或包 `m:oMath`，另存仍保留该元素，标题栏无 Repair。ECMA-376 §17.5.2.16：有 `w:equation` 只表示类型，不要求内容只能是公式。inspect 读 XML，不依赖 COM。

## 契约

- 现有 `kind` 保留。新增：`checkbox`（`w14:checkbox`）、`picture`（`w:picture`）、`group`（`w:group`）、`equation`（`w:equation`）。
- `docPartObj` / `docPartList` / `bibliography` / `citation` 仍不进内容控件名单。
- inspect 字段顺序仍是 `id`、`index`、`kind`、`level`、`host`、`tag`、`alias`、`xmlId`、`bound`、`parent`、`text`；`checkbox` 再跟 `checked`（布尔）。不把图片字节放进树。
- `insertContentControl` 仍只写行内 `w:sdt`。`plainText` 等旧 kind 仍必填非空 `text`。
- `checkbox`：不要 `text` / `file` / `items` / `fullDate`。`checked` 可选，缺省 `false`。写出 Word 那套 `checkedState` / `uncheckedState` 与对应符号字符。
- `picture`：必填 `file`（规则与 `insertPicture` 相同），不要 `text` / `checked` / `items` / `fullDate`。内容是一张行内 DrawingML，复用 `insertPicture` 的媒体与 `wp:inline`。
- `group` / `equation`：必填非空 `text`，内容仍是一条 `w:r`/`w:t`。
- `setContentControl`：`checkbox` 必填 `checked`、不要 `text`/`file`；`picture` 必填 `file`、不要 `text`/`checked`；`group` 报 `NotImplemented`；`equation` 与旧 kind 一样靠 `text` 换内容。
- 框内 / 注内 / 批注内仍不编。

## 不做

- 开发者模式 UI、自定义 XML XPath
- 把目录 / 书目 / 引文控件改成通用 sdt
- 排版引擎、任意控件外观全集、Word 占位图字节
- 块级组合去包已有多段（不新开 wrap 类 op）
