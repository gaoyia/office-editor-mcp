# 工作表旋转与两端对齐

状态：⚠️
日期：2026-11-16
分类：功能缺失

对应 C25 第 8 段，序号 **84**。一类一段，本切片只做单元格 `textRotation` 与水平 `justify` / `distributed`。文件名仍为 ❌：步骤 2 官方像素对照未做，不把实现或内部测试算作用户验收。不要与稍后的「非直角组合旋转」（图形组合转角）混淆，也不把本项扩大到全部 Excel 文字布局。

## 目标

点名的旋转单元格，以及点名的两端或分散对齐，与 Excel 16.0 差 0。对不上继续 `NotImplemented`。

2026-11-17（Asia/Shanghai）实现记录（非用户验收，亦非官方对照通过）：

步骤 0：已锁定本切片可独立核验、不必先凭官方导出调参的档，契约写入 `exportSheetImage`。水平对齐继续画 general/left/center/right，以及已交付的换行与缩进（`Face::width`，一级 = 三倍空格宽，不搬 Word `typo_width`）。水平 `justify`：ECMA 规定「若没有任何一行发生换行，则不做两端对齐」——无软换行、indent=0、且不是数字/布尔时按既有左对齐画。水平 `distributed`：ECMA 规定各词左右顶齐；两词时空隙唯一确定，按左右内缘顶齐画，缩进同时加在两侧。非 0 `textRotation`（0–180 及 Excel 堆积 255）、`shrinkToFit`、`justifyLastLine`、发生软换行或带缩进的 justify、不是恰好两词的 distributed、fill、centerContinuous、垂直 justify/distributed 仍明确 NotImplemented，不默默画不完整图。未用到的样式里有非 0 旋转不再整表失败。普通水平排版、RTL、合并/clip、日期 ###、错误绿标、换行缩进合同未改。

步骤 1：已实现上述锁定档，覆盖新建导出、像素/语义对照（无软换行的 justify 与 left 图字节一致；两词 distributed 右词在右半）、反例 NI、源包不变，以及与换行缩进同表共存。未打开 Office，未做步骤 2。非直角/堆积旋转的锚点与词间加空的官方几何仍缺，不猜测合同。

步骤 2 前置：要对齐旋转文字或软换行两端/多词分散的位置与黑框，需要 Excel 16.0 `Range.CopyPicture`（Zoom 100%，库侧 96 dpi）同源官方导出，至少覆盖：textRotation 90 / 180 / 45 / 255 堆积、软换行 justify 的词间空隙、3 词及以上 distributed、数字/布尔的 justify。本切片未取得这些证据，不凭截图调参，也不把内部测试勾成官方通过。

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。
