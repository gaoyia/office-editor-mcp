## 已锁定（写入契约后不要改）

- id 不走 docx 的 `comment:{w:id}`。用 `slide:{n}/comment:{guid}`；回复 `slide:{n}/comment:{guid}/reply:{guid}`。GUID 保留花括号，按文件原文精确匹配。
- pptx 认 `scope.comments`。xlsx 仍拒绝。
- `insertComment` 的 `id` 必须是 `slide:{n}`（不要 notes）。不提供字符偏移；可选 EMU `x`/`y`，缺省用幻灯片空白处。
- `create` 不写批注。
- 墨迹批注除 `deleteComment` 外报 `NotImplemented`。
- 批注内图本期不进树。对批注 id 发 `insertPicture` 仍 `InvalidId`。
- `replyComment` 的 id 是父批注容器 id，写入 `replyLst`。
- `setCommentDone`：`done: true` 写 `status="resolved"`；`false` 去掉 `status`。
- 旧式 §19.4 部件忽略：只有旧式时 `commentCount=0`。insert 只写现代部件。
- 找 comments 关系必须比完整 URI `http://schemas.microsoft.com/office/2018/10/relationships/comments`。
- xlsx 批注仍另开。docx 批注契约不动（`start`/`end`）。
