## 已锁定

- 不走 `ExecuteMso`、不走 COM `AddZoom`。与 21 相同：宿主是 `p:graphicFrame`，包在 `mc:AlternateContent` 的 Choice 里。
- 摘要缩放 uri 为 `http://schemas.microsoft.com/office/powerpoint/2016/summaryzoom`，`Requires` 为 `psuz`。
- `summaryZm` 下按 `targets` 顺序写 `summaryZmObj`（`@sectionId` 为节 GUID），再写空的 `gridLayout`。每个 `zmPr` 自带 GUID 与 `p166:blipFill`。
- Fallback 仍是一张 `p:pic`，`a:hlinkClick` 跳到 `targets` 第一节的第一页。预览用最小 PNG，不进 `pictures`。
- `insertZoom`：`type=slide` / `section` 仍用 `target`；`type=summary` 必须用 `targets`（节 id 数组，至少一条、不许重复）。两类字段不能同时给。
- `setZoom`：id 是 Zoom id。`target` 改幻灯片缩放 / 节缩放的目标；`targets` 改摘要缩放的节名单；`file` 换成自定义封面（各 `zmPr` 写 `imageType="cover"`）。至少给其中一个。不改种类。不写 timing。
- create 仍拒绝 `slides[].zooms`。备注 / 母版上的 Zoom 走 31 的宿主，本切片不新开母版专用 op。
- 不算放映引擎。不按新画布重排。不把 Fallback 预览并进 `pictures`。

## 不做

- create 带 Zoom
- 旧式批注上的 Zoom
