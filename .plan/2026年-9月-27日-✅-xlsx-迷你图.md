## 已锁定（写入契约后不要改）

- 真源是工作表 `<extLst>/<ext uri="{05C60535-1F16-4FD2-B633-F4F36F0B64E0}">/<x14:sparklineGroups>/<x14:sparklineGroup>`（MS-XLSX §2.2.4.12、§2.4.8）。URI 大小写不敏感。Excel 16.0 另存把 `xmlns:x14` 写在该 `ext` 上，把 `xmlns:xm` 写在 `sparklineGroups` 上。不是单元格属性，也不是图表 `xdr:graphicFrame`。
- 名单挂在该 `worksheet` 上，不挂在单元格节点上。每张 `worksheet` 始终有 `sparklineCount`（组数，不是组内 `sparkline` 条数）。工作簿根上 `sparklineCount` 为各表之和。`scope.sparklines: true` 时该表带 `sparklines`，不依赖单元格切片。
- id：`sheet:{name}/spark:{n}`。`{n}` 从 1 起，按该表全部 `x14:sparklineGroup` 的文档顺序。增删之后序号会变。
- 每组树上字段顺序：`id`、`index`、`type`、`displayEmptyCellsAs`、`sparklines`。`type` 为 `line` / `column` / `stacked`（XML `ST_SparklineType`，缺省 `line`）。`displayEmptyCellsAs` 为 `gap` / `span` / `zero`（XML 缺省按 schema 当作 `zero`；Excel 16.0 插入写 `gap`）。`sparklines` 是组内 `<x14:sparkline>` 数组，每项字段顺序：`ref`、`formula`。`ref` 取 `xm:sqref`，能解析成单格则规范化；否则原文或 `null`。`formula` 取 `xm:f` 原文，缺则为 `null`。不把颜色、标记点、坐标轴、`xr2:uid` 放进树。
- `insertSparkline` 的 id 必须是 `sheet:{name}`（worksheet）。必填 `ref`（恰好一格）与 `formula`（数据范围字符串）。可选 `type`，缺省 `line`。每次插入新建一组、组内一条。`formula` 若能解析成无表名前缀的 A1，写入时加上当前表名（`Sheet1!B1:F1`，不加 `$`）；已含 `!` 或解析不成 A1 的原文留下。能解析成 A1 却既跨行又跨列报 `InvalidField`。
- `setSparkline` / `deleteSparkline` 的 id 必须是迷你图组 id。`setSparkline` 认 `type` / `ref` / `formula`。至少给一个。该组若有多于一条 `sparkline`，给 `ref` 或 `formula` 报 `InvalidField`（只改类型可以）。
- 宿主格与已有迷你图宿主相交报 `InvalidField`。
- 对 `chartsheet` 发迷你图 op 报 `InvalidField`。对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。
- `create` 本期不写迷你图。`sheets[]` 出现 `sparklines` 报 `UnknownField`。
- 不新建部件、不写关系、不标重算。`setCell` 不改 `extLst`。`renameSheet` 不自动改 `xm:f` 里的表名。
- 其它 `ext`（扩展校验、扩展条件格式等）原样留下。

- 一次插入一组多条
- create 写迷你图
