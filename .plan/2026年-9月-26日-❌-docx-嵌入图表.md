# docx 嵌入图表

状态：❌ 未开始  
日期：2026-09-26

图表不是 `pic:pic`。本期编辑图表部件和缓存数据，不画图、不实现图表渲染引擎。

规范线索：宿主是 `w:drawing` 里 `a:graphicData` 的 chart URI，关系指向 `/word/charts/chartN.xml`（ECMA-376 §21.2）。数据常在 `c:externalData` 的 embedding（`/word/embeddings/….xlsx`）以及 chart 里的 `c:numCache` / `c:strCache`。图上的标签、系列、轴都在 chart 部件，不在主文档。

xlsx 工作表里的图与图表不在本计划。

## 目标

主文档（以及页眉页脚，若有）里的嵌入图表能列、改标题、改系列数据、增删系列、改类型、改轴标题与图例开关、插入与删除。Word 打开时自己重画。

## 稳定 id

| 节点 | id | 例子 |
| --- | --- | --- |
| 正文图表 | `{段落 id}/chart:{docPrId}` | `para:3F2A1B00/chart:7` |
| 页眉图表 | `{页眉段落 id}/chart:{docPrId}` | `header:default:1/para:AA/chart:7` |
| 系列 | `{图表 id}/series:{idx}` | `para:3F2A1B00/chart:7/series:0` |

`{idx}` 从 0 起，按 chart 部件里系列出现顺序。没有 `docPr/@id` 时用 `chart:index:{k}`。只认 graphicData 的 chart URI。`w:drawing` 里同时有图和图表的，各走各的名单。

## inspect

- 无 `scope.charts` 时只有 `chartCount`。
- 名单字段：`id`、`docPrId`、`name`、`type`、`title`、`series`、`legend`、`dataLabels`、`stable`。
- `series[]`：`id`、`index`、`name`、`categories`、`values`。cache 与 embedding 不一致时以 embedding 为准，并在该系列上标 `cacheStale: true`。
- 不把图表画成图，不读图表的渲染缓存图（若包里有）。

## apply

改数据必须同时改 cache（否则 Word 可能仍显示旧数）。有 embedding 时用现有 xlsx 路径写单元格，不要在库里求值公式。

`setChartType` 只改系列的 `c:barChart` 等包裹元素，能保持的数据留下；不能无损转换时报 `NotImplemented`，不要写出 Word 要修复的包。

插入图表：最小 Transitional chart、一份最小 embedding 工作簿、主文档关系。`wp:docPr/@id` 按该部件已有最大值加 1。

## 不做

- 图表渲染、布局算法、趋势线拟合
- 数据透视图表的透视计算
- 把图表当成 `replacePicture` 的位图来换
- xlsx 工作表图表（另开）
- SmartArt（另开）

## 验收

- Word 另存柱形图；inspect 的类型、标题、系列值与数据表一致。
- `setChartSeries` 后 Word 打开无修复，数据表是新值。
- 插入一张饼图、删除一张图，无修复。
- 改类型为折线，Word 按折线显示（允许样式重置）。
- 组合图 apply 改类型时得到明确 `NotImplemented`，文件未写坏。
