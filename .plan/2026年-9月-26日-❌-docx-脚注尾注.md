# docx 脚注与尾注

状态：❌ 未开始  
日期：2026-09-26

脚注、尾注是独立故事，不进现行正文 `paragraphs`。本期把部件和引用做成可查可改。不做注区排版。

规范线索：ECMA-376 §17.11。部件常见路径 `/word/footnotes.xml`、`/word/endnotes.xml`。引用是正文（或框、页眉）里的 `w:footnoteReference` / `w:endnoteReference`，用 `w:id` 对上 `w:footnote` / `w:endnote`。`w:type` 为 `separator`、`continuationSeparator`、`continuationNotice` 的是分隔符，不是用户注。

## 目标

用户脚注、尾注能列、读、改字，能在指定段落插入或删除，能改编号规则。注里的图复用图片 op。注里的文本框等文本框计划落地后再接同一套前缀。

## 稳定 id

| 节点 | id | 例子 |
| --- | --- | --- |
| 脚注 | `footnote:{id}` | `footnote:2` |
| 尾注 | `endnote:{id}` | `endnote:2` |
| 注内段落 | `{注 id}/para:{paraId}` | `footnote:2/para:3F2A1B00` |
| 注内图 | `{注内段落 id}/pic:{docPrId}` | `footnote:2/para:3F2A1B00/pic:1` |

`{id}` 取 `w:footnote/@w:id` / `w:endnote/@w:id` 的原文，按十进制数值匹配。分隔符用 `footnote:sep:{type}` 只出现在 `noteSeparators`，不接受 apply。

同一文件里脚注 id 与尾注 id 可以都是 `2`，靠前缀区分。拿正文 `para:` 改注内同 hex 报 `IdNotFound`。

## inspect

- 省略 `scope.notes` 时仍有两个计数，没有名单。
- 给了 `notes: true` 就返回全部用户注，不再分页（注通常不多）。单篇注特别长时，注内段落跟正文一样要 `from`/`maxParas` 还是一次倒出，写契约时定；默认一次倒出该注全部段落。
- 每条注字段：`id`、`noteId`、`type`、`host`（引用所在段落 id，多引用都列出）、`paraCount`、`pictureCount`。
- 正文段落上可标 `footnoteRef` / `endnoteRef`（id 数组），便于从正文跳到注。无 scope 切片时不出现。

## apply

插入注：分配未占用的 `w:id`（跳过分隔符占用的 0、1 等），写引用 run（保留 `w:rPr` 若插在已有引用旁则新建 run），写注部件一条 `w:footnote`/`w:endnote`（至少一段）。没有注部件则新建部件、关系、Override。

删除注：去掉所有匹配引用，去掉注元素。不得删分隔符。已经不存在则 `IdNotFound`。

编号：只改被点名的属性，不重算页面上的序号（序号由 Word 打开时画，那是渲染）。

## 不做

- 注区位置、分栏、续排线怎么画
- 把分隔符当用户内容改字
- 交叉引用域做成独立节点（域仍按现行规则：inspect 不收指令）
- xlsx / pptx 上发这些 op

## 验收

- Word 另存带脚注与尾注；计数与 `host` 对；分隔符不进用户名单。
- 改注内文字，正文未改，Word 无修复。
- 插入脚注后 Word 能看见引用与注文；删除后引用与注文都消失。
- 改 `numFmt` 后 Word 显示的编号样式变了（允许打开时才重画）。
- 注内换图无修复。
