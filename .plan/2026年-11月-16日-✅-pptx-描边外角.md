# 幻灯片描边外角

状态：✅ 已完成
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。手测已记：线宽 9525 和 19050 的直边是整像素，四个外角各有一个覆盖不同的半透明像素。已合入 main 的圆角直边单元测试（PR4）不是这一项。没有描边的不透明纯色圆角矩形官方直边和拐角已另案差 0，见 `.plan/2026年-11月-16日-✅-pptx-圆角矩形直边收口.md`，不得当作本项（直角矩形描边外角）已覆盖圆角描边。

## 目标

不透明直角矩形在恰好 1 或 2 像素的整像素线宽下，描边外角与 PowerPoint 16.0 差 0。对不上就继续不画，不加大容差，不在对照图上补像素。

## 验收

- 轴对齐、不透明、`prst` 为 `rect` 的实线描边，线宽恰好是 1 或 2 像素（9525 / 19050 EMU）时，用 GDI+ `DrawRectangle` 抗锯齿绘制：1 像素无像素偏移，2 像素半像素偏移，圆角接缝，平头线帽，叠在已有页底上。填充可以是不透明 `srgbClr` / 没有颜色变换的 `schemeClr`，或 `noFill`。外角与 PowerPoint 16.0 对齐。非整像素原点先按现有 `emu_px` 取整。
- 手测 `pptx-preview-stroke-image`：1 像素的方形、扁、高、另一原点、蓝底红边、无填充、20 像素小框，2 像素的方形、扁、另一原点、蓝底红边、无填充，1 像素非整像素 EMU 原点，以及白底黑边和蓝底红边在 `AABBCC` 页底上的样子。均为 1280×720、`differ=0`、`maxDelta=0`。已差 0 的横竖线、斜线、直角 L/Z 和弯曲连接符，以及 `pptx-slide-image` 没有回退。官方对照于 2026-11-16 21:51:43–21:57:38（Asia/Shanghai）跑完，PASS 126 / FAIL 0。
- 单元测试锁住 1 像素外角 48 / 16、2 像素外角 120 / 96 / 32，以及 `AABBCC` 页底上 1 像素外角 (36,38,41) / (12,13,14)。`insertShape` 只写 `line.color`、默认宽度 12700 的矩形仍整块不画。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不把圆角直边收口或已合入的单元测试算进本切片的通过
- 不在这一份里收 50% 填充混合或图片放大
- 不把全部描边泛称画完：默认 12700（约 1.333 像素）和其它宽度、虚线、箭头、显式的 `miter` / `bevel` / `round`、`algn` 不是 `ctr`、带旋转、半透明填充或描边、矩形上的渐变或图片再加描边，仍整块形状不画，页面继续成功
- 圆角矩形和椭圆的描边仍走原来的路径，不在这一份里收口
- xlsx 工作表图形描边未接线，仍未验证
