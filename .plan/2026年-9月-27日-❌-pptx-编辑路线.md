# pptx 编辑路线（不做渲染）

状态：❌ 只记账，不验收  
日期：2026-09-27

xlsx / docx 的图与图表都写过「pptx 另开」，本稿就是那条另开。第一期 pptx 只做了页名单和 `setShapeText`。渲染与完整动画时间轴永不做。每份计划仍是：先改当期 `docs/`，确认后再动代码。挂机一次只开一份，从序号 0 起。

pptx 模块不要引用 `docx::` 或 `xlsx::`。`c:chart`（§21.2）用 `crates/ooxp/src/chart/`。

## 永不做

- 排版引擎、与 PowerPoint 像素级一致
- 完整写入 `<p:timing>` / 动画时间轴（读清单可以另开，不进本表）
- 编辑 VML / `p:legacyDrawing`
- 默认把图片字节或 embedding 塞进 inspect 树
- 把 `p:pic` 当成 `slide:…/shape:…`（形状只收带 `p:txBody` 的 `p:sp`，已验收契约不拆）

## 不单开

- 组合 `p:grpSp` 里的图、图表、SmartArt：跟对应计划走，只展开符合条件的子节点，组合本身不进树
- 备注页、批注里的图：跟容器计划走，复用图片 op
- `exportMedia`：跟幻灯片图走，不另写动作名
- `exportChartData`：跟幻灯片图表走（pptx 有 embedding，规则对齐 docx）
