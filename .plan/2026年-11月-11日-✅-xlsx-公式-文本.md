# xlsx 公式：文本

状态：✅
日期：2026-11-11

对应 `roadmap/xlsx.md` 待做序号 **56**。前置：序号 50 的求值器。文本连接 `&` 已有，不是这片的函数。

## 目标

实现 §18.17.7 文本类，并把结果写入 `<v>`。文本缓存用 `t="str"`。

- 截取：`LEFT`、`LEFTB`、`RIGHT`、`RIGHTB`、`MID`、`MIDB`、`LEN`、`LENB`
- 查找与替换：`FIND`、`FINDB`、`SEARCH`、`SEARCHB`、`REPLACE`、`REPLACEB`、`SUBSTITUTE`
- 变换：`LOWER`、`UPPER`、`PROPER`、`TRIM`、`CLEAN`、`REPT`、`CONCATENATE`、`EXACT`、`T`、`VALUE`、`CHAR`、`CODE`
- 格式：`TEXT`、`DOLLAR`、`FIXED`、`BAHTTEXT`、`ASC`、`PHONETIC`。`JIS` 🚫

## 不做

- 不实现 `CONCAT`、`TEXTJOIN`、`TEXTSPLIT`。第五版类目表没有这些名字。
- 不把数字格式引擎做成通用渲染。`TEXT` 与 `DOLLAR` 只覆盖样本里出现的格式串。
- 不把认不出的函数写成 `#NAME?`。
- `JIS`：这台中文 Excel 16.0 打开 `JIS("A")` 是 `#NAME?`，函数不存在。不实现。

## 写法

- `LEFT`、`RIGHT`、`MID`、`LEN` 按 UTF-16 码元。字节版按 Windows ANSI 代码页。这台中文 Windows 上「中」是 2 字节，`CODE("中")` 是 54992，`CHAR(54992)` 回到「中」。全角「Ａ」的 `CODE` 是 41921，`LENB("ＡＢ１２")` 是 8。
- 截到双字节中间时，缺的那一字节换成空格。`LEFTB("AbC 中文",5)` 是 `AbC` 再加两个空格。`MIDB` 从第 4 字节取 2 个，是两个空格。`RIGHTB` 取末 3 字节，是一个空格加「文」。
- `FIND` 区分大小写。`SEARCH` 不区分。`?` 匹配一个码元，`*` 匹配任意长度。`SEARCH("中?",A1)` 是 5，`SEARCH("A*",A1)` 是 1。
- `FINDB("中")` 是字节位置 5。`SEARCHB("文")` 是 7。`REPLACEB` 删掉半个汉字时，留下的那一字节换成空格。
- `TEXT` 只认 `0.00` 和 `0%`。`DOLLAR(1234.5)` 是 `¥1,234.50`，`DOLLAR(-1234.5)` 是 `¥-1,234.50`。`FIXED` 的第三参为真时去掉千分位。
- `BAHTTEXT` 只写非负整数。0、1、21、1234 已有 Excel 16.0 样本。小数和负数不写缓存。
- `PHONETIC` 在格子没有拼音数据时返回原文，不编读音。
- `ECMA.LEFT` 不求值。`JIS` 见上文，不实现。
