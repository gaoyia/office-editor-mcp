## 已锁定

- 根上始终有 `theme`，不要另给 scope。来源是 workbook `.rels` 里 Type 以 `/theme` 结尾的部件。没有则为 `null`。
- 有部件时字段顺序与 docx 相同：`name`、`colors`、`fonts`、`fmt`。取值规则照抄 `crates/ooxp/src/theme.rs`。
- 根上始终有 `themeOverride`，放在 `theme` 之后。没有 Type 以 `/themeOverride` 结尾的关系则为 `null`。
- `setThemeColors` / `setThemeFonts` / `setThemeFmt` / `setThemeOverride` 的 id 必须是 `xlsx:workbook`。写入规则与 docx 相同。没有 theme 时前三条报 `IdNotFound`，不新建。`setThemeOverride` 缺则新建 `/xl/theme/themeOverride1.xml`。
- create：`workbook.theme` 可选。省略则仍不写 theme 部件。
- 不改 `styles.xml` 里格子的 `theme` 指数。docx / pptx 的 id 规则不变。
- 手测编号 **Xth**。脚本 `manual-check/office/cases/xlsx-theme.ps1`。不要和 Th、Ts、Xtf 撞。
