## 2026-11-17 有限核查（仍未差 0）

仓库与 `out/` 里此前没有 `SetSigmaBellShape` / `ChristopherVR` / `native-gradient-curve` 的实测记录，本轮才测这两条尚未验证的公开线索。不重复枚举已证伪的 GDI+ / D2D / GDI stock linear gamma± 模式。不重做文字灰度，也不重做已差 0 的不透明纯色圆角。t93u 只覆盖当前图片透明度，不适用于渐变，对照仍是 `MaxDelta=0`。不允许用渐变调色去补覆盖率，不改金样，不放宽容差，不硬编码样例。

### 像素类别

- 官方 `pptx-preview-fill-alpha-grad-px`（96×48、红到蓝、`alpha=50000`、页底 `AABBCC`、1280×720）：`differ=480`、`maxDelta=1`。框外几何为 0。480 个差像素全部是矩形内 10 条竖列的 R 通道差 1（10×48），不是描边或抗锯齿边。
- 官方 `pptx-preview-fill-shape-grad-px`（无描边不透明椭圆红到蓝 + 圆角矩形绿到品红，页底 `AABBCC`）：`differ=21103`、`maxDelta=6`。框外几何为 0。圆角直边中段已经接近现有 S 曲线（多数列差 0 或 1）；左、右端第一列金图是端点纯色 `00AA00` / `AA00AA`，现实现是 `06AA06` / `AA06AA`（`maxDelta=6`）。椭圆内部同样是曲线差 1，不是单纯几何跑偏。

### 新机制结论

- `ChristopherVR/ooxml` `0f1e8d877e87edeae94bbb59890a078ca581cbc6` 的 `native-gradient-curve.ts` 把 `OFFICE_SIGMA_FACTORS` 记为 GDI+ `SetSigmaBellShape(1, 1)` 的 256 项（单位 1/65536），再在伽马 2.2 里混合。该仓库自己的社区容差是 2–2.5，不是已证差 0。
- 把该表按像素中心线性插值再走现有伽马 2.2，比当前 17 点 `GRAD_WEIGHT` 在部分样本上少一些差点，但仍不是 0（例如官方 shape-grad 圆角中段 50/156、`maxDelta=1`；独立 96 宽红到蓝不透明矩形 `differ=960`、`maxDelta=1`）。两端第一列的 `maxDelta=6` 依旧在。不能当作可交付突破，也未改现有曲线，以免在仍未差 0 时改动已接近的像素。
- 公开 GDI+ `LinearGradientBrush.SetSigmaBellShape(1, 1)`，在多种端点约定（`x→x+w`、`x→x+w-1`、半像素、FromRect）、`PixelOffsetMode` None/Half，以及是否 `SetGammaCorrection` 下对照同一条 192 宽官方直边：无伽马时中段 `maxDelta` 约 48–49；最好的一轮是 `x→x+w` + 伽马校正 + Half，中段 `differ=100`、`maxDelta=4`，不如现有软件曲线，也不是 0。
- 半透明渐变现有路径是 sRGB 线性插值、`alpha` 按 8 位（50000→128）直通一次除以 255 再四舍五入（`blend_f`）。本轮纯色矩形用的两步 SourceOver（`blend_src_over`，源和页底各自四舍五入再相加）在官方 96×48、`alpha=50000` 页是 `differ=3552`，比现有 480 更差，不是通用修复。把不透明 S 曲线或 sigma 表套到半透明上会到 `maxDelta` 约 30，更远。

### 独立官方矩形样本

2026-11-17 01:28:26–01:30:17（Asia/Shanghai），用 PowerPoint 16.0 `Slide.Export` 对照 16 个无描边两色线性矩形（多种宽度、颜色、方向、alpha、页底；奇偶原点）。只开关本探测文稿 `grad-probe.pptx`，用户原有 PowerPoint 窗口（Pid 2828）未关、未点修复。全部 1280×720，框外几何 `differ=0`。框内无一页 `differ=0` / `maxDelta=0`：
