## 已锁定

- 不计算行距、不自动绕排、与 Word 像素级一致不算验收。
- 段上只读该 `w:p` 自己的 `w:pPr`，run 只读该 `w:r` 自己的 `w:rPr`，不把 `styles.xml` 摊进来。缺元素为 `null`，不猜规范缺省（禁则省略等于开）。
- 段上 `eastAsia` 始终出现。五个子元素都没有则为 `null`。有则对象字段顺序：`kinsoku`、`overflowPunct`、`topLinePunct`、`autoSpaceDE`、`autoSpaceDN`。各键取对应 `w:pPr` 子元素 OnOff；没有该子元素为 `null`。
- `setParaFormat` 增加这五个可选布尔或 `null`（`null` 删掉该元素）。与原有对齐 / 缩进 / 间距字段至少给一个。id 仍是任意故事段落 id。
- run 在 `scope.runs` 名单上于 `eastAsiaFont` 之后跟 `em`、`eastAsianLayout`。`em` 取 `w:em/@w:val`，没有为 `null`。`eastAsianLayout` 没有该元素为 `null`；有则对象字段顺序：`id`、`combine`、`combineBrackets`、`vert`、`vertCompress`。
- `setRunFormat` 增加 `em`（`none` / `dot` / `comma` / `circle` / `underDot` 或 `null` 删掉）与 `eastAsianLayout`（对象整份替换属性，或 `null` 删掉）。`id` 仍是 run id。
- 拼音是 run 内 `w:ruby`（ECMA-376 §17.3.3.25）。根上始终 `rubyCount`；`scope.rubies` 才有名单。id 为 `ruby:{n}` 或 `{页眉页脚容器}/ruby:{n}`。遇 `w:txbxContent` 停住。框内 / 注内 / 批注内本期不编、不插。
- 每条拼音字段顺序：`id`、`index`、`host`、`base`、`rt`、`align`、`hps`、`hpsRaise`、`hpsBaseText`、`lid`。`base` / `rt` 取 `rubyBase` / `rt` 里可见 `w:t` 拼接。属性取 `rubyPr` 对应子元素 `@w:val`，缺则为 `null`。
- apply：`insertRuby` / `setRuby` / `deleteRuby`。`insertRuby` 的 id 是正文或页眉页脚段落 id，或 `docx:document`。写入一个只含该 `w:ruby` 的 `w:r`。`base` 与 `rt` 必填非空。省略时 `align` 为 `distributeSpace`，`hps` 为 `12`，`hpsRaise` 同 `hps`，`hpsBaseText` 为 `24`，`lid` 为 `zh-CN`。
- 对含本期收入的 `w:ruby` 的段落发 `setParaText` 报 `NotImplemented`。
- 文档根上始终 `eastAsianSettings`。字段顺序：`characterSpacingControl`、`strictFirstAndLastChars`、`noLineBreaksBefore`、`noLineBreaksAfter`。没有 settings 或没有对应元素则为 `null`。`setEastAsianSettings` 的 id 必须是 `docx:document`；`null` 删掉该元素。没有 settings 且要写入时新建 `/word/settings.xml`。
- create 本期不写这些字段，见待做 52。
- xlsx / pptx 上发拼音 op、`setEastAsianSettings` 报 `InvalidField`。xlsx / pptx 的 `scope` 里出现 `rubies` 报 `InvalidField`。
