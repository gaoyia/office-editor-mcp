# 幻灯片 50% 半透明混合

状态：✅
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。点名的手测是 50% 的 `EE4455` 叠在 `AABBCC` 上得到 `CC7F91`。一次除法的 8 位线性混合会得到 `CC7F90`，对不上。官方对照后采用与 PowerPoint 16.0 / GDI+ 默认 SourceOver 相同的算法：先把 `a:alpha` 按 `((val * 255 + 50000) / 100000)` 收成 8 位覆盖率，再把源和目标各自按覆盖率四舍五入后相加。
