# docx 导出媒体

状态：✅ 1–5 已过（含框 / 注 / 批注图与 `exportChartData`）  
日期：2026-09-26

inspect 默认不读媒体字节。调用方要拿到图文件时，按图 id 把 OPC 里的媒体部件原样写出。不做格式转换，不生成缩略图。

规范线索：`a:blip/@r:embed` 经该部件 `.rels` 指向 `/word/media/…`（ECMA-376 §20.2）。

## 目标

已有图 id 能导出为本地文件。领域 JSON 仍不把 base64 当默认载荷。

## 动作

新动作 `exportMedia`，不要塞进 `inspect` 的树。契约见 `docs/json-contract.md`。

xlsx 认工作表图 id，写出 `/xl/media/…`。pptx 仍报 `InvalidField`。以后若要导出 pptx 的 `p:pic`，另开，不改本动作字段名。xlsx 的 `exportChartData` 仍报 `InvalidField`（数据在本工作簿单元格里）。

## 不做

- 默认把字节放进 inspect 树
- 转码、缩放、生成预览（那是渲染）
- 从本地文件「导入媒体但不插图」（插图走 `insertPicture`）

## 验收

- 对页眉图 id 导出，字节与 `/word/media/…` 一致，扩展名与内容类型相符。
- 换图后再导出，得到的是新文件。
- 对段落 id 或不存在的图 id 报错类别对。
