# pptx 表内列宽与行高

状态：❌
日期：2026-10-11

对应 `roadmap/pptx.md` 待做序号 **40**。前置：`.plan/2026年-9月-27日-✅-pptx-表格.md`。不要和 41 合成一份。

inspect 只报 graphicFrame 的 `x` / `y` / `cx` / `cy`。`setTableSize` / `setTablePos` 只改 `p:xfrm`，不重分配 `a:gridCol/@w` 与 `a:tr/@h`。insert 时按框尺寸均分一次之后冻住。不算自动列宽。

## 目标

inspect 能报格网列宽与行高。apply 能改这两项。create 复用同一套 apply。`setTableSize` 仍只改框。

## 已锁定

- 不要复用 docx 的 `setTableWidth` / `setTableRowHeight`（单位是 twip，还有 `tblW/@type`）。
- 不要改 `setTableSize` / `setTablePos` 的语义。
- inspect：表上在 `colCount` 之后加 `colWidths`（`a:gridCol/@w`，EMU 整数数组）。没有网格则为 `[]`。
- 行字段顺序改为 `id`、`index`、`height`、`cells`。`height` 取 `a:tr/@h`，缺则为 `null`。没有 `rule`。
- `setTableColWidths`：id 必须是表 id。`cols` 长度必须等于 `colCount`，每项 EMU 正整数。只写 `a:tblGrid`。不改 `a:ext`。不改各格 `tcW`（DrawingML 表通常没有格级宽）。
- `setTableTrHeight`：id 必须是行 id。`h` 为 EMU 正整数或 `null`（去掉 `@h`）。
- create：`tables[].cols` 与 `tables[].rowHeights` 可选，规则同上。省略则仍按框均分。
- 备注表、母版表同样认。xlsx / docx 上发这两个 op 报 `InvalidField`。
- 手测编号 **Pg**。脚本 `manual-check/office/cases/pptx-table-grid.ps1`。不要和 Pt 撞。
