## 要改什么

### 1. ask

`help` 顶层 `ask` 的键是问法名字：`list`、`search`、`op`、`def`。值才是字段。试用把 `def` 当成了入参。

`ask` 改成完整请求的列表，每条自带 `action`。例如打开定义是 `{"action":"help","name":"inspectScope"}`。不要让 `def` 成为字段，也不要给它做别名。

`docs/cli.md` 用一句话说明 `ask` 里的每条都能原样提交。`crates/ooxp/src/help.rs` 与盯住旧形状的测试一起改。

### 2. 覆盖

`createRequest` 的 description / limits，以及 `crates/ooxp-cli/src/mcp.rs` 的 initialize 说明，改成与分册同一句：目标路径已存在则覆盖。保留「改已有内容用 apply」。英文 limits 同步。

### 3. 改文字

`setParaTextOp` 的 limits 补一句：多个 run 时只留第一个 run 已有的 `w:rPr`，其余 run 的字符格式去掉。细节仍以 docx 分册第 4 步为准。

`setShapeTextOp` 的 limits 补一句：第一个含 `a:t` 的 run 留下 `a:rPr`，其余可见 run 清掉。细节仍以主契约第 5 到 7 步为准。

两句都写中英 limits。不改 Rust 替换代码。

### 4. 空页与画布

`pptxPresentation` 的 limits 抄分册已有的两句：`slides` 为空则生成一页，该页一个空文本框；某一页 `shapes` 为空则生成一个空文本框。再补一句：create 不写画布尺寸，建好后用 `setSlideSize`。

不改 `pptx/create.rs` 里补页的代码。未知字段 `slideSize` 仍报 `InvalidField`，不单开一种错误。

### 5. 形状编号

pptx 分册「稳定 id」的形状一条加一句：该宿主 `p:spTree` 自己的 `cNvPr/@id` 是 `1`，不是形状。新建形状至少从 `2` 起。写入节已有这句话，id 一节现在没有。

### 6. 格子样式

`xlsx` create 单元格的 `font`、`fill`、`border`、`align` 现在只有 `type: object` 或 `null`，所以 help 看不到子字段。`setCellStyle` 的同名字段已经有 `name`、`sz`、`bold`、`color`、`pattern`、`fg`、`bg`。

create 改为引用那一份结构，并仍允许 `null`。字段名保持 `fg`，不改成 `fgColor`。不在 `help.rs` 里另写展开逻辑。

收紧之后，create 若多写了定义里没有的键，报 `InvalidField`。这是预期。

### 7. 词表

这些值分册已经封闭，schema 仍是自由字符串，help 因此不给可选值。把词表写成 enum，不在帮助代码里另抄：

- `align`：`l`、`ctr`、`r`、`just`，或 `null`
- `textAnchor`：`t`、`ctr`、`b`、`just`、`dist`，或 `null`
- `underline`：`sng`、`none`、`dbl`，或 `null`
- `prst`：pptx 分册 `insertShape` 已列出的可写预设名

create 与 apply 用同一份 enum。连接线几何名仍不在形状 `prst` 里。

### 8. 三句说明

- `inspectRequest` 的 limits：不带 `scope` 只返回名单，不返回单元格。xlsx 公式格的 `value` 是包里的缓存，没有缓存则为 `null`，库不算。
- `cellColor` 的 `rgb` 加 description：6 位或 8 位，写入大写；6 位前面补 `FF`。与 xlsx 分册「6 位补成 `FF` + 六位」一致。
- `docxParaCreate` 的 `num` 加 description：从 1 起，指向 `document.numberings` 的下标，不是 `num:{n}`。

### 9. 图表工作表

只给 `sheet`、不给 `range` 时，库还没打开文件，不知道这张表是不是图表工作表。这条仍是「看单元格时必须同时给 sheet 和 range」。

打开之后，对 `chartsheet` 读单元格报 `InspectWorksheetOnly`。中英条文案补上：图表用 `scope.charts`，不要带 `range`。`scope.charts` 为真时的现有路径不变。

### 10. 表内字色

`tables[].cells` 的说明补一句：格子对象没有字号、颜色、加粗。改可见文字用 `setTableCellText`。改字色用 `setShapeFormat`，`id` 用单元格 id。不新增字段。

### 11. 安装说明

`README.md`「安装与构建」加一段：预编译包在 GitHub Releases，四个命令行名字和 `wasm` 见 `docs/cli.md` 的「发布」。Windows 用 `Get-FileHash 文件 -Algorithm SHA256`，对照同一次 Release 的 `SHASUMS256.txt`。

`docs/cli.md` 的平台表下加一句：没有 `win32-arm64`。

`crates/ooxp-cli` 里 `--lang` 的说明补上：省略时错误文案是英文。`docs/cli.md` 已有这句，以它为准。
