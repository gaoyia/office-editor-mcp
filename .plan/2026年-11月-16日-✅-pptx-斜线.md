# 幻灯片斜线

状态：✅ 已完成
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。`prst` 为 `line` / `straightConnector1`，且宽和高都不为 0 时，是角到角的斜线，有抗锯齿。轴线对齐的直线不在这一份，见已完成的水平或垂直直线与 1 像素竖线计划。

## 目标

画出这类斜线，并与 PowerPoint 16.0 的 `Slide.Export` 差 0。对不上之前整页失败，不加大容差。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 契约写明斜线条件；对照官方抗锯齿 | ✅ |
| 1 | 只实现能差 0 的不透明实线斜线 | ✅ |
| 2 | 手测 1280×720，`differ=0`，`maxDelta=0` | ✅ |

## 验收

- 不透明实线、笔画像素四舍五入为 1 或 2 的 `line` / `straightConnector1` 斜线，用 GDI+ 抗锯齿绘制：1 像素无像素偏移，2 像素半像素偏移。可带 `flipH` / `flipV` 表示方向。
- 手测 `pptx-preview-diag-image`：1 像素 45°、1:4、4:1、5:12，45° 的 `flipH` / `flipV`，2 像素 45° 与 1:4，以及 `straightConnector1` 的 45°，均为 1280×720、`differ=0`、`maxDelta=0`。已差 0 的 2 像素横竖线和 1 像素横竖线、以及 `pptx-slide-image` 没有回退。
- 单元测试覆盖 45°、浅斜线和翻转方向的端点覆盖。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不重做已差 0 的水平或垂直直线
- 不画直角折线、弯曲连接符
- 虚线、箭头、非平头线帽、其它宽度的斜线仍整页失败
