## 第 0 步结论（Word 16.0，2026-10-09）

探测脚本 `manual-check/office/cases/_probe-docx-38-group.ps1`（不要提交）。

- **组合**：两个浮动文本框 / 两张浮动图 / 图+框 / 跨段两个框，`Shapes.Range.Group()` 都成功，`Type = 6`。XML 是一个 `wp:anchor` 包 `wpg:wgp`（`Requires="wpg"`，`graphicData/@uri` 为 wordprocessingGroup）。子对象是 `wps:wsp` 和/或 `pic:pic`，带各自 `cNvPr/@id`。组合 `a:xfrm` 的 `off` 为 0，`ext` / `chOff` / `chExt` 取包围盒。没有 `cxnSp`。解开后变回两个独立 `wp:anchor`，`Requires="wps"`。行内图须先 `ConvertToShape` 才能组合；组合结果仍是浮动。页眉同样能组合。
- **连接线**：`AddConnector` 1/2/3 写成 `wps:wsp` + `wps:cNvCnPr` + `a:prstGeom` 为 `straightConnector1` / `bentConnector3` / `curvedConnector3`。`AddLine` 写成 `prst="line"`。都不是独立 `cxnSp`。现有 inspect 不把它们算进 `textBoxes`（无 `txbx`）。`BeginConnect` 这次 COM 仍失败，本期不写连接点。页眉也能插连接线。
- **开刀前缺口**：两个图组合后 inspect 把整组当成一张图（外层 `wp:docPr`）。混合组里框已按子 `cNvPr` 展开，图没有。`scope.connectors` 当时为 `InvalidField`。本刀已按锁定项补上。

## 锁定

- 连接线 id：`{宿主段}/cxn:{docPrId}`；组合里取该 `wps:wsp` 的 `cNvPr/@id`。只认连接线几何（含 `line`）或带 `cNvCnPr`、且没有文本框内容的 `wps:wsp`。
- `insertConnector` 的 id 是段落 id（正文或页眉页脚），写法对齐 `insertTextBox`。
- `groupShapes` 的 id 是 `docx:document`（正文）或页眉/页脚容器 id。成员是已有浮动图 / 文本框 / 连接线 id，可跨段、须同部件。行内、已在 `wpg:wgp` 里、图表 / SmartArt / OLE 不当成员。
- `ungroup` 的 id 是该组合内一个成员 id。
- 组合本身不进树。组合里的图按子 `pic:cNvPr` 展开。
- 不做：`insertShape`、绑连接点、create 生成组合/连接线、框内再套框、VML。

## 不做

- 编辑 VML / `w:pict`
- 排版引擎、像素级绕排
- 框内再套框（待做 39）
