# 工作表非直角组合旋转

状态：⚠️
日期：2026-11-16
分类：功能缺失

对应 C25 第 12 段。文件名仍为 ❌：步骤 2 官方 Excel 16.0 `Range.CopyPicture` 像素对照未做，不把实现或内部测试算作用户验收。锚点组合转 90 度的倍数并翻转已经差 0，本切片不重做那一档。

2026-11-17（Asia/Shanghai）实现记录（非用户验收，亦非官方对照通过）：

步骤 0：契约已写明本切片边界，依据已差 0 的组合整数比例缩放、翻转和直角旋转链，以及幻灯片上已验收的公开 GDI+ 旋转矩形画法，而不是为单张截图调参，也不把转完后的轴对齐外接框拿来铺色。只画 twoCell 锚点组合，且成员仍是已支持的无描边不透明纯色矩形。锚点组合可以绕外框中心转任意 DrawingML 角度（顺时针，1/60000 度）：先按组的外框和子坐标做整数比例（除法去掉余数），再翻转，再旋转。子矩形自己仍只许转 90 度的倍数或翻转。里层组合仍只许直角/翻转/缩放；换算从内到外后，外层再转非直角。锚点外接矩形必须和转完、翻完之后的组外框按像素重合。直角倍数仍走原整数路径，与已差 0 的像素保持一致。Windows 上用公开 GDI+ `TranslateTransform` / `RotateTransform` / `FillRectangle`（抗锯齿和半像素偏移）画真实旋转矩形。子矩形自己的非直角、里层组合的非直角、组合内描边/图片/文字、未编组矩形的非直角，以及 GDI+ 不可用，报 `NotImplemented`。不涉及单元格 `textRotation`。官方 `Range.CopyPicture` 对照仍属步骤 2，未做，不勾通过。

步骤 1：已实现上述子集。测试覆盖 15°/30° 与 0° 的差异、翻转后再转、非均匀缩放后再转、里层直角再外层 15°、外接框四角不得填红的反例、源包不变，以及里层非直角、子矩形非直角、描边、锚点不合等 NotImplemented。直角组合、单元格旋转缺口与其它已交付出图项未回退。未打开 Office，未做步骤 2。图表工作表、折线、散点、条形、迷你图日期轴的步骤 2 官方对照，以及旋转与两端对齐中非 0 文字旋转、迷你图日期轴写入 API 等缺口，仍未做，不混成完成。

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。
