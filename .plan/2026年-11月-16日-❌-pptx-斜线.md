# 幻灯片斜线

状态：❌
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。`prst` 为 `line` / `straightConnector1`，且宽和高都不为 0 时，是角到角的斜线，有抗锯齿。当前（含已交付的直线分支）整页 `NotImplemented`。轴线对齐的直线不在这一份。

## 目标

画出这类斜线，并与 PowerPoint 16.0 的 `Slide.Export` 差 0。对不上之前整页失败，不加大容差。

| 序号 | 内容 | 状态 |

| 1 | 只实现能差 0 的不透明实线斜线 | ❌ |
| 2 | 手测 1280×720，`differ=0`，`maxDelta=0` | ❌ |

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。字形灰度仍按 C25 第 0 段暂缓，位置和黑框大小要对齐；不把灰阶差靠放宽容差算通过。幻灯片已交付的多行文本是布局近似、不保证文字逐像素一致，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。
