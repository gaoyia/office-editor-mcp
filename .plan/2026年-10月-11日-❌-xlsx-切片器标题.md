# xlsx 切片器视图属性

状态：❌
日期：2026-10-11

对应 `roadmap/xlsx.md` 待做序号 **42**。前置：`.plan/2026年-9月-29日-✅-xlsx-切片器.md`。不要和 41 的锚点、44 的 cache 选项合成一份。不在库里执行筛选。

inspect 切片器已有 `caption`。`insertSlicer` 不写标题，缺省用字段名。同一视图元素上还有 `rowHeight`（schema 必填）、`columnCount`、`showCaption`、`startItem`、`lockedPosition`、`style`。时间线还有 `showHeader` 等开关。这些都是视图部件属性，不是 cache，本切片一次收齐。

## 目标

已有切片器与时间线能改视图部件上的标题、行高、列数、显示开关与样式名。insert 可带同一套字段。

## 已锁定

- inspect 切片器在 `caption` 之后加：`rowHeight`、`columnCount`、`showCaption`、`startItem`、`lockedPosition`、`style`。时间线在 `caption` 之后加：`showHeader`、`showSelectionLabel`、`showTimeLevel`、`showHorizontalScrollbar`、`level`、`selectionLevel`、`scrollPosition`、`style`。缺属性按 schema 缺省报，与 insert 写入一致；`style` 缺则为 `null`。
- 新 op `setSlicerView`。id 必须是切片器 id（含时间线）。至少给一个字段。
- 切片器可写：`caption`（非空字符串）、`rowHeight`（EMU 正整数）、`columnCount`（正整数）、`showCaption`（布尔）、`startItem`（非负整数）、`lockedPosition`（布尔）、`style`（非空字符串或 `null` 去掉属性）。
- 时间线可写：`caption`、`showHeader`、`showSelectionLabel`、`showTimeLevel`、`showHorizontalScrollbar`、`level` / `selectionLevel`（0–3）、`scrollPosition`（`dateTime` 原文或 `null`）、`style`。对时间线发切片器专用字段、对切片器发时间线专用字段，报 `InvalidField`。
- 写入 slicer 或 timeline 部件。不改 drawing 锚点，不改 cache。
- `insertSlicer` 增加上述可选字段。省略 `caption` 仍用 `field`。省略 `rowHeight` 仍用现有缺省。时间线 `level` 规则与现有 insert 相同，本切片允许事后改。
- 不要只开 `setSlicerCaption` 再把其余属性写成不做。
- docx / pptx 上发此 op 报 `InvalidField`。
- 手测编号 **Xsc**。脚本 `manual-check/office/cases/xlsx-slicer-caption.ps1`。不要和 Xsl、Xsn、Xtl 撞。
