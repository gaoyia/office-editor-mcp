# docx 文本框内垂直对齐

状态：✅ 文档、实现、库测试与 Word 16.0 手测已通过
日期：2026-10-11

对应 `roadmap/docx.md` 待做序号 **63**。前置：`.plan/2026年-9月-26日-✅-docx-文本框.md`。不要和表格格级 `vAlign`（59）、节级 `setVerticalAlign`、`setTextBoxDirection` 合成一份。

`setTextBoxDirection` 只改横排 / 竖排（`wps:bodyPr/@vert`）。inspect 框节点没有 `textAnchor`。框内段落左右对齐仍走 `setParaFormat`。Word 文本框「上下居中」写在 `wps:bodyPr/@anchor`。

## 目标

文本框内文字相对框的上 / 中 / 下能 inspect、能 apply。不算排版引擎。

## 已锁定

- inspect 框字段在 `wrap` 之后加 `textAnchor`。取 `wps:bodyPr/@anchor`：`t` / `ctr` / `b` / `just` / `dist`（`ST_TextAnchoringType` 全套）。缺属性为 `null`。不认识的原文报 `XmlBroken`。
- 新 op `setTextBoxAnchor` 与 xlsx 的锚点 op 重名，不要用。用 `setTextBoxTextAnchor`。id 必须是框 id。值为上述五者之一，或 `null`（去掉属性）。
- 不要和 `setPictureWrap` 的 `alignV` 混（那是框相对页边）。
- 不要和 59 的格级 `w:vAlign` 混。
- xlsx / pptx 上发此 op 报 `InvalidField`。xlsx / pptx 框内垂直仍用已有 `setShapeFormat.textAnchor`。
- 手测编号 **Bta**。脚本 `manual-check/office/cases/docx-textbox-anchor.ps1`。不要和 Tb、Bx 撞。
