# docx 注内、尾注内、批注内 3D

状态：✅ 已完成。
日期：2026-11-01

对应 `roadmap/docx.md` 序号 **76**。前置：3D 已过。

## 探测

2026-11-02 用 Word 16.0 对脚注、尾注、批注的 Range 调用 `InlineShapes.Add3DModel(文件, false, true, Range)`。三处都另存出 `wp:inline`，没有 `wp:anchor`。`mc:AlternateContent` 的 Choice `Requires="am3d"`，里面是 `am3d:model3d`。关系挂在该部件：`rId1` 的 Type 是 `http://schemas.microsoft.com/office/2017/06/relationships/model3d`，Target 是 `media/model3d1.glb`；海报是 image 关系。脚注里的 InlineShape 没有 `WrapFormat.Type`，`ConvertToShape` 失败。所以只写行内，改成浮动报 `InvalidField`。

## 做到的事

- 脚注、尾注、批注段落可以 `insertModel3d`。写出的是行内 `Requires="am3d"`，关系和媒体跟正文同一套，宿主换成该部件。
- `replaceModel3d`、`deleteModel3d`、`setModel3dSize`、`setModel3dCamera`、`exportMedia` 认带 `footnote:` / `endnote:` / `comment:` 前缀的 id。
- `scope.model3ds` 时根上 `model3ds` 只列这三处，id 带前缀，并计入根上 `model3dCount`。页眉页脚和正文段落上的名单位置不变。注节点和批注节点不加 `model3dCount`。Fallback 海报不进 `pictures`。
- 没有 `docPr/@id` 时 id 用 `model3d:index:{k}`，`k` 在宿主段内从 1 起。
- 删掉脚注里最后一个 3D 后，没人用的 GLB 和 model3d 关系去掉。
- 手测 `docx-model3d-notes.ps1`（D3n1）：库插入脚注和批注，Word 16.0 打开没有 Repair，两处 Range 的 InlineShape 都至少有 1 个。

## 不做

- 不改正文和页眉页脚已经能做的 3D。
- 脚注、尾注、批注里不写浮动。
- 不写批注墨迹。
