## 已锁定（写入契约，实现时不要改）

- 不执行嵌入的 Excel / Visio，不画图标。
- 认 `w:object`：有 oleObject 或 package 嵌入关系即可。Word 16.0 另存是 `o:OLEObject` 包在 VML 里，xlsx 等 Office 文件的关系 Type 常为 `package`；ECMA 写法是 `w:objectEmbed` 加可选 `w:drawing`，关系常为 `oleObject`。两种 markup、两种关系都进树。
- 不提供改 VML 属性的 op。删除整棵 `w:object`。插入写出 Word 能打开的最小 Transitional `w:object`。单独的 `w:pict` 仍不碰。
- `objectLink` / `Type="Link"`、`w:control`、`w:movie` 不进树。
- 框内、注内、批注内本期不编。xlsx / pptx 本期不编。
- 导出共用 `exportMedia`：OLE id 写出 embeddings 部件，不是预览图。不要新动作。
- Equation Editor 3.0 若以 `w:object` 出现则进 `oleObjects`，仍不进 `maths`。

## 不做

- 链接对象、ActiveX、影片
- 把嵌入字节塞进 inspect 树
