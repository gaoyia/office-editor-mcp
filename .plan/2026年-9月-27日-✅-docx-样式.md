## 已锁定

- 只动 `styles.xml` 与段上 `pStyle`，不重排整篇。
- 不实现排版引擎，树上不出现算出来的字号或颜色。
- 定义在 `/word/styles.xml`（关系 `/styles`）。文档根始终 `styleCount`（`w:style` 且 `styleId` 非空的个数）。页眉页脚容器不挂这份计数。
- 实例 id 用 XML 的 `w:style/@w:styleId`：`style:{styleId}`。`styleId` 为空的不进树。这与 `table:{n}` 不同：样式 XML 本身有稳定字符串 id。
- `scope.styles` 为 true 时根上列出 `styles`（按 `w:style` 文档顺序）。每条字段顺序：`id`、`styleId`、`type`、`name`、`basedOn`、`default`。`type` / `name` / `basedOn` 取对应属性或子元素 `@w:val` 原文，缺则为 `null`。`default` 看 `w:default`：`1` / `true` / `on` 为 `true`，其余或没有为 `false`。`w:latentStyles` 与 `w:docDefaults` 不进名单。
- 段落上的 `style` 仍只读自己的 `w:pStyle/@w:val`，不解析 `basedOn`，也不把样式定义上的字体字号摊到段上。没有 `pStyle` 则为 `null`（Word 按默认段落样式显示，树上不猜）。直接格式（下一切片「段落与 run 格式」）本期不读写。
- apply：
  - `setParaStyle`：`id` 为正文或页眉页脚段落 id，`style` 为 `style:{styleId}` 或 `null`（去掉 `pStyle`）。目标必须是已有的段落样式（`w:type` 为 `paragraph` 或缺省）。字符 / 表格 / 编号样式报 `InvalidField`。找不到样式报 `IdNotFound`。apply 不返回新 id。
  - `setStyle`：`id` 为 `style:{styleId}`，只改该条段落样式上已有或新建的 `w:pPr` / `w:rPr`。可选 `font`、`eastAsiaFont`、`sz`、`bold`、`color`、`before`、`after`，至少给一个。`sz` 是半磅整数（与 `w:sz/@w:val` 相同），2 到 3276。`color` 是六位 RGB 十六进制，不带 `#`，写入 `w:color/@w:val` 并去掉 theme 属性。`before` / `after` 单位 twip。不改 `outlineLvl`，不改 `basedOn`，不新建样式。
- create 本期不写额外样式定义；`paragraphs[].style` 仍只认 `Normal` 与 Heading1–3。
- xlsx / pptx 的 `scope.styles` 与样式 op 报 `InvalidField`。
- `setStyle` 脏 `styles.xml`。`setParaStyle` 脏段落所在部件。未点名的 `styles.xml` 仍原样写回。
