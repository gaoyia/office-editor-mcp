### 1. 删掉命令行 `--output`

全库只有命令行把 `--output` 传进 `run` 的第二个参数。库测试和 `ooxp mcp` 都传 `None`，路径写在领域 JSON 里。inspect、help 的结果走 stdout，这个开关对它们不起作用。

`dispatch.rs` 的 `output_path` 只用它补 JSON 里缺的路径，三处：

- create 缺 `path`。这条走不到：`create_bytes` 要先用 `path` 推断格式。
- apply 缺 `output`。JSON 里写了 `output` 就另存；省略则覆盖 `path`。
- exportMedia、exportChartData 缺 `output`。两个都缺报 `MissingField`，不能默认写成源 `path`。

决定（用户 2026-10-30 确认）：删掉命令行 `--output`。落盘路径只走 JSON。

- create 的 `path` 必填。
- apply 的 `output` 仍可选，省略则覆盖 `path`。
- exportMedia、exportChartData 的 `output` 改为必填。

要改的地方：

- 删掉 `main.rs` 的 `--output`，以及 `run` 的 `cli_output` 参数。
- `docs/cli.md`、`README.md` 的用法行去掉这个开关。`mcp` 说明里「这里没有命令行的 `--output`」一并删掉，只留 JSON 字段。
- `docs/json-contract.md` 的 exportMedia、exportChartData：`output` 改为必填，删掉「省略时用命令行 `--output`」。
- `docs/json-contract-xlsx.md`、`docs/json-contract-docx.md`、`docs/json-contract-pptx.md` 的 create：`path` 改为必填，删掉「省略时用 `--output`」。
- `docs/json-schema/src/shared/envelope.json` 里三处同样的注释改掉，再跑 `build.py`。
- 已完成的旧计划不必回改。

### 2. `ooxp mcp` 的错误

现状：用 `--lang en` 启动后，命令行自己产生的错误仍是中文纯文本，没有 `code`。MCP 说明却让调用方「读错误里的 code」。

- 工具错误改成和库错误相同的 JSON 形状：`{"ok":false,"error":{"code","message","path"}}`。
- 先在 `docs/cli.md` 列出每种错误用哪个现有 `ErrorCode`，建议如下：

| 情形 | code |
| --- | --- |
| 未知工具 | `UnsupportedAction` |
| `arguments` 不是对象 | `InvalidJson` |
| `requestPath` 与其它字段同时出现 | `InvalidField` |
| 请求文件读不到 | `Io` |
| 请求文件不是 JSON 或不是对象 | `InvalidJson` |
| 请求文件里有 `requestPath` | `InvalidField` |
| `action` 与工具名不符 | `InvalidField` |

- 文案跟着 `--lang`，没有就用 `OOXP_LANG`，规则与 `docs/cli.md` 已写的一致。
- JSON-RPC 层的 `-32700`、`-32601` 保留协议码，只让 `message` 跟着语言。
- `parse_lang` 的命令行报错同样中英文都有。

### 3. 缺包

- `dispatch.rs` 的 `require_package` 现在拼一句写死的英文 IO 错误。
- 改成正式的错误种类，补中英文文案，在 `docs/errors.md` 登记。错误码在文档里定，建议用 `InvalidField`，`path` 为空。

### 4. `write_atomic`

现状：

- 先把原文件改名成 `.ooxp.bak`，再把临时文件改名到原路径，最后删掉备份。
- 两次改名之间原路径上没有文件。进程这时退出，用户的文件就只剩 `.bak`。

改法：

- 临时文件写好后直接改名覆盖原路径。Windows 上 `std::fs::rename` 会替换已有文件。
- 改名失败时删掉临时文件，原文件不受影响。
- 目标文件被 Office 占用时，覆盖改名会失败。核对报错仍是 `Io` 并带路径。
- `docs/cli.md` 或 `docs/opc.md` 里有写到备份文件的，同步删掉。

### 5. 测试

- 命令行不再接受 `--output`。create 不写 `path` 报缺少 `path`。exportMedia 不写 `output` 报缺少 `output`。apply 不写 `output` 仍覆盖 `path`。错误文案与文档一致。
- `mcp`：`--lang en` 下未知工具、`requestPath` 冲突，各返回英文文案和对应 `code`。
- `write_atomic`：覆盖已有文件后目录里没有 `.ooxp.bak`、`.ooxp.tmp`；目标是目录时报 `Io`。
- `cargo test --workspace` 全过。
- `cargo fmt --all` 与 `cargo clippy --all-targets --all-features -- -D warnings` 通过。
- 不改写出的 Office 内容，不要求 Office。
