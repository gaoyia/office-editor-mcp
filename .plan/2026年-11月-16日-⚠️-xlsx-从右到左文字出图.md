## 语义分界（本刀遵守）

| 概念 | 含义 | 本刀 |
| --- | --- | --- |
| `sheetView/@rightToLeft` | **列镜像**（A 在视觉右侧）；填充/网格随列翻 | ✅ 有拉丁/CJK 文字时：非文字层翻转后，字在翻转坐标系 **正写** |
| `alignment/@readingOrder` 0/1/2 | **单元格双向**（上下文/LTR/RTL），与列镜像不同 | 0/1/缺省可画；**2 → NI** |
| 强 RTL 文种（阿拉伯/希伯来等） | 需整段 bidi + shaping | **NI**（`Face::width`/`draw_cells` 为逐字 glyph advance，不能接 `DirectionRightToLeft` 否则测画错配；**不做 Unicode 反序**） |

不重做无文字翻转金样；条件格式 / 自动筛选在 RTL 下仍整表 NI。

### Oracle / 布局（非整图 0）

COM（Asia/Shanghai）：`DisplayRightToLeft=True`；ReadingOrder=xlContext(-5002)→OOXML 无 readingOrder；A1:B2 **97.811×28.528 pt**；CopyPicture gold **145×43@≈106**（≈COM→106 **144×42**）。

库：DEFAULT_COL 64×2 + 框 → **129** 宽；实出 **129×49**（有字时自动行高，非仅 `defaultRowHeight=14.3`→38）。COM→96 ≈ **130.4×38**。

**sizeDiffer=True** → 不得写 layoutPASS / 整图 PASS。CLI 成功 ≠ layout PASS。不缩金样、不放宽容差、不把坐标按 dpi 换算后宣称 0 差。不套 PPT 文字灰度许可。
