## 已锁定

- 视图挂在工作表节点上的 `view` 对象，不另编 id。工作表级筛选是同级的 `autoFilter`（字符串或 `null`），不进 `view`。`setSheetView` / `setAutoFilter` 的 `id` 必须是 `sheet:{name}`。
- 每张 `worksheet` / `chartsheet` 始终有 `view`。没有对应 XML 时：`zoom` 100、`frozenRows` / `frozenCols` 0、`activeCell` 为 `A1`。每张 `worksheet` 始终有 `autoFilter`；没有工作表级 `<autoFilter>` 则为 `null`。`dialogsheet` / `macrosheet` 没有这两项。`chartsheet` 没有 `autoFilter`。
- `view` 字段顺序：`zoom`、`frozenRows`、`frozenCols`、`activeCell`。工作表字段：`print` 之后始终跟 `view`，`worksheet` 再跟 `autoFilter`，然后才是可选的 `headerFooters` / `pictures` / `charts` / 单元格切片。
- 多视图只操作 `sheetViews` 里第一个 `sheetView`，其余原样留。没有则按 `CT_Worksheet` 新建，`workbookViewId="0"`。
- `zoom` 取 `@zoomScale`，缺省 100；apply 只写 10–400。`chartsheet` 给了 `zoom` 时把 `@zoomToFit` 写成假，否则 Excel 会忽略缩放。
- 冻结只认 `pane/@state` 为 `frozen` 或 `frozenSplit`。`split` 不当冻结，inspect 报 0。apply 只写 `state="frozen"`，不写 `split` / `frozenSplit`。`frozenRows` / `frozenCols` 为非负整数，对应 XML `ySplit` / `xSplit`（冻结时表示冻结的行数 / 列数）。两侧都为 0 则去掉 `<pane>`（解冻，原先的 split 一并去掉）。只给一个冻结字段时另一侧沿用当前冻结值。`topLeftCell` 写成冻结区右下角的下一格。不写隐藏行。
- `activeCell` 是单格 A1。inspect 取与 `activePane` 对应的 `<selection>`，没有则取第一条。apply 写成该选区的 `activeCell` 与 `sqref`。
- `setAutoFilter` 只改工作表级 `<autoFilter>/@ref`，不改表格部件里的 `<autoFilter>`，不写 `filterColumn`，不隐藏行，不求值。`ref` 为单一 A1 或 `null`（删除该元素）。与同一张表上已有表格的 `ref` 相交报 `InvalidField`。已有工作表级筛选时只改 `@ref`，子元素留下。
- `setSheetView` 除 op/id 外至少一字段。`setAutoFilter` 必须给 `ref`。对 `dialogsheet` / `macrosheet` 报 `NotImplemented`。对 `chartsheet` 发 `frozenRows` / `frozenCols` / `activeCell` 或 `setAutoFilter` 报 `InvalidField`。不标重算。create 本期不写视图与筛选。
- 手测编号 **Xvw**，脚本 `manual-check/office/cases/xlsx-view.ps1`。
