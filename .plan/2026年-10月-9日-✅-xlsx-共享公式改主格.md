# xlsx 共享公式改主格

状态：✅ 已通过 Excel 16.0  
日期：2026-10-09

从 `roadmap/xlsx.md` 待做序号 28。第一期公式结构已能改当前左上角主格的公式文本、按 `sharedRef` 扩缩范围，以及拆组。目标格不是当前主格、且新区域与已有共享组相交时，会当成新建一组并报 `NotImplemented`。本期补「迁主格」：把共享组的主格迁到新区域左上角，沿用该组 `si`。

## 目标

`setCell` 带 `formula` 与 `sharedRef` 时，若新区域与恰好一组已有共享组相交，沿用该组 `si`，把主格迁到目标格（必须是新区域左上角）。Excel 打开无修复。库不求值。

## 已锁定（写入契约后不要改）

- 目标格必须是新 `sharedRef` 的左上角。不要把主格写到非左上角。
- 给 `formula` 与 `sharedRef`：新区域与恰好一组已有共享组相交（含目标本身属于该组）时，沿用该组 `si`，把主格迁到目标格。给了 `formula` 就用这段文本当新主格公式，不从旧主格再平移一遍。
- 旧主格若仍在新区域内，改成空的共享从属格。被踢出的格子按旧主格公式相对展开成独立 `<f>`。新范围内缺的格子补空的 `<f t="shared" si>`。新区域缩成单格则目标格改成普通公式。
- 新区域与任何已有共享组都不相交：仍新建一组，`si` 取本表未用的下一个非负整数。
- 新 `sharedRef` 同时盖住两组及以上已有共享组，或盖住数组 / 数据表，仍报 `NotImplemented`。`arrayRef` 盖住其它组的规则不变。
- 对从属格只给 `shared: true`、不给 `sharedRef`：仍报 `InvalidField`（`SharedNeedsRef`）。对从属格不带 `shared` / `sharedRef` 的 `setCell` 仍只把该格写成独立公式，主格不动。
- 不求值，不插行引用平移。create 仍不写 `t="shared"`。数据表公式仍不能改。
- 手测编号 **Xsm**，脚本 `manual-check/office/cases/xlsx-formula-master.ps1`。不要占用 Xf。

## 不做

- 公式求值
- 主格不是新区域左上角
- create 写共享公式
- 数据表公式、数组公式迁主格（数组主格仍必须是左上角，且不能吸收共享组）

## 验收

手测编号 Xsm1–Xsm5。Excel 16.0：`xlsx-formula-master.ps1`，5 PASS / 0 FAIL，收尾 Office 进程 0。向上迁主格后 COM `B1=20`、`B2=22`、`B3=24`，无 Repair。

- Xsm1：把 `B2:B3` 的主格迁到 `B1`（`sharedRef` `B1:B3`）后，inspect 上 `B1` 是主格，`B2` / `B3` 是从属格。
- Xsm2：同一份文件 Excel 无修复，COM `B1`/`B2`/`B3` 公式与打开后的值正确。
- Xsm3：把 `B1:B3` 收到 `B2:B3` 后，`B2` 是主格，`B1` 是独立公式；Excel 无修复。
- Xsm4：`sharedRef` 同时盖住两组已有共享组得 `NotImplemented`，未写文件。不强制开 Excel。
- Xsm5：对从属格只给 `shared: true` 得 `InvalidField`，未写文件。不强制开 Excel。
