# pptx 母版装饰形

状态：✅
日期：2026-10-10

对应 `roadmap/pptx.md` 待做序号 **29**。前置：母版写入剩余、动画 setAnim。PowerPoint 16.0 手测 Md1–Md5 已过。

`docs/json-contract-pptx.md` 现状：`scope.masters` 只收带 `p:ph` 的占位符；没有 `p:ph` 的 `p:sp` 不进树。`insertAnim` 对装饰形报 `IdNotFound`。`insertShape` 不扩到母版。

## 目标

母版 / 版式上的装饰形能进 inspect，能改几何与文字，能绑同一套预设动画。不实现母版排版引擎。

## 已锁定

- 装饰形仍是 `p:sp`，不要新开对象名。id 与占位符同一套 `master:{n}/shape:{cNvPrId}`（版式带 `layout:{k}`），按 `cNvPr/@id` 区分，不要抢号。
- 没有 `cNvPr/@id` 时装饰形用 `shape:index:{i}`，`{i}` 只在该宿主装饰形内从 1 计，不和占位符的 `index` 混编。
- inspect：`placeholders` 仍只收带 `p:ph` 的；`shapes` 收没有 `p:ph` 的 `p:sp`（含无 `txBody`）。字段顺序：母版 / 版式在 `placeholders` 之后加 `shapes`。
- `insertShape` 的 id 扩到 `master:{n}` 与 `master:{n}/layout:{k}`，写出没有 `p:ph` 的装饰形。不抄进各页。
- `deleteShape` / `setShapeFill` / `setShapeLine` 认装饰形；对占位符仍报 `InvalidId`。
- `setShapeText` / `setShapeFormat` / `setShapePos` / `setShapeSize` 认占位符与装饰形。没有 `txBody` 仍报 `IdNotFound`，不补框。
- `insertAnim` / `setAnim` / `deleteAnim` / `moveAnim` 对装饰形与占位符同一套预设。
- 不把母版装饰形抄进各页。不算母版排版引擎。

## 不做

- 母版排版引擎、与 PowerPoint 像素级一致
- 备注母版插删占位符（30）
- 母版 / 版式上的图、OLE、表、域、超链接、Zoom（31）
- create 的 `presentation.masters` 装饰形（38）
- 编辑 VML
