## 已锁定（Excel / Word / PowerPoint 16.0）

C1 已过：inspect 能标 `stock` / `surface` / `ofPie` / `chartex`；已有股价 / 曲面 / 复合饼可改系列数据与装饰；增删系列与 `setChartType` 当时仍拒；`insertChart` 当时不接受这三种；chartex / `other` 除删除与尺寸位置外仍锁。

三家另存同一套 `c:chart` 包裹：

- **HLC `ChartType=88`**：`c:stockChart`，恰好 **3** 条 `c:ser`，`c:hiLowLines`，两条轴。COM `SeriesCollection.Count` 常报 1，以 XML 为准。
- **OHLC `89`**：Excel 失败 `0xB0D70190`。PPT `AddChart(89)` 能写出 4 条 `c:ser` 的 `stockChart`（另有 `upDownBars`、`gapWidth=150`）。本期 `insertChart type=stock` **只写 HLC 三条**，4 条报 `InvalidField`。不写 OHLC。
- **VHLC `90` / VOHLC `91`**：PPT 是 `barChart`+`stockChart` 组合（成交量柱 + 股价），不是单 `stock`。不要当 `stock` 写。
- **曲面 `83`**：`c:surface3DChart`，`wireframe=0`，3 系列，3 条 `axId`（含 `c:serAx`），`c:bandFmts`，`c:view3D`（`rotX=15` `rotY=20` `rAngAx=0`）。Word / PPT 相同。
- **`84` 线框**：`surface3DChart` + `wireframe=1`。本期 insert 不写。
- **`85` 俯视**：`c:surfaceChart`（2D）+ `view3D rotX=90`。本期 insert 写 **`surface3DChart`**，不写俯视。
- **复合饼 `68`**：`c:ofPieChart`，`ofPieType=pie`，恰好 1 系列，无 `axId`，`secondPieSize=75`，有 `serLines`。Excel `gapWidth=150`；Word / PPT 另存是 `100`。insert **写 `150`**（ECMA 缺省，Excel 锁过）。
- **复合条 `71`**：同上，`ofPieType=bar`。用可选字段 `ofPieType`，不要新 `type`。
- **chartex**（瀑布 `119` / 树状图 `117` / 旭日 `120`）：根 `cx:chartSpace`，CT `application/vnd.ms-office.chartex+xml`，`cx:series/@layoutId` 为 `waterfall` / `treemap` / `sunburst`。Word `AddChart2(119)` 失败。`SetSourceData` 在 Excel 报未实现。数据公式是 `_xlchart.v1.N`，不是工作表 A1。**`insertChart` 仍不接受 `chartex`。** inspect 收 `layoutId`。

PPT COM 转类型（关 ChartData 之后）：HLC(3) → col / line / pie / ofPie / surface 成功，→ OHLC 失败；surface(3) → col / line / stock / ofPie 成功；ofPie(1) → pie / col 成功，→ stock / surface 失败。库契约不要跟着 COM 把 3 系列转成饼：饼 / 圆环 / 复合饼必须 1 条；转成 `stock` / `surface` 必须恰好 3 条，否则 `NotImplemented`。

`SeriesCollection.NewSeries` 在本机 PPT OM 上不是方法。**`addChartSeries` / `deleteChartSeries` 对 stock / surface / ofPie 继续 `NotImplemented`。**

`ofPieType` 缺省：insert 省略写 `pie`；setChartType 已是 ofPie 则保留原值，否则写 `pie`。非 ofPie 上出现 `ofPieType` → `InvalidField`。

手测编号 **Cq**（docx）、**Xq**（xlsx）、**Pq**（pptx）。脚本 `manual-check/office/cases/docx-charts-rare.ps1`、`xlsx-charts-rare.ps1`、`pptx-charts-rare.ps1`。不要和 Cr / Xr / Pr、Pc、Cs 撞。Cx8 改为三条系列转柱形成功。
