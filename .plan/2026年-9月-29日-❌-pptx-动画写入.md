## 已锁定（探测通过后写入契约，实现时不要改）

- 不新开与对象并列的「动画对象」模型。效果仍在该页 `<p:timing>` 里，`target` 仍是现有 inspect id。
- inspect 每条补 `id`：`slide:{n}/anim:{k}`，`k` 与现有名单文档顺序相同，从 1 计。字段顺序：`id`、`target`、`type`、`trigger`。没有 `cTn/@id` 也不改 `stable` 规则——动画 id 按顺序，删中间一条后面要重排。
- `insertAnim`：`id` 是可绑对象（形状 / 图 / 表 / 图表 / SmartArt / 视频 / 音频）。`type` 本期白名单，第 0 步最少锁定 `fade`。`trigger` 为 `click` / `with` / `after`，省略为 `click`。接到该页 `mainSeq` 末尾。没有 timing 则写出与另存同构的最小树。
- `deleteAnim`：`id` 是 `slide:{n}/anim:{k}`。摘掉对应效果 `cTn`，空壳按现有 `strip_timing_for_spid` 同一套修剪；整节空了则删 `<p:timing>`。
- 写入只动被点名那一页的幻灯片 XML。不改 `<p:transition>`。不改未点名效果。
- 新节点的 `cTn/@id` 取该页 timing 树已有最大整数加 1。
- 不提供把整棵 `<p:timing>` 当 JSON 交进来的 op。`setTiming` 继续可以没有；有也不接受任意树。
- 备注页、母版、版式上的动画本期不写。
