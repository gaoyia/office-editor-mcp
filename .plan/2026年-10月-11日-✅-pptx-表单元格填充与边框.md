41 放弃的是文字格式。格填充和四边写在 `a:tcPr`（§21.1.3、`CT_TableCellProperties`），不是 `a:txBody`。inspect 格上没有 `fill` / `borders`。`setShapeFill` / `setShapeLine` 写 `p:spPr`，单元格 id 报 `InvalidId`。docx 的 `setCellFormat` 在 pptx 上仍报 `InvalidField`。

## 目标

格级实心填充与六边（含两条斜线与线型）能 inspect、能 apply。不算表样式主题，不算排版引擎。

## 已锁定

- inspect 格字段在 `runs` 之后加 `fill`、`borders`。
- `fill` 取 `a:tcPr` 的 `a:solidFill/a:srgbClr/@val`，大写六位。`a:noFill` 或没有填充子元则为 `null`。渐变 / 图案 / 图片 / theme 填充见 50，本切片读到那些子元时 `fill` 为 `null`，不报错、不删。
- `borders` 对象字段顺序：`left`、`right`、`top`、`bottom`、`tl2br`、`bl2tr`。对应 `lnL` / `lnR` / `lnT` / `lnB` / `lnTlToBr` / `lnBlToTr`。缺该边则为 `null`。每边字段顺序：`color`、`width`、`dash`。`color` 取该线 `a:solidFill/a:srgbClr`；`width` 取 `@w`（EMU）；`dash` 取 `a:prstDash/@val`，缺则为 `null`。一边是 `a:noFill` 则为 `null`。
- 新 op `setTableCellFill`。id 必须是单元格 id。`color` 为六位 RGB 或 `null`（写成 `a:noFill`，去掉其它填充子元）。
- 新 op `setTableCellBorders`。id 必须是单元格 id。值为对象。未点名的边留下。某边 JSON `null` 去掉该 `ln*`。边对象必须有 `color`（六位 RGB）与 `width`（EMU 正整数）。可选 `dash`（`ST_PresetLineDashVal` 原文，或 `null` 去掉 `prstDash`）。写入 `a:solidFill/a:srgbClr` 与 `@w`。不写箭头、`miter`。
- 两个 op 都先保证有 `a:tcPr`。不要复用 `setShapeFill` / `setShapeLine` / `setCellFormat`。
- create：`tables[].cells[]` 对象可带可选 `fill` 与 `borders`，规则同上。
- 备注表、母版表同样认。xlsx / docx 上发这两个 op 报 `InvalidField`。
- 手测编号 **Ptb**。脚本 `manual-check/office/cases/pptx-table-cell-fill.ps1`。不要和 Pt、Pg、Ptf、Tf 撞。
