- 不打开浏览器。
- 工作表式单元格链、PowerPoint 的 `hlinkHover` / `on` / `event` 不搬进 Word。
- 正文与页眉页脚里的图、文本框，inspect 在该对象上始终带 `hyperlink`：没有 `a:hlinkClick` 为 `null`。不进 `hyperlinks` 名单，不计入 `hyperlinkCount`。HYPERLINK 域仍走域切片。

- `hyperlink` 对象字段顺序：`kind`、`rId`、`url`、`anchor`、`tooltip`。`kind` 为 `url`（有 `r:id`）或 `anchor`（没有 `r:id`，或关系 Target 以 `#` 开头）。规则尽量跟现有 `w:hyperlink` 一条走：外部链关系写在该故事部件 `.rels`，Type 以 `/hyperlink` 结尾，`TargetMode` 为 `External`。内部书签：无 `r:id` 时用 `anchor`；有 `r:id` 且 Target 为 `#{name}` 时 `anchor` 为 `{name}`。`tooltip` 取 `a:hlinkClick/@tooltip`。
- `insertHyperlink` 的 id 可以是段落 id（仍写 `w:hyperlink`），也可以是正文或页眉页脚的图 id / 文本框 id（写 DrawingML `a:hlinkClick`）。对图 / 框禁止 `text`。`url` 与 `anchor` 必须恰好一个。

- 框内图、连接线、SmartArt、图表、墨迹、3D、OLE 本期不写 DrawingML 链。对这些 id 发超链接 op 仍报 `InvalidId`。
