# xlsx / pptx 公式框事后几何

状态：✅
日期：2026-10-11

对应 `roadmap/xlsx.md`、`roadmap/pptx.md` 跨格式 **C13**。前置：`.plan/2026年-10月-9日-✅-xlsx-pptx-嵌入OMML.md`。不要改 Word 公式。不要和 3D、形状 pos 合成一份。不算公式排版引擎。

公式框不进 `shapes` / `textBoxes`。inspect 已有坐标或锚点。`setMath` 只换 `m:t`，契约写明不改位置尺寸。`setShapePos` / `setTextBoxAnchor` 不认 `math:` id。

## 目标

Excel 公式框能改锚点与尺寸。PowerPoint 公式框能改画布坐标与尺寸。`setMath` 仍只改字。

## 已锁定

- pptx：`setMathPos` 字段与 `setShapePos` 相同；`setMathSize` 字段与 `setShapeSize` 相同。写入 Choice 里该 `p:sp` 的 `a:xfrm`。id 必须是公式框 id。
- xlsx：`setMathAnchor` 字段与 `setTextBoxAnchor` 相同；`setMathSize` 与 `setTextBoxSize` 相同（含 `twoCell` 只改 `to`）。id 必须是公式框 id。
- 不要对 `math:` 发 `setShapePos` / `setTextBoxAnchor`。docx 上这些新 op 报 `InvalidField`。
- `setMath` 仍禁止出现 `x` / `y` / `cx` / `cy` / `from` / `to`。
- 手测编号 **Xmg** / **Pog**。脚本 `manual-check/office/cases/xlsx-math-geom.ps1` 与 `pptx-math-geom.ps1`。不要和 Xm、Pom、Pmg 撞。

- 把公式框并进 `shapes`
