# 幻灯片非直角旋转

状态：✅
日期：2026-11-16
分类：功能缺失

对应 C25 第 2 段。组合和矩形绕中心转 90 度的倍数，以及水平、垂直翻转，已经差 0。本切片点名没有描边的不透明纯色矩形（`srgbClr` 或没有颜色变换的 `schemeClr`）绕中心做非直角旋转。不要一次收任意对象。

## 目标

点名一档能独立对照的非直角旋转：没有描边、没有翻转、没有文字的不透明纯色矩形，与 PowerPoint 16.0 差 0。对不上继续 `NotImplemented`。

2026-11-17 00:47:19–00:51:30（Asia/Shanghai）官方 Microsoft Office 16.0（`C:\Program Files\Microsoft Office\root\Office16`，PowerPoint 16.0）`Slide.Export`：新用例 `pptx-preview-rot-rect-image` 13 页全部 `differ=0`、`maxDelta=0`（921600 像素）。覆盖 15° / 22.5° / 30° / 45° / 60° / 120° / 315°，正方形 64×64、不等边 96×48 与 32×96，原点 (192,96)、(400,200)、(10,200)，填色 `EE4455` 与 `0000FF`，以及 90° 对照页。同轮针对性回归还跑了 `pptx-slide-image`、`pptx-crop-image`、`pptx-preview-scale-image`、`pptx-preview-crop-scale-image`，合计 PASS 89 / FAIL 1。唯一失败仍是已记录的缩放裁剪不透明 `dest_y=65` 页，官方原文 `differ=34`、`maxDelta=2`，不得把本轮说成全套绿。未改金样，未放宽容差。t93u 透明度放宽不扩到旋转形状。直角旋转和翻转仍走原路径，未退。

已交付范围：嵌入在幻灯片上的 `prst=rect`，没有描边（或线为 `noFill`），没有 `flipH` / `flipV`，没有可见文字，填充是不透明 `srgbClr` 或没有颜色变换的 `schemeClr`。`a:xfrm rot` 按 ECMA-376 为 60000 分之一度、绕中心顺时针。Windows 上走上述公开 GDI+ 路径，画在真实页面坐标上。非 90 度倍数走这条路径；90 度倍数仍走原来的外接矩形对调。

仍不画：带描边、翻转、可见文字、半透明填充、渐变或图片填充的非直角矩形；组合的非直角旋转；椭圆、圆角矩形、线条和连接符的非直角旋转；xlsx 工作表图形的非直角旋转，见 `.plan/2026年-11月-16日-✅-xlsx-非直角组合旋转.md`。非 Windows 没有这条 GDI+ 对照路径，这种矩形整块留空，不声称与 Office 差 0。

不要把「旋转支持」标成全部完成。字形灰度仍按 C25 第 0 段暂缓，见已合入 main 的 `.plan/2026年-11月-16日-✅-pptx-多行文本布局近似.md`（用户 t66u 验收），不要在本切片里重开文字灰度 MaxDelta=0。缩放裁剪的不透明 `dest_y=65` 相位差仍是未接受的在研限制，见 `.plan/2026年-11月-16日-✅-pptx-缩放裁剪.md`。形状渐变收口和圆角直边收口仍是未差 0，不重做。

验收时：非文字像素必须 `differ=0`、`maxDelta=0`。不得用几何锚点过就省略像素检查，也不得用套件 PASS 汇总掩盖其它切片的失败。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不用 Office COM 作库 renderer
- 不重做已差 0 的直角旋转和翻转
- 不把 t93u 的透明残差接受扩到旋转形状
- 不在这一份里收描边、翻转、组合、文字、半透明或其它几何的非直角旋转
