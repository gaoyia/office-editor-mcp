# pptx 备注母版与讲义形状

状态：✅
日期：2026-10-10

对应 `roadmap/pptx.md` 待做序号 **30**。前置：讲义、母版写入。PowerPoint 16.0 手测 Nh1–Nh5 已过。

`docs/json-contract-pptx.md` 现状：讲义容器 id 固定为 `handout`，本期不把讲义占位符编成 `handout/shape:…`。备注母版不写插删占位符。讲义母版与备注母版不写 `<p:timing>`。

## 目标

备注母版能插删占位符。讲义占位符能编成形状 id。这两处能写与幻灯片相同的预设动画。PowerPoint 16.0 打开无修复。

## 已锁定

- `setHandoutText` 继续只改四个槽位的字，不要和本切片的形状 id 抢语义。
- 不实现放映引擎。不打印讲义。
- 备注母版容器 id 固定为 `notesMaster`（`p:notesMasterIdLst` 最多一份，§19.2.1.27、§19.3.1.27）。
  占位符 id 为 `notesMaster/shape:{cNvPrId}`；没有 `cNvPr/@id` 则为 `notesMaster/shape:index:{i}`。
- 讲义容器仍是 `handout`。占位符 id 为 `handout/shape:{cNvPrId}`；没有则为 `handout/shape:index:{i}`。
  `{i}` 只在该宿主占位符内从 1 计。
- inspect：`scope.notesMaster: true` 时根上填 `notesMaster`。没有 notesMaster 关系则为 `null`。
  有则为对象，字段顺序：`id`、`animCount`，`scope.timing` 同开时再跟 `timing`，然后 `placeholders`。
  不新增根上 `hasNotesMaster`。不算装饰形。
- `scope.handout` 四个槽位字段留下。对象在 `sldNum` 之后加 `animCount`，`scope.timing` 同开时再跟 `timing`，然后 `placeholders`。
  `placeholders` 收全部带 `p:ph` 的 `p:sp`（含 `sldImg`）。不算讲义打印布局。
- 根字段顺序：有 `scope.masters` 时 `masters`，有 `scope.notesMaster` 时再跟 `notesMaster`，有 `scope.handout` 时再跟 `handout`。
- `insertPlaceholder` 的 id 扩到 `notesMaster` 与 `handout`。没有该部件则按 `setNotesText` / `setHandoutText` 同一套规则新建最小部件。
  可写 `type` 加 `hdr`。仍不写 `sldImg` / `obj` / `chart` / `tbl` / `pic` / `media`。
  备注母版画布取 `p:notesSz`；讲义母版取 `p:sldSz`。
- `deletePlaceholder` 认 `notesMaster/shape:…` 与 `handout/shape:…`。只删该 `p:sp`，不改各页 notesSlide。
- `setShapeText` / `setShapeFormat` / `setShapePos` / `setShapeSize` 认这两处占位符。
  `p:ph/@type` 为 `sldImg` 仍报 `InvalidField`，不补框。
- `deleteShape` / `setShapeFill` / `setShapeLine` / `insertShape` 对这两处占位符与容器仍报 `InvalidId`。
- `insertAnim` / `setAnim` / `deleteAnim` / `moveAnim` 认这两处占位符，预设与幻灯片同一套。
  动画 id 为 `notesMaster/anim:{k}` 与 `handout/anim:{k}`。不抄进各页。根上 `animCount` 仍只计幻灯片 XML。
  ECMA `CT_NotesMaster` / `CT_HandoutMaster` 没有 `timing`；对照备注页，Office 16.0 另存不剥则写。
  插入位置：`clrMap` 之后、`hf` / `notesStyle` 之前。
- xlsx / docx 的 `scope` 里出现 `notesMaster` 报 `InvalidField`。
