# xlsx 图案填充出图

状态：✅
日期：2026-11-15

对应跨格式 **C25** 第 9 段里能和 Excel 16.0 差 0 的图案。只读，不改包。像素不进 inspect。

## 目标

工作表格子上的两种纯色图案，和 Excel 16.0 的 `Range.CopyPicture`（`xlScreen`、`xlBitmap`）差 0。点用整张图的像素坐标。前景是点，背景是底。

2026-11-15 用 Excel 16.0 量过。关掉网格后，这些图案在填充矩形里只有两种纯色，没有灰边。坐标含左边和上边那 1 像素外框。后画的格子盖住交界。

- `gray125`：`(y % 4 == 2 且 x % 4 == 2)` 或 `(y % 4 == 0 且 x % 4 == 0)`
- `gray0625`：`(y % 8 为 2 或 6 且 x % 8 == 4)` 或 `(y % 8 为 0 或 4 且 x % 8 == 0)`
- `lightHorizontal`：`y % 4 == 0`
- `darkHorizontal`：`y % 4` 为 0 或 1
- `lightVertical`：`x % 4 == 0`
- `darkVertical`：`x % 4` 为 0 或 1
- `lightGrid`：`x % 4 == 0` 或 `y % 4 == 0`
- `darkGrid`：`y % 4` 为 1 或 2 时 `x % 4` 为 1 或 2，否则 `x % 4` 为 0 或 3
- `mediumGray`：`(x + y) % 2 == 0`
- `lightGray`：奇数行 `x % 4 == 2`，偶数行 `x % 4 == 0`
- `darkGray`：奇数行只留 `x % 4 == 1` 为底，偶数行只留 `x % 4 == 3` 为底
- `darkDown`：`(x - y)` 的非负余数 mod 4 为 0 或 1
- `lightDown`：`x % 4 == y % 4`
- `darkUp`：`(x + y) % 4` 为 2 或 3
- `lightUp`：`(x + y) % 4 == 3`
- `darkTrellis`：`y` 为偶数，或与 `darkUp` 相同
- `lightTrellis`：偶数行与 `lightDown` 相同，奇数行 `x` 为奇数

列宽 10（75 像素）和第 1 行 16 磅（21 像素）把相位错开。A、B 两列的 `gray125` 仍落在同一套整图坐标上，不是每格从头排。`fgColor` 为 `EE4455`、`bgColor` 为 `112233` 时，点是前者，底是后者。没写颜色时点是黑、底是白。只写前景时底仍是白。

2026-11-15 手测：上面这 20 格，关掉网格，Excel 16.0 的 `CopyPicture` 是 332×82。库和金样 differ=0，maxDelta=0。
