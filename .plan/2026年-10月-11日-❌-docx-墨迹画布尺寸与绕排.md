# docx 墨迹画布尺寸与绕排

状态：❌
日期：2026-10-11

对应 `roadmap/docx.md` 待做序号 **58**。前置：`.plan/2026年-10月-9日-✅-docx-墨迹画布.md`。不要和批注墨迹、3D 合成一份。不把手写识别成字。

inspect 已有 `cx` / `cy` / `wrap`。`insertInkCanvas` 可写成对 `cx` / `cy`。只有 `replaceInkCanvas` / `deleteInkCanvas`。对墨迹 id 发 `setPictureSize` / `setPictureWrap` 报 `InvalidId`。

## 目标

已有墨迹画布能改 `wp:extent` 与行内 / 浮动绕排。不换 InkML。不写独立 `wpi` 画布。

## 已锁定

- `setInkCanvasSize`：id 必须是墨迹画布 id。字段与 `setPictureSize` 相同（`cx` / `cy` 至少给一个）。写入宿主 `wp:extent`；若有 `a:ext` 一并改。
- `setInkCanvasWrap`：字段与 `setPictureWrap` 相同。位置只支持相对页边，与图相同。
- `replaceInkCanvas` 仍不改几何。
- 注内 / 批注内仍不编、不插。xlsx / pptx 上发这两条报 `InvalidField`。
- 手测编号 **Is**。脚本 `manual-check/office/cases/docx-ink-geom.ps1`。不要和 Ic 撞。

## 不做

- 编辑 InkML 笔画
- 独立 `wordprocessingInk` 写入路径
- xlsx / pptx 工作表或幻灯片墨迹（仍先探测）
