## 已锁定（写入契约，实现时不要改）

- 真源是工作表 `<sheetProtection>`（§18.3.1.85）与 workbook `<workbookProtection>`（§18.2.29）。图表工作表用 `CT_ChartsheetProtection`（`@content` / `@objects`）。
- 不要复用 docx 根上的 `protection`。xlsx 根用 `workbookProtection`，表上用 `sheetProtection`。不要另给 scope 键。
- 复用 op 名 `setProtection`。工作表 id 为 `sheet:{name}`，工作簿 id 为 `xlsx:workbook`。pptx 仍拒绝。
- Excel 16.0 无密码 `Protect()` 写出 `<sheetProtection sheet="1" objects="1" scenarios="1"/>`。允许格式化单元格时再加 `formatCells="0"`。带密码写出 `algorithmName="SHA-512"` 与 `hashValue` / `saltValue` / `spinCount="100000"`。
- 权限键与 XML 同向：`true` 表示锁住。不把哈希放进树。出现 `password` 或已有哈希时报 `NotImplemented`。
- 单元格 `locked` 是样式位，本期不动。
- create 本期不写保护。

## 不做

- 写入 Excel 认识的密码哈希
- IRM
- `protectedRanges` / `fileSharing`

无。

## 验收

无密码保护工作表后 Excel 认保护；解开后能改格；锁工作簿结构后 COM `ProtectStructure` 为真；带哈希样例 inspect 不报明文，apply 改保护得 `NotImplemented`。
