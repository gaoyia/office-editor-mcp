## 已锁定（实现时不要改）

- 继续用现有 `setTransition`，不新开 op。仍整段替换 `<p:transition>`（含 AlternateContent）。不写 `sndAc`。不写 `<p:timing>`。
- inspect 对象字段顺序：`type`、`dur`、`advClick`、`advTm`，然后有则跟 `dir`，再有则跟 `invX` / `invY`。`advClick` 缺属性为 `true`（属性 `0` / `false` 为 `false`）。`advTm` 无该属性为 `null`。
- `type` 为 `prstTrans` 时取 `prst` 属性。白名单：`fallOver` / `drape` / `curtains` / `wind` / `prestige` / `fracture` / `crush` / `peelOff` / `pageCurlSingle` / `pageCurlDouble` / `airplane` / `origami`。不在名单里的 `prst` 仍为 `other`。
- 写入 prst：与 `morph` 一样走 `mc:AlternateContent`，Choice `Requires="p15"`，子元素 `p15:prstTrans prst="…"`，`invX` / `invY` 为真时写 `"1"`，Fallback `p:fade`。
- `setTransition`：`advClick` 省略为 `true`（不写属性）；`false` 写 `advClick="0"`。`advTm` 省略或 `null` 不写属性；正整数毫秒写入。`dir` 写在效果子元素上，省略则不写（与 Office 默认一致）。该效果没有 `dir` 却给了 `dir`，或 `dir` 不在该效果允许值里，报 `InvalidField`。`invX` / `invY` 只认 prst；给到别的 `type` 报 `InvalidField`。
- `dir` 允许值：`wipe` / `push` / `pan` / `vortex` 为 `l` / `r` / `u` / `d`；`cover` / `pull` 再加四角；`strips` 为四角；`blinds` / `checker` / `comb` / `randomBar` / `doors` / `window` 为 `horz` / `vert`；`zoom` / `warp` / `split` 为 `in` / `out`；`conveyor` / `gallery` / `ferris` / `flip` / `switch` / `reveal` 为 `l` / `r`。
- `type` 为 `null` 时忽略上述新字段，仍清整节。
- 不写 `split/@orient`、`wheel/@spokes`、`thruBlk`、声音。
