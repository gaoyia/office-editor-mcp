# 工作表有描边的形状

状态：⚠️
日期：2026-11-16
分类：功能缺失

对应 C25 第 12 段，序号 **84**。没有描边的纯色矩形及其直角旋转、翻转已差 0。有描边的形状此前让整表失败。

## 目标

点名的有整像素描边的纯色矩形与 Excel 16.0 差 0。外角对不上则继续失败，不加大容差。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 对照官方描边和外角 | ⚠️ |
| 1 | 只画这一档 | ✅ |
| 2 | 手测差 0 | ⚠️ |

## 本刀交付（2026-11-17，Asia/Shanghai）

- 库内：轴对齐、不透明 `srgbClr`（或无变换 `schemeClr`）/`noFill` 填充 + 线宽恰好 9525/19050 EMU 的不透明实线描边 `prst=rect`，复用 PPT 已锁的 GDI+ `fill_device_stroked_rect`（1px 无偏移 / 2px 半像素，圆角接缝，平头）。`oneCell` / `absolute` / `twoCell` 锚点均解析；组合内描边 NI（不默画错）。其它线宽（含缺省/非 9525·19050）、虚线、箭头、显式接缝、`algn≠ctr`、旋转/翻转描边、半透明填/线 → 整块形状 NotImplemented。
- 官方：`xlsx-sheet-stroke-image`（absolute 由 A1 oneCell 改写 + oneCell 独立 + twoCell 证据）。本机 `GetDpiForSystem=106`，CopyPicture 与库图 **sizeDiffer**（例 oneCell 金样 73×89 vs 库 65×81；无描边基线 `xlsx-sheet-shape-image` 同机亦 73×67 vs 65×61）。**不**缩金样、**不**改系统 DPI、**不**放宽容差；整图像素差 0 门未过 → ⚠️。PPT 描边外角单测 `a_one_pixel_rect_stroke_matches_office_corners` 仍 PASS（0 差代表回归保护）。
- twoCell 保留为独立对照，不因 absolute/oneCell 偷换验收。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不重做没有描边的矩形
- 图表工作表另见 `.plan/2026年-11月-16日-❌-xlsx-图表工作表出图.md`
- 主题色变换 / 翻转描边 / 组合内描边未支持，不默画错
