## 第 0 步结论（Word 16.0，2026-10-09）

探测脚本（不要提交、不要进 `run.ps1`）：`_probe-docx-37-revision.ps1`、`_probe-docx-37-revision-2.ps1`、`_probe-docx-37-revision-3.ps1`。create 产物两段 + 一张 2×2 表，`TrackRevisions = true`，TEMP 里 `Save()`。

1. **移动**：`TrackMoves = true` 后 COM 剪切 + 粘贴仍写成 run 级 `w:del` + `w:ins`，没有 `w:moveFrom` / `w:moveTo` / RangeStart。本刀不做 move。
2. **整段插入**：新空段 `w:pPr/w:rPr` 上有空的 `<w:ins/>`（段落标记插入）。COM `Revisions.Count = 1`，`Type = 1`。Accept 后该空段留下、ins 消失；Reject 后该空段消失。
3. **整段删除文本**：仍是 run 级 `w:del`（第 13 刀已收），不是块级包 `w:p` 的 `ins`/`del`。
4. **删表行**：`w:trPr` 上有空 `<w:del/>`，格内另有段落标记 `pPr/rPr/del` 与 run 级 `w:del`。COM `Revisions.Count = 1`，`Type = 2`。Accept 后该行消失；Reject 后两行都在、del 全部消失、格字还原。
5. **改格底纹 + 加粗**：写出 `tblPrChange`、`tblGridChange`（无 author/date）、`tblPrExChange`、`tcPrChange`、以及已收入的 `rPrChange`。没有 `trPrChange`、`sectPrChange`。AcceptAll 留下当前底纹与加粗并去掉 Change；RejectAll 去掉底纹与加粗。COM 把全部 `rPrChange` 当成一条，其余表 Change 当成另一条；树上仍按 XML 节点各列一条。

## 已锁定（写入契约后不要改）

- 继续按 XML 节点编号 `rev:{n}`。`kind` 增加：`paraMarkIns`、`paraMarkDel`、`rowIns`、`rowDel`、`tblPrChange`、`tblGridChange`、`tblPrExChange`、`tcPrChange`、`trPrChange`、`sectPrChange`。
- run 级 `ins` / `del` 与 `rPrChange` / `pPrChange` 语义不变。
- `paraMarkIns` / `paraMarkDel`：`pPr`（含其中 `rPr`）里、且不在 `w:r` 内的空 `ins`/`del`。若祖先 `w:tr` 的 `trPr` 已有 `ins`/`del`，这些段落标记是行修订的伴随节点，不另列。
- `rowIns` / `rowDel`：`trPr` 里的空 `ins`/`del`。接受行删除或拒绝行插入：删掉整行 `w:tr`（只剩一行时报 `InvalidField`）。拒绝行删除或接受行插入：去掉该行标记，并把该行内 run 级 `del` 还原、run 级 `ins` 拆壳、伴随段落标记去掉。
- `paraMarkIns` 接受：去掉该空 `ins`，留下该段。`paraMarkIns` 拒绝 / `paraMarkDel` 接受：删掉该 `w:p`；容器只剩该段时报 `InvalidField`；该段带 `sectPr` 或跨段范围标记时报 `NotImplemented`。`paraMarkDel` 拒绝：去掉该空 `del`。
- 表 / 节 `*Change`：接受删掉 Change、留下当前属性；拒绝用 Change 内旧属性替换当前容器。`tblGridChange` 常无 author/date，树上仍为 `null`。
- 不进树：`w:moveFrom` / `w:moveTo`、块级包 `w:p`/`w:tbl` 的 `ins`/`del`、框内 / 注内 / 批注内修订。
- 表结构 op 仍因这些痕迹报 `NotImplemented`（含 `tblPrExChange`）。`setParaText` 碰到已收入的段落标记修订也报 `NotImplemented`。
- 手测组号 **Rm**。脚本 `manual-check/office/cases/docx-revision-remain.ps1`。不要和 Rv、Pr、Pb、Ph 撞。
