## 第 0 步（Word 16.0）

探测脚本 `manual-check/office/cases/_probe-docx-32-biblio.ps1`（不要提交、不要进 `run.ps1`）。2026-10-09 Word 16.0：

- 访问 `Bibliography` 就会建 `/customXml/itemN.xml`：`b:Sources`，默认 `SelectedStyle="\APASixthEditionOfficeOnline.xsl"`、`StyleName="APA"`、`Version="6"`。`itemProps` 的 `ds:schemaRef` uri 为 bibliography 命名空间。主文档 `.rels` 有 `/customXml` 关系。
- `Sources.Add` 把 `<b:Source>` 追加进去，Word 会补 `b:RefOrder`。COM `Range.InsertCitation` / `InsertBibliography` 不存在。
- `Fields.Add` type=-1、指令 `CITATION Book01`：复杂域，COM type=96，包在行内 `w:sdt`（`sdtPr` 里空的 `w:citation`，无 `dataBinding`）。有源时更新结果为 `(Ecma, 2006)`。
- `Fields.Add` type=-1、指令 `BIBLIOGRAPHY`：复杂域，COM type=97，**不**包 `w:sdt`。begin 与结果可与正文同段，`end` 可在后续段。不要用 type=75（那是 MERGESEQ）。
- COM `ContentControls.Count` 为 0（citation SDT 不进该集合）。本期内容控件名单继续不收 `citation` / `bibliography`。

## 已锁定（探测后写入契约，不要改）

- CITATION / BIBLIOGRAPHY 仍是域：继续出现在 `fields`。另给 `cite:{n}` / `biblio:{n}`。书目源来自 customXml，id 为 `source:{n}`。
- 根上始终有 `sourceCount` / `citationCount` / `bibliographyCount`，放在 `indexEntryCount` 之后、`mathCount` 之前。只计主文档。页眉页脚容器不出现这三项。
- `scope.sources` / `scope.citations` / `scope.bibliographies` 才列名单。嵌套在其它域结果里的 CITATION / BIBLIOGRAPHY 不进名单。
- `insertSource`：id 为 `docx:document`。没有 bibliography customXml 则新建（空 `b:Sources` + itemProps + 关系 + itemProps Override）。`tag` 必填且包内唯一。默认 `sourceType` 为 `Book`。写入 `b:RefOrder`（现有源个数加 1）。
- `insertCitation`：id 为段落（正文或页眉页脚）。追加行内 `w:sdt`（`w:citation`）+ 复杂 CITATION（begin dirty、指令 ` CITATION {tag} `、separate、end，不写结果）。`tag` 必须已在源名单里。
- `insertBibliography`：id 为 body 直接子段落或 `docx:document`。新 `w:p`：复杂 BIBLIOGRAPHY（与 INDEX 相同：dirty、separate、不写结果）。不写 Bibliography 样式，不包 `w:sdt`。
- `deleteSource` / `deleteCitation` / `deleteBibliography`：按对应 id。删引文时若包在 `w:citation` 的 sdt 里则整块删掉 sdt。删书目按 INDEX 那套清空段。不按构建基块删。
- 不在库里求值。Word 打开后刷新是预期。
- create 本期不写书目。框内 / 注内 / 批注内本期不编。xlsx / pptx 上这些 op 与 scope 键报 `InvalidField`。
- 手测编号 **Bi**，脚本 `manual-check/office/cases/docx-biblio.ps1`。
