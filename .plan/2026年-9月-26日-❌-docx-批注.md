# docx 批注

状态：❌ 未开始  
日期：2026-09-26

批注是标注，不是正文段落。现行契约不进树。本期做查、改字、插入、删除、回复、标记完成。不做批注气泡排版。

规范线索：ECMA-376 §17.13。内容在 `/word/comments.xml` 的 `w:comment`（`w:id`、`w:author`、`w:date`、`w:initials`）。主文档用 `w:commentRangeStart` / `w:commentRangeEnd` / `w:commentReference` 成对标定范围。Word 2013 以后还有 `commentsExtended.xml`（完成、父批注）、`people.xml`、以及更新的 commentsIds / commentsExtensible。改的时候这些部件要一起维持，不能只改 `comments.xml` 让 Word 修复。

## 目标

批注能列、读、改字，能按段落范围插入，能删，能回复成线程，能标完成。批注里的图复用图片 op。

## 稳定 id

| 节点 | id | 例子 |
| --- | --- | --- |
| 批注 | `comment:{id}` | `comment:0` |
| 批注内段落 | `comment:{id}/para:{paraId}` | `comment:0/para:3F2A1B00` |
| 批注内图 | `{批注段落 id}/pic:{docPrId}` | `comment:0/para:3F2A1B00/pic:1` |

`{id}` 取 `w:comment/@w:id` 原文，按十进制数值匹配。范围 start/end 的 `w:id` 与 comment 的 `w:id` 应对上；对不上报 `XmlBroken`。

`parent` 取 extended 里的父批注 id，没有则为 `null`。根批注的 `parent` 为 `null`。

## inspect

- 省略 `scope.comments` 时只有计数。
- 给了就返回全部批注，按 `w:comment` 在部件里的顺序。字段：`id`、`commentId`、`author`、`initials`、`date`、`done`、`parent`、`start`、`end`、`paraCount`、`pictureCount`。
- `start` / `end` 是范围落在的正文（或框、页眉）段落 id。范围跨段时 `start` 与 `end` 不同。找不到对应段（残缺标记）则该侧为 `null`，并仍列出该批注，不要丢。
- 不把墨迹、语音批注做成可编辑节点；若 XML 里有，inspect 可标 `kind: "ink"` 之类，apply 除 `deleteComment` 外报 `NotImplemented`。

## apply

插入：分配未占用 comment id，在 `start` 段合适位置写 `commentRangeStart`，在 `end` 段写 `commentRangeEnd` 与 `commentReference`（具体插点：该段现有内容之后、`w:pPr` 之后，写进契约）。没有 `comments.xml` 则建部件与关系。

删除：该 id 的三处标记都去掉；子批注按契约要么级联删，要么拒绝并报 `InvalidField`。推荐级联删，并在清单里验回复没残留。

回复：新 id，范围与父批注相同（Word 常见写法），extended 指向父 id。

`setCommentText` 只改 `w:comment` 里的可见 `w:t`，不改范围。

## 不做

- 批注窗格怎么排、怎么画气泡
- 修订痕迹（`w:ins` / `w:del`）与批注混在一起的接受或拒绝
- 墨迹、语音的内容编辑
- xlsx / pptx 批注（xlsx 的 18.7、pptx 的 19.4 另开）

## 验收

- Word 另存带两条批注、一条回复；inspect 的作者、范围、`parent`、`done` 对。
- 改批注字、插入新批注、删除后 Word 无修复；审阅窗格里条数对。
- 标记完成后 COM 或 Word UI 显示已解决。
- 批注内插图无修复。
- 只改批注文本时，未点名的正文段落字节在保真度测试里按「范围标记未动」验收。
