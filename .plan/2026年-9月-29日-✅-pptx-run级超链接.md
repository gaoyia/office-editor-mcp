Office 16.0：

- `Shape.ActionSettings` → `p:cNvPr/a:hlinkClick`（形状级）
- `TextRange` / `Characters` → `a:rPr/a:hlinkClick`。部分选区拆 run。两条链两个 `rId`。
- 跳页：`action="ppaction://hlinksldjump"`，slide 关系。URL：External hyperlink 关系，无 `action`。
- 不写 `a:hlinkHover`，不写下划线，不改成主题超链接色。

inspect：同一份 `hyperlinks`，id 仍是 `slide:{n}/link:{k}`。每个形状先形状级、再 run 级。每条多 `on`（`shape` / `run`）与 `text`（run 取该 `a:t`，形状级为 `null`）。

apply：

- `insertHyperlink` 可选 `on`：省略或 `shape` 为现行为；`run` 则写 `a:rPr`。给了 `text` 时追加新 `a:r`。没给则挂到最后一段最后一个无链 `a:r`。
- `setHyperlink` / `deleteHyperlink` 认两种宿主。删 run 级只去掉 `a:hlinkClick`。
- 不认 `a:hlinkHover`，不认 `a:fld` / `a:br` / `endParaRPr` 上的链。
