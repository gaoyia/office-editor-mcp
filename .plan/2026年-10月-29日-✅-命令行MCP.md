# 命令行 MCP

状态：✅ 已落地。`cargo test -p ooxp-cli` 通过。`cargo clippy -p ooxp-cli --all-targets --all-features -- -D warnings` 通过。
日期：2026-10-29

不在 `roadmap/docx.md`、`roadmap/xlsx.md`、`roadmap/pptx.md` 的待做表里。这是用户点名的命令行模式，不占待做序号。领域 JSON 不改字段。

契约真源仍是 `docs/`。本切片改的是命令行怎么把领域 JSON 放进 JSON-RPC，不是新的操作字段。

## 目标

同一个 `ooxp` 可执行文件增加 `ooxp mcp`。它从标准输入读 JSON-RPC，把结果写回标准输出。工具是 `inspect`、`create`、`apply`、`exportMedia`、`exportChartData`、`help`。参数仍是领域 JSON，`action` 由工具名补上。操作怎么填继续走 `help`，不把每个 `op` 做成一个工具。

不带 `mcp` 时，命令行仍是读一份领域 JSON、交给库、然后退出。

## 不做

- 不改 `inspect`、`apply`、`create`、`help`、`exportMedia`、`exportChartData` 的领域字段。
- 不在库里解析 JSON-RPC。`crates/ooxp` 仍只认领域 JSON。
- 不把 `ops` 拆成另一套工具参数。
- 不在 `roadmap/` 里为 MCP 开格式待做。
