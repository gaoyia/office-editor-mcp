# 超大已用区域按 4096 切块

状态：⚠️
日期：2026-11-16
分类：功能缺失→本刀有限交付

对应 C25 第 13 段，序号 **84**。一边超过 4096 时默认仍 `NotImplemented`；可选 `tilePx` 按块导出，不分配整表画布。

## 目标

超过 4096 的已用区域按 4096 切块导出多张 PNG，每一块与 Excel 16.0 对应区域的 `CopyPicture` 差 0。契约写明块的 id 和命名。单块仍不得超过 4096。

## 步骤

| 序号 | 内容 | 状态 |
| --- | --- | --- |
| 0 | 契约写明切块规则和输出 | ✅ `tilePx` + `paths` / `{stem}-rRcC.png` |
| 1 | 实现切块导出 | ✅ 资源有界 `Canvas::window`；默认 API 不绕 4096 |
| 2 | 用手测对照至少一块边界和一块内部 | ⚠️ 一致性门：小图 tile 拼接 vs 整图 **differ=0**；未跑官方超大 CopyPicture |

## 机制（2026-11-17 Asia/Shanghai）

- `Canvas` 带绝对原点 `(ox,oy)`，`put`/`grid`/`leading_frame` 按窗裁剪；每块只分配 `tw×th≤tilePx≤4096`。
- 不加 `tilePx`：行为不变，一边 >4096 → NI（不偷偷绕上限）。
- `tilePx` 1–4096：未超限走整图路径（与旧像素一致）；超限行主序切块。RTL 切块 NI。
- 本机多块：zip 中转后落盘 `{stem}-r{row}c{col}.png`，`Written.paths` 列出。
- 集成 `xlsx_sheet_tiles`：4×4 格 `tilePx=40` 拼接 == mono 逐像素；`tilePx=0` → NI。

## 不做

- 不靠加大容差、不改金样、不在对照图上补像素
- 不把像素写回包，也不塞进 inspect
- 不把其它段、其它对象类算进这一份的通过
- 官方对照只认 Microsoft Office 16.0，不认 WPS
- 不把整张超大表画成一张图
- 不在这一份里补第 7–12 段还不会画的对象
- 不把未设 `tilePx` 的默认导出改成自动切块
