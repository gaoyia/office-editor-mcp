### 成立

下面这些和代码一致，留下。

- 不支持预览。`help` 的 limits 仍写不调用 Office 导出。
- create 的 `document.protection.password` 仍报 `NotImplemented`（`docx/protect.rs` 的 `apply_create`）。apply 的 `password` 已经能写哈希。这是下一份 `docx-create写限制编辑口令` 的范围，本份不改行为。
- `insertCrossRef` 仍不写 `NOTEREF`。inspect 能读 `kind: note`。写入留给路线图 docx 71。
- xlsx 的 `exportChartData` 仍是 `InvalidField`（`ActionNotForFormat`）。
- 股价、曲面、复合饼的 `addChartSeries` / `deleteChartSeries` 仍报 `NotImplemented`。
- docx 框内、注内、批注内的 OLE、3D、修订、目录、题注、索引、书目、连接线、形状，以及页眉页脚上不编的 `xref:` / `xe:` / `cite:`，代码仍按文档拒绝或只计正文字段。后面的「容器内对象」「容器内域块」才接这些。
- xlsx 页眉、图表工作表、OLAP、孤立切片器不进对应名单。页眉图示、页眉 OLE、页眉 3D、页眉墨迹同样不进树。
- pptx create 仍不写批注内图。`insertPlaceholder` 仍不写 `obj` / `chart` / `tbl` / `pic` / `media` / `sldImg`。批注内仍不插 3D 和公式。
- 数据表公式仍不新建、不拆、不扩缩。create 骨架仍先写普通 `<f>`，共享公式和数组公式再按 `setCell` 改写。
- 「不含页眉页脚 / 框内 / 注内 / 批注内」的计数字段是范围说明，不是过期的「不做」。`pictureCount` 仍只数主文档段落里的图（`body_picture_count`）。
- 「本期 DrawingML 对象」「本期收入的域 / 修订 / 拼音」指当前已经进树的那一类，不是还没做。
