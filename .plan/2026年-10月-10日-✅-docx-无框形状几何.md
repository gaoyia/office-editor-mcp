## 目标

Word 16.0 会写出的无文本框 `wps:wsp` 能进 inspect，能插、删、改位置、尺寸、填充与线。不算排版引擎。不编辑 VML。框内再套框保持 🚫。注内 / 批注内不插形状。不要把 pptx 的 `insertShape` 语义原样搬过来：Word 的 id 仍跟段落宿主走。

## 第 0 步探测（2026-10-10，Word 16.0）

`Shapes.AddShape`：矩形 Type=1 / AutoShapeType=1，椭圆 9，圆角矩形 5。`HasTextFrame=0`。

三个 `wps:wsp`：

- `prst` 为 `roundRect` / `ellipse` / `rect`
- 没有 `wps:txbx`、没有 `txBox` 属性、没有 `cNvCnPr`
- 空 `wps:cNvSpPr/`
- 有 `wps:style`（theme `schemeClr`，inspect 不要解析主题色）
- 有 `wps:bodyPr`（无 txbx），含 `prstTxWarp textNoShape`
- 浮动 `wp:anchor` + `wp:wrapNone`
- `positionH relativeFrom="column"` + `posOffset`，`positionV relativeFrom="paragraph"` + `posOffset`
- 独立 AutoShape 常常没有 `wps:cNvPr`，`wp:docPr/@id` 是很大的整数

现有 inspect 把这些当成未知 `wsp`，完全不进树。连接线判定仍是：无 txbx，且有 `cNvCnPr` 或连接线几何名。

## 已锁定

### 判定

- 形状：`wps:wsp`，没有 `txbx` / `txbxContent` / `linkedTxbx`，且不是连接线（不要把连接线收进 `shapes`）。
- 组合本身仍不进树；组合里符合条件的子 `wps:wsp` 要展开（`cNvPr/@id`，没有则 `shape:index:{k}`）。
- 注内 / 批注内 / 框内本期不编、不插。对这些容器发 `insertShape`：注 / 批注报 `InvalidField`（`GraphicInRestrictedStory`），框内报 `InvalidId`。
- 页眉页脚要收，规则对齐连接线。

### inspect

- 新 `scope.shapes`（docx 专用解析）。xlsx / pptx 的 scope 出现 `shapes` 仍按现有规则。
- 根上 / 段落 / 页眉页脚容器始终 `shapeCount`。键序插在 `connectorCount` 之后、`inkCanvasCount` 之前。
- 注节点与批注节点不加 `shapeCount`，也不填 `shapes`。
- 每条字段顺序：`id`、`docPrId`、`name`、`kind`、`cx`、`cy`、`wrap`、`prst`、`stable`。对齐连接线，本期 inspect 不报 fill / line。
- id：`{宿主段}/shape:{docPrId}`；没有 `docPr`/`cNvPr` 则为 `/shape:index:{k}`，`stable: false`。`k` 只在该宿主段内从 1 计。
- 独立形状取外层 `wp:docPr/@id`。组合子形状取该 `wps:wsp` 的 `cNvPr/@id`。
- 不报 `text`。不把 `insertHyperlink` 扩到形状 id。

### apply

复用现有 op 名，不要新开 Word 专用 op。

- `insertShape`：id 必须是正文或页眉页脚段落 id。禁止 `text`、`x` / `y`、`geom`、`from` 等。`prst` 可选，缺省 `rect`，必须是 `crate::pptx::shape::is_writable_shape_prst`。连接线几何名报 `InvalidField`（`InvalidShapePrst`）。`cx` / `cy` 必须成对或成对省略；省略默认 `1828800` × `914400`。
- 写入对齐 `insertConnector` / `insertTextBox`：`mc:AlternateContent` `Requires="wps"`，Fallback 空白 `w:pict`。浮动 `wp:anchor` + `wrapSquare`，`positionH/V relativeFrom="margin"` + `align` left/top。`wps:cNvSpPr` 空（不写 `txBox`），无 `txbx`，空 `wps:bodyPr`。不写 `wps:style`。显式填充 `FFFFFF`、线宽 `6350` 黑色描边。`wp:docPr/@name` 写成「形状 {id}」。
- `deleteShape`：id 必须是形状 id。
- `setShapeSize`：`cx` / `cy`，至少一个；改 `wp:extent` + `a:xfrm/a:ext`。
- `setShapePos`：共用 pptx 字段名 `x` / `y`（EMU），至少一个。写成 `wp:positionH/V` 的 `posOffset`，`relativeFrom="margin"`。行内没有 `anchor` 时报 `InvalidField`（`DocxShapeNeedsAnchor`）。
- `setShapeFill` / `setShapeLine`：字段与 pptx / 现有 `setTextBoxFill` / `setTextBoxLine` 相同。写入 `wps:spPr`。不要解析或删除 `wps:style`。
- 本期仍不认：`setShapeGeom`、`setShapeFormat`、`setShapeText`、`setConnector`。
- `groupShapes` / `ungroup` 必须收形状 id 为成员。解开组合时走 `Requires="wps"`。

### 错误 / id

- 新增 `IdReason::DocxShapePrefix`、`DocxShapeContainer`。
- `InsertNeedsHostPara` 文案扩到包含 `insertShape`。
- `parse_cxn_id` / `looks_like_cxn_id` 拒绝 `/shape:`。
