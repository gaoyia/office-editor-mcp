# xlsx 公式求值对照

状态：⚠️
日期：2026-11-10

对应 `roadmap/xlsx.md` 待做序号 **50**。前置：公式结构已过。一类没记全之前，不写该类的求值代码，也不另开实现切片。

缘起是 MCP 试用里的第 1 条。`create` 写入公式后，能算的格会写缓存 `<v>`，并在 `calcPr` 上设 `fullCalcOnLoad="1"`。`inspect` 的 `value` 来自已有 `<v>`，没有 `<v>` 时为 `null`。`formula` 由库在 `<f>` 原文前补 `=`。没样本的类仍然不求值。现在没有单独的重算动作。

2026-11-10 对过 `docs/json-contract-xlsx.md` 与 ECMA-376 第 18.17 节。下表里标「契约已定」的，以分册为准，不在本计划里改口。

## 目标

先把计算方式分门别类记全。某一类记全、并且有 Excel 16.0 的实际结果之后，再为该类写单元测试。期望值取电子表格算出来的结果，不拿另一套实现当标准。

## 本期不做

- 不改 `docs/` 契约
- 不写求值代码，不加 MCP 重算工具
- 不改 `create` / `inspect` 的现有行为：公式仍是字符串。新建公式格不写 `<v>`。已有 `<v>` 时 `inspect` 仍读缓存，不把它改成 `null`
- 不把图表渲染、与 Excel 像素级一致挪进本计划。这两项仍在 `roadmap/xlsx.md` 的永不做里

## 计算方式

| 门类 | 要记清的差别 | 状态 |
| --- | --- | --- |
| 普通单元格公式 | 常量、A1 引用、算术。文件里的引用始终是 A1 | 可测 |
| 函数调用 | 内置函数按 §18.17.7，不在本表逐个展开 | 可测 |
| 引用运算符 | `:` 区域，`,` 并集，空格交集。空交集为 `#NULL!` | 可测 |
| 比较、连接、百分号 | 比较得到逻辑值，`&` 得到文本，`%` 把数缩小一百倍 | 可测 |

| 数据表 | `TABLE` 主格与输入格。可以新建，仍不求值。Excel 样本见新建计划的手测 | ❌ |
| 结构化引用 | 表公式。契约写明不求值 | 可测 |

## 手测

脚本 `manual-check/office/cases/xlsx-formula-oracle.ps1`，编号 **Xfo**。库先写入公式，不写缓存。然后打开本机 Excel 16.0 重算。通过标准是：Excel 格子上的结果，和随后 `inspect` 读到的 `value` 相同。算术类还核对确定的得数。

| 检查 | 门类 | 格子 | Excel 应得 |
| --- | --- | --- | --- |
| Xfo0 | 库先写缓存 | `数据!C1` | 打开 Excel 前已经是 5 |
| Xfo-C1 | 普通单元格公式 | `=A1+B1` | 5 |
| Xfo-C2 | 跨表引用 | `=来源!A1` | 7 |
| Xfo-C3 | 定义名称 | `=Rate*2`，`Rate` 为 `数据!$B$1` | 6 |
| Xfo-D1 / D2 | 共享公式 | `=A1*2`，区域 `D1:D2` | 4 与 22 |
| Xfo-E1 / E2 | 数组公式 | `=A1:A2*10`，区域 `E1:E2` | 20 与 110 |
| Xfo-H1 | 结构化引用 | `=SUM(QtyTable[Qty])` | 30 |
| Xfo-I1 | 错误值 | `=1/0` | `#DIV/0!` |
| Xfo-J1 | 日期，1900 | `=DATE(2026,1,2)`，格式 `yyyy-mm-dd` | 缓存 46024。列宽不够时屏幕是 `########` |
| Xfo-1904 | 日期，1904 | 同一公式，工作簿改成 1904 | 缓存 44562 |
| Xfo-K1 | `HYPERLINK()` | `=HYPERLINK("#A1",A1)` | 2 |
| Xfo-L1 | 函数调用 | `=SUM(A1,B1)` | 5 |
| Xfo-M1 | 表级定义名 | `=LocalAdd`，公式文本 `2` | 2 |
| Xfo-N1 / V1 | 逻辑值 | `=TRUE`，`=A1>B1` | `TRUE` 与 `FALSE` |
| Xfo-W1 | 文本连接 | `=A1&"x"` | `2x` |
| Xfo-U1 | 百分号 | `=B1%` | 0.03 |
| Xfo-X1 / Y1 / Z1 | 并集、交集 | `=SUM((A1,B1))`，`=A1:B2 B1:C1`，`=A1:A2 B1:B2` | 5、3、`#NULL!` |

| Xfo-REF | 删表改写引用 | 删掉 `删` 之后 | `#REF!` |

## 以后的验收

某一类从 ❌ 改到可测时，至少有一条 Excel 16.0 样本。样本记下输入、公式原文和 Excel 算出的缓存值。单元测试只比对这个缓存值。显示格式不作为数值是否相等的依据。
