## 第 0 步（Excel 16.0 另存）

探测脚本 `manual-check/office/cases/_probe-xlsx-24-split-customview.ps1`（不要提交、不要进 `run.ps1`）。

金样：

- `SplitRow=4` `SplitColumn=2`（选 C5 再 `Split=True`，或直接写这两项）：`FreezePanes` 为假。工作表 `<pane xSplit="2595" ySplit="1425" topLeftCell="C5"/>`，不写 `state`（规范缺省 `split`）。`xSplit` / `ySplit` 是 1/20 磅，不是行 / 列数。`topLeftCell` 是拆分区右下角的下一格。直接写 SplitRow 时可以不写 `activePane`；选格再拆会写 `activePane="bottomRight"` 以及另外两个 pane 的 `<selection>`。
- 自定义视图 `CustomViews.Add("DemoView", True, True)`：workbook `<customWorkbookViews>/<customWorkbookView name="DemoView" guid="{…}" xWindow="156" yWindow="25" windowWidth="1456" windowHeight="1007" activeSheetId="1"/>`。`windowWidth` / `windowHeight` / `xWindow` / `yWindow` 是 `bookViews/workbookView` 同名属性除以 15。`includePrintSettings` / `includeHiddenRowCol` 缺省为真则不写。工作表 `<customSheetViews>/<customSheetView guid="同一 guid">` 只跟 `<pageMargins>`。
- 冻结后再 Add：`customSheetView` 复制当前 `<pane state="frozen">` 与对应 `<selection>`，再跟 `pageMargins`。
- `Add("SplitView", False, True)`：workbook 写 `includePrintSettings="0"`。`customSheetView` 只跟 `<pane xSplit="2" ySplit="4" topLeftCell="C5"/>`（这里用行 / 列数，与当前 `sheetView` 的 1/20 磅不同）。无 `pageMargins`。

不写 `xr:uid`、`x14ac:dyDescent`。

## 契约要点

- `view` 始终加 `splitRows` / `splitCols`（非负整数，缺省 0），插在 `frozenCols` 之后、`activeCell` 之前。拆分与冻结互斥：有拆分则冻结为 0，有冻结则拆分为 0。
- inspect 拆分：pane 无 `state` 或 `state="split"`，且 `xSplit` / `ySplit` 至少一个大于 0 时，从 `topLeftCell` 取列号减 1 / 行号减 1。没有 `topLeftCell` 则为 0。不要用 1/20 磅反推行列。
- `setSheetView` 加 `splitRows` / `splitCols`。与任一冻结字段同时出现报 `InvalidField`。两侧都为 0 则去掉拆分 pane。只给一侧时另一侧沿用当前拆分值（当前是冻结则当作 0）。apply 写 `topLeftCell`，把列按缺省列宽换成 1/20 磅，行按 Excel 16.0 金样（4 行 → `ySplit=1425`）写入；不写 `state`。不保证与 Excel 像素级一致。手测认 COM `SplitRow` / `SplitColumn`。
- 工作簿始终 `customViewCount`。`scope.customViews` 为 true 时展开 `customViews`。id 为 `customView:{n}`，从 1 计，按 `customWorkbookView` 文档顺序。每项：`id`、`name`、`includePrintSettings`、`includeHiddenRowCol`、`activeSheet`。不把 guid 放进树。
- apply：`insertCustomView`（id=`xlsx:workbook`）、`deleteCustomView`、`showCustomView`。`name` 必须非空、工作簿内大小写不敏感唯一。insert 给每张 `worksheet` / `chartsheet` 写对应 `customSheetView`（同一 guid）。`showCustomView` 把该 guid 的 pane / selection 写回各表第一个 `sheetView`；`includePrintSettings` 为真时还写回 `pageMargins`。不恢复隐藏行 / 列。create 本期不写拆分与自定义视图。
