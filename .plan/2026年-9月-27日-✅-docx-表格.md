## 已锁定

- 单元格内段落 id 规则与现在相同（主文档顺序含表内 `w:p`），不要另编一套段落 id。
- 嵌套表按该故事里 `w:tbl` 的文档顺序展开，id 为 `table:{n}`（页眉页脚带容器前缀）。树上 `nested` 为 `true` 表示该表的父元素是 `w:tc`。
- 框内、注内、批注内的表本期不进树；对这些容器发表格结构 op 报 `InvalidId`。
- 带修订痕迹（表 / 行 / 单元格上的 `w:ins` / `w:del` / `w:moveFrom` / `w:moveTo`，或 `tblPrChange` / `trPrChange` / `tcPrChange` / `tblGridChange`）的结构 op 报 `NotImplemented`。inspect 仍列出。
- 行 id 为 `{table id}/row:{r}`，单元格 id 为 `{table id}/r{r}c{c}`。`r` 是从 1 起的 `w:tr` 序号。`c` 是该格在 `tblGrid` 上的起始列（从 1 起）。`gridSpan` 缺省当作 1。`vMerge` 无元素为 `null`，有则为 `restart` 或 `continue`（缺 `val` 按规范当作 `continue`）。
- `setParaText` / `insertPara` / `deletePara` 继续只动 `w:p`，不插删 `w:tbl` / `w:tr` / `w:tc`。

## 不做

- 自动列宽、绕排计算、与 Word 像素级一致
- 公式域 `=SUM(ABOVE)` 求值
- 表样式主题的完整复制；新建表只写单线边框与等宽 `gridCol`（每列 1440 twip）
- `tblpPr` 浮动定位、斜线、单元格边距与底纹
