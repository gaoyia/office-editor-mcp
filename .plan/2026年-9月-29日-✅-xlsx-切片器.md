## 第 0 步结论（2026-09-29，Excel 16.0）

脚本：`manual-check/office/cases/_probe-xlsx-21-slicer.ps1`（不进 `run.ps1`）。表格切片器：`$wb.SlicerCaches.Add($listObject, '产品')` 再 `$cache.Slicers.Add($ws, Missing, name, caption, top, left, width, height)`。透视切片器：先 `insertPivotTable`，再 `$ws.PivotTables()`、`$wb.SlicerCaches.Add($pt, '产品')`。

### 表格切片器

- `/xl/slicers/slicer1.xml`：根 `slicers`（x14），`slicer/@name`、`@cache`、`@caption`、`@rowHeight`
- `/xl/slicerCaches/slicerCache1.xml`：`slicerCacheDefinition/@name`、`@sourceName`（列名）；`extLst` 里 `x15:tableSlicerCache/@tableId` 与 `@column`（1 基列号）
- 工作表 `.rels`：drawing、table、slicer（Type `http://schemas.microsoft.com/office/2007/relationships/slicer`）
- 工作簿 `.rels`：slicerCache（Type `http://schemas.microsoft.com/office/2007/relationships/slicerCache`）
- 工作表 `extLst`：`uri="{3A4CF648-6AED-40f4-86FF-DC5316D8AED3}"`，`x14:slicerList/x14:slicer/@r:id`
- 工作簿 `extLst`：`uri="{46BE6895-7355-4a93-B00E-2C351335B9C9}"` 的 `x15:slicerCaches`，里面 `x14:slicerCache/@r:id`
- drawing：`twoCellAnchor` 是 `wsDr` 的直接子元素；`mc:Choice Requires="sle15"` 只包 `xdr:graphicFrame`，`a:graphicData/@uri` 为 `http://schemas.microsoft.com/office/drawing/2010/slicer`，`sle:slicer/@name` 与 slicer 部件 `@name` 相同。Fallback 是说明文字的 `xdr:sp`
- `[Content_Types]`：Override slicer `application/vnd.ms-excel.slicer+xml`，slicerCache `application/vnd.ms-excel.slicerCache+xml`

### 透视切片器

- slicer 部件形态与表格相同
- slicerCache：`pivotTables/pivotTable/@tabId` 与 `@name`；`data/tabular/@pivotCacheId` 加 `items/i`
- 透视缓存定义 `extLst`：`uri="{725AE2AE-9491-48be-B2B4-4EB974FC3084}"` 的 `x14:pivotCacheDefinition/@pivotCacheId`，必须与 `tabular/@pivotCacheId` 相同。缺这条时 Excel 16.0 `Workbooks.Open` 失败
- 工作簿 `extLst`：`uri="{BBE1A952-AA13-448e-AADC-164F8A28A991}"` 的 `x14:slicerCaches`（不是 x15 那条）
- drawing：`twoCellAnchor` 是 `wsDr` 的直接子元素；`mc:Choice Requires="a14"` 只包 `xdr:graphicFrame`，Fallback 只包 `xdr:sp`，`xdr:clientData` 在 AlternateContent 之后

## 契约（已写入 docs/）

- 只认工作表 drawing 里 `a:graphicData/@uri` 为 2010/slicer（可带尾斜杠）的 `graphicFrame`，且 `sle:slicer/@name` 能对上该表 slicers 部件里的 `slicer/@name`。时间线 `timeslicer`、没有 drawing 的孤立 slicer 部件本期不进树。
- id：`sheet:{name}/slicer:{cNvPrId}`。没有 `cNvPr/@id` 时用 `slicer:index:{k}`，`stable` 为 `false`。`{k}` 只在该表被收入的切片器内从 1 计。
- 根与每张 `worksheet` 始终 `slicerCount`（放在 `oleObjectCount` 之后）。`scope.slicers: true` 时展开该表 `slicers`。
- `insertSlicer` 的 id 必须是 `sheet:{name}`。必须给 `source`（表格 id 或透视表 id）与 `field`（列名或透视字段名）与 `from`。锚点字段对齐 `insertPicture`。
- 表格源写 `x15:tableSlicerCache`；透视源写 `tabular` + `pivotTables`，并补透视缓存定义上的 `x14:pivotCacheDefinition/@pivotCacheId`。不写 OLAP。不写时间线。不把选中项当筛选引擎执行。
- `deleteSlicer` 的 id 必须是切片器 id。摘 drawing 锚点、slicers 部件里对应 `slicer`、若 cache 已无视图则摘 slicerCache 与 workbook 关系。
- create 本期不写切片器。不提供改筛选、改样式、改标题的 op。
