# docx 字符间距

状态：❌
日期：2026-10-11

对应 `roadmap/docx.md` 待做序号 **62**。前置：`.plan/2026年-10月-10日-✅-docx-段落边框底纹与run剩余.md`。不要和段落行距、东亚压缩合成一份。

`setParaFormat` 已有段前、段后、行距（`w:pPr/w:spacing` 的 `before` / `after` / `line` / `lineRule`）。55 计划写明不做 run 上的 `spacing`（字符间距）与 `kern`。inspect 的 `runs` 名单也没有这两项。这不是表格专用字段，格内文字同样走格内段落的 run。

## 目标

run 上的字符间距与字距调整能 inspect、能 `setRunFormat`。不算排版引擎，不把样式里的字距摊进来。

## 已锁定

- `scope.runs` 在 `vertAlign` 之后加 `spacing`、`kern`。
- `spacing` 取 `w:rPr/w:spacing/@w:val`（§17.3.2.35），twip 整数，可负。没有元素为 `null`。
- `kern` 取 `w:kern/@w:val`（半磅），没有为 `null`。
- `setRunFormat` 增加同样两个可选字段；`null` 去掉对应元素。
- 不要 `w:w`（字符缩放百分比）。那不是间距。
- 文档级 `characterSpacingControl`（标点压缩）已有 `setEastAsianSettings`，不要复用。
- 格内、框内、注内、批注内段落的 run 同样认。xlsx / pptx 上这些新字段报未知字段。
- 手测编号 **Rcs**。脚本 `manual-check/office/cases/docx-run-spacing.ps1`。不要和 Bd、Rh、Ea 撞。

- 与 Word 像素级一致
