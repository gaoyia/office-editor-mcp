# xlsx 条件格式与迷你图字段

状态：✅
日期：2026-10-10

对应 `roadmap/xlsx.md` 待做序号 **32**。前置：条件格式、迷你图已过。

`docs/json-contract-xlsx.md` 现状：`insertConditionalFormat` 可写 `cellIs` / `expression` / `colorScale` / `dataBar` / `iconSet`。`containsText` / `notContains` / `beginsWith` / `endsWith` 本期不写。`top10` 只能改已有条，不能按该类型 insert。迷你图不把颜色、标记、坐标轴放进树。`setCellStyle` 不写对角线、缩进、旋转、缩小字体。

## 目标

条件格式能按 `top10` / `aboveAverage` / 文本类规则插入。迷你图能读写颜色、标记与坐标轴。单元格样式能写对角线与缩进 / 旋转。不求值、不渲染色阶。

## 已锁定

- 不求值公式，不把迷你图画进 inspect。不写 `xr2:uid`。
- 不写 `x14` 扩展数据条（渐变、负值色、轴）或扩展图标集。
- 可写 `insertConditionalFormat` 类型再加 `top10` / `aboveAverage` / `containsText` / `notContainsText` / `beginsWith` / `endsWith`。
  其余 `ST_CfType`（`uniqueValues` / `timePeriod` 等）仍只许改 `sqref` / `priority` / `stopIfTrue` / `dxf`。
- Excel 16.0 另存：`top10` 写 `rank`，后 N 写 `bottom="1"`，百分位写 `percent="1"`。省略 `rank` 当作 `10`。
- `aboveAverage` 高于平均不写该属性；低于平均写 `aboveAverage="0"`。`AboveBelow=2` 写 `equalAverage="1"`，`=3` 再加 `aboveAverage="0"`。
- 文本类必须给 `text`。库按首块 `sqref` 左上角写公式：
  - `containsText`：`operator="containsText"`，`NOT(ISERROR(SEARCH("…",A1)))`
  - `notContainsText`：`operator="notContains"`，`ISERROR(SEARCH("…",A1))`
  - `beginsWith`：`LEFT(A1,LEN("…"))="…"`
  - `endsWith`：`RIGHT(A1,LEN("…"))="…"`
- inspect：`aboveAverage` 仅在 XML 为假时出现且为 `false`。`percent` / `bottom` / `equalAverage` 仍只在为真时出现。
- 迷你图 inspect / apply 增加标记布尔、`lineWeight`、`minAxisType` / `maxAxisType` / `manualMin` / `manualMax`、`colors`。
  `displayXAxis` 可写 XML 属性。`custom` 轴必须带对应 `manualMin` / `manualMax`。
- `setCellStyle` 的 `border.diagonal` 与 `diagonalUp` / `diagonalDown`。只给对角线样式、不给方向时两个方向都写（与 Excel 同时画两根斜线一致）。
- `align.indent` / `rotation` / `shrink`。`indent>0` 且未给 `horizontal` 时写 `left`。`rotation` 为 `0`–`180`。
