# pptx / xlsx 形状行距与字距

状态：❌
日期：2026-10-11

对应 `roadmap/pptx.md`、`roadmap/xlsx.md` 跨格式 **C14**。前置：`.plan/2026年-10月-9日-✅-pptx-xlsx-形状文字格式.md`。不要改 Word。不要重做 C9 已有的 `align`。

`setShapeFormat` 已有水平 `align` 与框内垂直 `textAnchor`，pptx 表单元格 id 同样认（checklist Tf4）。没有段落行距（`a:lnSpc` / `a:spcBef` / `a:spcAft`），也没有字符间距（`a:rPr/@spc`）与 `kern`。`textAnchor` 还缺 `just` / `dist`。

## 目标

pptx / xlsx 的形状、文本框，以及 pptx 表单元格，能读写行距、段前段后、字符间距与 kern。`textAnchor` 补全五个锚点值。`setShapeFormat` 加字段，不新开 op。

## 已锁定

- inspect 在 `textAnchor` 之后加 `spcBef`、`spcAft`、`lnSpc`；run 上加 `spc`、`kern`。
- `spcBef` / `spcAft` / `lnSpc`：对象 `{ "type": "pts"|"pct", "val": 整数 }` 或 `null`。`pts` 取 `a:spcPts`，`pct` 取 `a:spcPct`。缺子元则为 `null`。三种间距同一套形状，不要只给行距开百分比。
- `spc`：`a:rPr/@spc`，百分之一磅，可负。缺则为 `null`。
- `kern`：`a:rPr/@kern`，百分之一磅非负整数。缺则为 `null`。
- `setShapeFormat` 增加同样可选字段。id 规则不变（含 pptx 表单元格）。
- `textAnchor` 取值扩为 `t` / `ctr` / `b` / `just` / `dist`（`ST_TextAnchoringType` 全套）。C9 已锁前三个；本切片写 `setShapeFormat`，把漏掉的两个补上，不要再欠一刀。
- docx 上这些新字段报未知字段。Word 行距仍走 `setParaFormat`，字距与 kern 走待做 62。Word 框内锚点走 63。
- 手测编号 **Pln** / **Xln**。脚本 `pptx-shape-spacing.ps1` 与 `xlsx-shape-spacing.ps1`。不要和 Ps、Ptf、Xtf 撞。
