# pptx / xlsx 形状行距与字距

状态：❌
日期：2026-10-11

对应 `roadmap/pptx.md`、`roadmap/xlsx.md` 跨格式 **C14**。前置：`.plan/2026年-10月-9日-✅-pptx-xlsx-形状文字格式.md`。不要改 Word。不要和 C9 的 `align` / `textAnchor` 合成一份。

`setShapeFormat` 已有水平 `align` 与框内垂直 `textAnchor`，pptx 表单元格 id 同样认（checklist Tf4）。没有段落行距（`a:lnSpc` / `a:spcBef` / `a:spcAft`），也没有字符间距（`a:rPr/@spc`）。inspect 形状与表单元格都不报这些键。

## 目标

pptx / xlsx 的形状、文本框，以及 pptx 表单元格，能读写行距、段前段后与字符间距。`setShapeFormat` 加字段，不新开 op。

## 已锁定

- inspect 在 `textAnchor` 之后加 `spcBef`、`spcAft`、`lnSpc`；run 上加 `spc`。
- `spcBef` / `spcAft`：百分之一磅整数，取 `a:spcBef` / `a:spcAft` 的 `spcPts`。缺则为 `null`。不写 `spcPct`。
- `lnSpc`：对象 `{ "type": "pts"|"pct", "val": 整数 }` 或 `null`。对应 `a:lnSpc/a:spcPts` 或 `a:spcPct`。
- `spc`：`a:rPr/@spc`，百分之一磅，可负。缺则为 `null`。
- `setShapeFormat` 增加同样可选字段。id 规则不变（含 pptx 表单元格）。
- docx 上这些新字段报未知字段。Word 行距仍走 `setParaFormat`，字距走待做 62。
- 手测编号 **Pln** / **Xln**。脚本 `pptx-shape-spacing.ps1` 与 `xlsx-shape-spacing.ps1`。不要和 Ps、Ptf、Xtf 撞。
