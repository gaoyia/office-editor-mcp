# xlsx 编辑路线（不做渲染）

只记账顺序，不验收。Excel 全量指包里能表达的对象都能进 inspect、能 apply、create 能按同一套 JSON 生成。不是复刻 Excel 运行时。公式只当字符串读写。

docx 见 [`roadmap/docx.md`](docx.md)。pptx 见 [`roadmap/pptx.md`](pptx.md)。本仓库不实现 MCP；外部 MCP 用领域 JSON 调库，不在本目录开切片。

每份计划仍是：先改当期 `docs/`，确认后再动代码。挂机一次只开一份，从待做序号 0 起。当期切片写在 `.plan/`，不写进本目录。

## 永不做 🚫

- Excel 公式求值、图表渲染、与 Excel 像素级一致
- 按列宽行高去反推 `twoCell` 的显示尺寸
- 编辑 VML / `legacyDrawing`（批注框、旧式控件）
- 默认把图片字节或 chart 部件塞进 inspect 树
- xlsx 上的 `exportChartData`（数据在本工作簿单元格里）
- SmartArt 版式算法
- 执行宏、打印本身
- `.xls`

`vbaProject.bin` 未点名则原样写回。

## 不单开

- 工作表页眉页脚里的图：跟页眉页脚计划走
- 图表工作表上那张 `xdr:graphicFrame`：id 仍是 `sheet:{name}/chart:{cNvPrId}`
- 组合 `xdr:grpSp` 里的图：不够用时补进 `.plan/2026年-9月-27日-✅-xlsx-工作表图.md`
- `exportMedia`：跟图走
- 复制已有文件再 apply：不必新动作
- 功能区艺术字：另存是无 `txBox` 的 `xdr:sp`。按现有规则不进 `textBoxes`，不扩大收集，不单开对象
