# docx 编辑路线（不做渲染）

只记账顺序，不验收。Word 全量指包里能表达的对象都能进 inspect（带稳定 id）、能 apply 增删改、create 能按同一套 JSON 生成。不是复刻 Word 运行时。

xlsx 见 [`roadmap/xlsx.md`](xlsx.md)。pptx 见 [`roadmap/pptx.md`](pptx.md)。本仓库不实现 MCP；外部 MCP 用领域 JSON 调库，不在本目录开切片。

每份计划仍是：先改当期 `docs/`，确认后再动代码。挂机一次只开一份，从待做序号 0 起。当期切片写在 `.plan/`，不写进本目录。

## 永不做 🚫

- 排版引擎、自动绕排、分页计算、与 Word 像素级一致
- 编辑 VML / `w:pict`（现代文件走 DrawingML；删 AlternateContent 时整段带走 Fallback）
- 把页眉页脚图改挂到页眉段落上（已验收契约不拆）
- 默认把图片、embedding、chart 部件字节塞进 inspect 树
- 公式排版引擎、SmartArt 版式算法
- 框内再套框：Word 16.0 另存只写出故事级兄弟框，不手写嵌套 XML（见已过 39）
- 执行宏、邮件合并、打印本身
- `.doc`

`vbaProject.bin` 未点名则原样写回。

## 不单开

- 正文图单独分页、根上挂图名单：不够用时补进 `.plan/2026年-9月-26日-✅-docx-正文图.md`
- 脚注、尾注、批注、文本框里的图：跟容器走，复用图片 op
- 组合里符合条件的图 / 图表 / SmartArt：展开子节点，组合本身不进树
- `exportMedia` / `exportChartData`：跟图、图表走
- 复制已有文件再 apply：不必新动作
- 功能区艺术字：另存是 `wps:wsp` ，inspect 已进 `textBoxes`。不新开对象，不做字填充或弯曲切片
