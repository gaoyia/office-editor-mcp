按稳定 id 改包里的 XML

ooxp 读写新版 Office 文件。已有文件只改目标节点，其余部件按原字节写回。只有新建才整包生成。这一页的示例写进你授权的目录。

工作簿

.xlsx

表格、图表、条件格式和迷你图。.xlsm 可以查看，不执行宏。

文档

.docx

段落、表格、图片、公式、水印和批注。

演示文稿

.pptx

幻灯片、形状、图示、图表和切换，支持写入动画。

支持的格式

只读写 .docx、.xlsx、.pptx。老的二进制 .doc、.xls、.ppt 不在范围内。库不排版、不算公式、也不放映。

文件怎么落地

示例不从浏览器另存。先在右侧选择一个目录，再点「写入目录」，文件直接出现在那里。

MCP

把命令行接到编辑器。command 也可以写成这个程序的完整路径。
