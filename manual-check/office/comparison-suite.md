# PR10 comparison-test tooling

These are test-only tools. They do not change renderer DPI, geometry, tolerances, or supported features.
All inputs and output roots are explicit command-line parameters. No application, regression test, or script depends on a user's desktop examples.

## Portable invocation

Use any copied historical comparison archive as an explicit input; it is not a repository/test dependency:

```text
python manual-check/office/pr10_comparison_suite.py --archive <archive-root> --destination manual-check/office/out/pr10-comparison --prepare --render-current
python manual-check/office/comparison_outcomes.py manual-check/office/out/pr10-comparison
python manual-check/office/comparison-suite-report.py manual-check/office/out/pr10-comparison
python -m unittest discover -s manual-check/office -p "test*.py"
```

The first tool records original hashes, exact old requests, explicit reconstructions where historical requests are unavailable, and current CLI provenance. It creates isolated copies, omitting only a confirmed invalid optional empty spreadsheet shape-style node. All unrelated ZIP part payloads are retained.

Office oracle scripts take explicit plan/destination arguments. `comparison-oracle.ps1` and `comparison-excel-batch.ps1` cover whole-sheet ranges. `comparison-excel-targets.ps1` covers the existing selected chart/spark objects. `comparison-powerpoint-oracle.ps1` uses public Slide.Export with source-derived 96-DPI extents. Plans generated by `comparison_outcomes.py` are runtime outputs, never tracked source dependencies.

Only run Office on owned, statically checked copies. Hash before opening; retain each own reference; close without saving. Do not Quit/kill Office, delete owner locks, change display DPI, or repair an original. Failed exports and repair logs disqualify references. Completed certificates are not an instruction to reopen the same files repeatedly.

## Reference semantics

- A clean certificate binds exact source/object/range and image SHA, checks unchanged source, and verifies the own document is closed/exclusively readable.
- Same dimensions do not imply correct content. Size mismatch means no raw pixel comparison, never `differ=None == PASS`.
- Excel screen CopyPicture/Chart.Export have no explicit DPI parameter. Raw outputs are retained. Physical-scale display views must be named view-only; they are not gold and must not be used to fit renderer output.
- Native PowerPoint export sizes are derived from presentation EMUs, not from library PNGs.
- The attempted Word full-paper EMF route is **not a qualified text reference**. Word rows remain explicitly blocked until separately authorized evidence establishes a valid oracle. This is an oracle limitation, not a claim that Word rendering is unsupported in the library. Experimental replay scripts/images are not dependencies of this tooling.
- Historical-reference rows remain labeled historical, not silently counted as rerun.
- No PR feature checkboxes or semantic acceptance are updated by this tooling.

Unit tests use self-contained temporary fixtures. No desktop source, image, or absolute user path is required for regression tests.
