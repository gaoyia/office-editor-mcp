2.3.9 usePre2018iOSMacLayout
A compatSetting element whose name attribute has the value "usePre2018iOSMacLayout" and
whose uri attribute has the value "http://schemas.microsoft.com/office/word" specifies information
about the layout of documents based on old MacOS font metrics, which are different from the
Windows font metrics.
If the value of val is false, then the Windows font metrics will be used on both Windows and Mac.
If the value of val is true, then the pre-2025 Mac font metrics will be used on both Windows and Mac.
If usePre2018iOSMacLayout is not present, then it is set based on the current platform.
