formattingAllowed
Target namespace: http://schemas.microsoft.com/office/word/2024/wordml/sdtformatlock
An ST_OnOff ([ECMA-376] section 22.9.2.7) attribute that specifies whether the content control is
restricted to formatting. This attribute is applicable only when used in combination with contentLocked
or sdtContentLocked.
The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
attribute.
 <xsd:attribute name="formattingAllowed" type="w12:ST_OnOff"/>
