2.3.10.1
Python environment
The Python environment is a set of resources that we require for execution of code written in the
Python programming language within Excel. The environment definition MUST include a GUID that
identifies a unique programming environment as specified in CT_PythonEnvironmentDefinition
(section 2.6.250). It MUST also include code in the Python programming language as specified in
CT_PythonInitialization (section 2.6.251) that is executed to initialize the Python environment. It
MAY include a Boolean value as specified in CT_PythonInitialization (section 2.6.251), that if
present and set to true specifies that the code to initialize the Python environment has been modified
by the user.
2.3.10.2
Python Function
A PY function as specified in section 2.2.3 enables the Python programming code to be added to Excel.
The first parameter of the function MUST be a 0-based index referencing a CT_PythonScript element
that indicates the Python script for this function as specified in section 2.6.252.
The second parameter of the function MUST take value either 0 or 1.
The function MUST pass the first two parameters. The function can have other optional parameters
that if passed, can be referenced by the corresponding Python script (section 2.3.10.3).
2.3.10.3
Python Script
Each of the CT_PythonScript elements, as specified in section 2.6.252 indicates the Python script
corresponding to a PY function. Any references to the optional parameter passed in a Python function
are encoded as specified in section 2.3.10.4. A CT_PythonScripts element as specified in section
2.6.253 holds the Python scripts corresponding to all PY functions in the workbook.
2.3.10.4
Parameter reference encoding
Any references to an optional parameter of the Python function are encoded as %Px% where x
specifies the 0-based index of a parameter in the Python function. For example, if the third parameter
is to be referenced it would be encoded as %P2%.
