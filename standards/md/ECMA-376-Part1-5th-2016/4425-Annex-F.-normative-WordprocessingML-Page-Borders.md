4415
Annex F.
(normative)
WordprocessingML Page Borders
This Office Open XML specification includes the definitions of all predefined WordprocessingML art
borders, as referenced by the following simple types:

ST_Border (§17.18.2)
The normative source files defining these borders resides in an accompanying file named
OfficeOpenXML-WordprocessingMLArtBorders.zip, which is distributed in electronic form only.
