Annex G.
(normative)
Predefined SpreadsheetML Style
Definitions
This Office Open XML specification includes the definitions of all predefined SpreadsheetML styles that
are referenced by the following elements:

cellStyle (§18.8.7)

tableStyle (§18.8.40)
The normative SpreadsheetML markup defining these styles resides in an accompanying file named
OfficeOpenXML-SpreadsheetMLStyles.zip, which is distributed in electronic form only.
