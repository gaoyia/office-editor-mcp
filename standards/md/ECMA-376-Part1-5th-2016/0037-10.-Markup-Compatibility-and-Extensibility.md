10. Markup Compatibility and Extensibility
Office Open XML documents are designed to allow for innovation by extending their capabilities, by using
(where allowed) the Application-Defined Extension Element extLst specified by this Part of ECMA-376 or by
using the Markup Compatibility and Extensibility features specified by ECMA-376-3. All the features of ECMA-
376-3 are supported by this Part of ECMA-376.
