Annex H.
(informative)
Example Predefined DrawingML Shape
and Text Geometries
This clause is informative.
This Office Open XML specification includes an example definition for all predefined DrawingML shape
geometries that are referenced by the following elements:

prstGeom@prst (§20.1.9.18)

prstTxWarp@prst (§20.1.9.19)
The informative sample DrawingML markup defining these shape and text geometries resides in an
accompanying file named OfficeOpenXML-DrawingMLGeometries.zip, which is distributed in electronic
form only.
End of informative text.
