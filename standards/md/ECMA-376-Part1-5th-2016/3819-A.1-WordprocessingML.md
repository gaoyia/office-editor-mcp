Annex A.

Schemas – W3C XML Schema
This Office Open XML specification includes a family of schemas defined using the W3C XML Schema 1.0 syntax.
The normative definitions of these schemas follow below, and they also reside in an accompanying file named
OfficeOpenXML-XMLSchema-Strict.zip, which is distributed in electronic form.
